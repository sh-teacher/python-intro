Chapter 13: for문: 정해진 횟수만큼 반복하기¶

🎯 이 장에서 배우는 것¶

  • for문으로 정해진 횟수만큼 반복하는 코드를 작성할 수 있다
  • range() 함수를 이용해 반복 횟수를 제어할 수 있다
  • 반복 변수를 활용하여 패턴과 규칙을 만들 수 있다

📚 핵심 개념¶

개념 1: for문과 range()의 관계¶

for문은 마치 "복사기"와 같아요. 같은 명령을 여러 번 똑같이 반복해야 할 때, 일일이 복사하지 말고 한 번만 적으면 자동으로 반복해 줍니다.

# 같은 작업을 100번 해야 한다면?
print("사랑해")  # 100줄을 써야 한다면... 😫
print("사랑해")
print("사랑해")
# ... (97줄 더)

# for문으로는 2줄이면 된다! 
for i in range(100):
    print("사랑해")

for문의 구조: 

for 변수 in range(횟수):
    반복할 코드

range()의 세 가지 형태:

1️⃣ range(n): 0부터 n-1까지 (n번 반복) 

for i in range(5):  # 0, 1, 2, 3, 4 → 총 5번
    print(i)

2️⃣ range(시작, 끝): 시작부터 끝-1까지 

for i in range(1, 6):  # 1, 2, 3, 4, 5
    print(i)

3️⃣ range(시작, 끝, 간격): 간격만큼 증가 

for i in range(0, 10, 2):  # 0, 2, 4, 6, 8
    print(i)

개념 2: 반복 변수를 활용한 패턴 만들기¶

반복할 때마다 변수의 값이 자동으로 변합니다. 이 값을 활용하면 규칙 있는 패턴을 만들 수 있어요.

# 반복 변수를 그대로 사용
for i in range(1, 4):
    print(f"{i}번 출력합니다")

# 출력 결과:
# 1번 출력합니다
# 2번 출력합니다
# 3번 출력합니다

🔨 따라하기¶

Step 1: 간단한 for문으로 시작하기¶

코드: 

# 1부터 5까지 출력하기
for i in range(1, 6):
    print(i)

실행 결과: 

1
2
3
4
5

Step 2: 반복 변수 활용하기¶

코드: 

# 반복 변수를 곱셈에 활용
for i in range(1, 6):
    print(f"{i} × 2 = {i * 2}")

실행 결과: 

1 × 2 = 2
2 × 2 = 4
3 × 2 = 6
4 × 2 = 8
5 × 2 = 10

Step 3: 별(★) 패턴 만들기¶

코드: 

# 세로로 별 늘어나기
for i in range(1, 6):
    print("★" * i)

실행 결과: 

★
★★
★★★
★★★★
★★★★★

Step 4: 간격을 활용한 반복¶

코드: 

# 2의 배수 출력 (0, 2, 4, 6, 8)
for i in range(0, 10, 2):
    print(f"{i}는 2의 배수입니다")

실행 결과: 

0는 2의 배수입니다
2는 2의 배수입니다
4는 2의 배수입니다
6는 2의 배수입니다
8는 2의 배수입니다

Step 5: 구구단 한 줄로 만들기¶

코드: 

# 5단 만들기
for i in range(1, 10):
    print(f"5 × {i} = {5 * i}")

실행 결과: 

5 × 1 = 5
5 × 2 = 10
5 × 3 = 15
5 × 4 = 20
5 × 5 = 25
5 × 6 = 30
5 × 7 = 35
5 × 8 = 40
5 × 9 = 45

📝 전체 코드 (체크포인트: 이름을 예쁜 틀 안에 출력하기)¶

# 사용자 이름 입력받기
name = input("당신의 이름을 입력하세요: ")

# 상단 테두리
print("=" * 20)

# 이름을 반복해서 출력
for i in range(3):
    print(f"  {name}을(를) 환영합니다!")

# 하단 테두리
print("=" * 20)

실행 결과 (이름이 "민지"라고 입력했을 때): 

====================
  민지을(를) 환영합니다!
  민지을(를) 환영합니다!
  민지을(를) 환영합니다!
====================

⚠️ 주의할 점¶

1️⃣ range()는 끝값을 포함하지 않습니다 

# range(5)는 0, 1, 2, 3, 4 (5는 포함 안 됨!)
for i in range(5):
    print(i)  # 0부터 4까지만 출력됨

# 1부터 5까지 원한다면 range(1, 6) 사용
for i in range(1, 6):
    print(i)  # 1부터 5까지 출력됨

2️⃣ 들여쓰기를 꼭 확인하세요 

# ❌ 잘못된 예
for i in range(3):
print("반복")  # 들여쓰기가 없음 → SyntaxError!

# ✅ 올바른 예
for i in range(3):
    print("반복")  # 들여쓰기(스페이스 4개) 필수!

✅ 점검하기¶

1. 다음 코드를 실행하면 어떤 값들이 출력될까요? 

for i in range(1, 8, 2):
    print(i)

정답 확인 1, 3, 5, 7 이 출력됩니다. - 시작: 1 - 끝: 8 (미포함) - 간격: 2 따라서 1, 3, 5, 7

2. 별 5개를 한 줄에 출력하는 코드를 작성하세요. 

# 힌트: "★" * 5 를 활용하세요

정답 확인 
for i in range(5):
    print("★", end="")  # end=""를 쓰면 줄바꿈 안 함
또는 더 간단하게: 
print("★" * 5)  # 굳이 for문이 필요 없네요!

3. 구구단 3단을 모두 출력하는 코드를 작성하세요.

정답 확인 
for i in range(1, 10):
    print(f"3 × {i} = {3 * i}")
출력 결과: 
3 × 1 = 3
3 × 2 = 6
3 × 3 = 9
3 × 4 = 12
3 × 5 = 15
3 × 6 = 18
3 × 7 = 21
3 × 8 = 24
3 × 9 = 27
