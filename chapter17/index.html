Chapter 17. 리스트 완전 정복! 추가, 삭제, 정렬¶

🎯 이 장에서 배우는 것¶

  • append(), insert()로 리스트에 요소를 추가할 수 있다
  • remove(), pop()으로 요소를 삭제할 수 있다
  • sort(), reverse(), 슬라이싱으로 리스트를 정렬하고 변형할 수 있다

📚 핵심 개념¶

개념 1️⃣ : 리스트 추가 (append & insert)¶

비유: 리스트는 마치 출석부처럼 동작해요. 새로운 학생이 들어오면 맨 뒤에 이름을 쓰거나(append), 특정 줄에 끼워 넣을 수 있습니다(insert).

정의: - append(): 리스트의 맨 끝에 요소 추가 - insert(): 특정 위치에 요소 삽입

# 멍이의 좋아하는 노래 리스트 만들기
songs = ["아리랑", "밤하늘별", "산토끼"]

# 맨 끝에 추가
songs.append("떡볶이노래")
print(songs)
# ['아리랑', '밤하늘별', '산토끼', '떡볶이노래']

# 특정 위치(인덱스 1)에 삽입
songs.insert(1, "새노래")
print(songs)
# ['아리랑', '새노래', '밤하늘별', '산토끼', '떡볶이노래']

개념 2️⃣ : 리스트 삭제 (remove & pop)¶

비유: 더 이상 필요 없는 노래를 지울 때, 이름으로 찾아 지우거나(remove) 위치를 지정해서 빼낼 수 있어요(pop).

정의: - remove(): 특정 값을 찾아서 삭제 (없으면 오류) - pop(): 특정 위치의 요소를 꺼내기 (꺼낸 값 반환)

songs = ["아리랑", "새노래", "밤하늘별", "산토끼"]

# 값으로 찾아 삭제
songs.remove("산토끼")
print(songs)
# ['아리랑', '새노래', '밤하늘별']

# 인덱스 1번 요소를 꺼냄 (반환값 저장 가능)
removed_song = songs.pop(1)
print(removed_song)  # '새노래'
print(songs)         # ['아리랑', '밤하늘별']

🔨 따라하기¶

Step 1: 기본 노래 리스트 만들기¶

코드: 

# 멍이의 플레이리스트
playlist = ["불난집", "숲길", "카페"]
print(f"원본 리스트: {playlist}")

실행 결과: 

원본 리스트: ['불난집', '숲길', '카페']

Step 2: 노래 추가하기 (append, insert)¶

코드: 

playlist = ["불난집", "숲길", "카페"]

# 좋아하는 새 노래 발견! 맨 뒤에 추가
playlist.append("보이지않는손")
print(f"append 후: {playlist}")

# "불난집" 다음에 "유리에비" 삽입
playlist.insert(1, "유리에비")
print(f"insert 후: {playlist}")

실행 결과: 

append 후: ['불난집', '숲길', '카페', '보이지않는손']
insert 후: ['불난집', '유리에비', '숲길', '카페', '보이지않는손']

Step 3: 노래 삭제하기 (remove, pop)¶

코드: 

playlist = ["불난집", "유리에비", "숲길", "카페", "보이지않는손"]

# 싫증난 노래 제거
playlist.remove("카페")
print(f"remove 후: {playlist}")

# 2번 위치 노래를 꺼내기
popped = playlist.pop(2)
print(f"꺼낸 노래: {popped}")
print(f"pop 후: {playlist}")

실행 결과: 

remove 후: ['불난집', '유리에비', '숲길', '보이지않는손']
꺼낸 노래: 숲길
pop 후: ['불난집', '유리에비', '보이지않는손']

Step 4: 정렬 및 뒤집기 (sort, reverse)¶

코드: 

playlist = ["불난집", "유리에비", "보이지않는손"]

# 가나다순 정렬
playlist.sort()
print(f"sort 후: {playlist}")

# 역순으로 뒤집기
playlist.reverse()
print(f"reverse 후: {playlist}")

실행 결과: 

sort 후: ['보이지않는손', '유리에비', '불난집']
reverse 후: ['불난집', '유리에비', '보이지않는손']

Step 5: 슬라이싱으로 일부만 추출¶

코드: 

# 숫자로 재정렬한 플레이리스트
numbers = [5, 2, 8, 1, 9, 3]
numbers.sort()
print(f"정렬된 리스트: {numbers}")

# 상위 3개만 뽑기 (인덱스 0~2)
top3 = numbers[-3:]
print(f"상위 3개: {top3}")

# 중간 2개 추출 (인덱스 2~3)
middle = numbers[2:4]
print(f"중간값들: {middle}")

실행 결과: 

정렬된 리스트: [1, 2, 3, 5, 8, 9]
상위 3개: [5, 8, 9]
중간값들: [3, 5]

📝 전체 코드¶

# 🎵 멍이의 플레이리스트 관리 프로그램

playlist = ["불난집", "숲길", "카페"]
print("=== 플레이리스트 관리 시작 ===")
print(f"초기 리스트: {playlist}\n")

# 1단계: 노래 추가
playlist.append("보이지않는손")
playlist.insert(1, "유리에비")
print(f"1단계 (노래 추가): {playlist}")

# 2단계: 노래 삭제
playlist.remove("카페")
removed = playlist.pop(2)
print(f"2단계 (노래 삭제): {playlist} (제거된 곡: {removed})")

# 3단계: 정렬
playlist.sort()
print(f"3단계 (가나다순 정렬): {playlist}")

# 4단계: 역순 정렬
playlist.reverse()
print(f"4단계 (역순 정렬): {playlist}")

# 5단계: 슬라이싱
print(f"\n현재 리스트: {playlist}")
print(f"처음 2곡: {playlist[:2]}")
print(f"마지막 1곡: {playlist[-1:]}")

실행 결과: 

=== 플레이리스트 관리 시작 ===
초기 리스트: ['불난집', '숲길', '카페']

1단계 (노래 추가): ['불난집', '유리에비', '숲길', '카페', '보이지않는손']
2단계 (노래 삭제): ['불난집', '유리에비', '보이지않는손'] (제거된 곡: 숲길)
3단계 (가나다순 정렬): ['보이지않는손', '불난집', '유리에비']
4단계 (역순 정렬): ['유리에비', '불난집', '보이지않는손']

현재 리스트: ['유리에비', '불난집', '보이지않는손']
처음 2곡: ['유리에비', '불난집']
마지막 1곡: ['보이지않는손']

⚠️ 주의할 점¶

1️⃣ remove()는 첫 번째 일치값만 삭제 

songs = ["떡볶이", "떡볶이", "우동"]
songs.remove("떡볶이")  # 첫 번째 '떡볶이'만 제거
print(songs)  # ['떡볶이', '우동']

2️⃣ pop()은 범위를 벗어나면 오류 발생 

songs = ["가", "나"]
songs.pop(5)  # ❌ IndexError! 
# 길이가 2인데 인덱스 5는 없음

✅ 점검하기¶

1️⃣ 다음 코드의 실행 결과는? 

items = [10, 20, 30]
items.insert(1, 15)
print(items)

정답 확인 답: [10, 15, 20, 30]
insert(1, 15)는 인덱스 1 위치에 15를 끼워 넣습니다.

2️⃣ remove()와 pop()의 차이점은?

정답 확인 remove(): 값을 찾아서 삭제 (반환값 없음)
pop(): 위치(인덱스)로 제거하고 그 값을 반환

3️⃣ 리스트 [3, 1, 4, 1, 5]를 sort()한 후 슬라이싱으로 마지막 2개를 얻으려면?

정답 확인 코드:
nums = [3, 1, 4, 1, 5]
nums.sort() # [1, 1, 3, 4, 5]
last_two = nums[-2:] # [4, 5]
