Chapter 06. 계산도 파이썬으로! 연산자 마스터¶

🎯 이 장에서 배우는 것¶

  • 산술 연산자(+, -, *, /, //, %)를 사용하여 실제 계산을 수행할 수 있다
  • 문자열에 연산자를 적용했을 때의 결과를 예측할 수 있다
  • 연산자 우선순위를 고려하여 올바른 계산식을 작성할 수 있다

📚 핵심 개념¶

개념 1️⃣: 산술 연산자 - 파이썬은 계산기다!¶

파이썬의 산술 연산자는 마치 전자계산기의 버튼과 같아요. 버튼을 누르면 계산 결과가 나오듯이, 연산자를 사용하면 계산 결과를 얻습니다.

주요 산술 연산자: - + (더하기): 10 + 5 → 15 - - (빼기): 10 - 5 → 5 - * (곱하기): 10 * 5 → 50 - / (나누기): 10 / 5 → 2.0 ⚠️ 소수점이 나옵니다! - // (몫): 10 // 3 → 3 (나머지 버림) - % (나머지): 10 % 3 → 1 (나눈 후 남은 것) - ** (제곱): 2 ** 3 → 8

예시로 확인: 

# 일상 계산 예제
pizza_price = 20000  # 피자 가격
people = 3           # 사람 수

price_per_person = pizza_price / people  # 한 명당 가격
print(f"한 명당: {price_per_person}원")  # 한 명당: 6666.6666...원

whole_price = pizza_price // people      # 정확한 몫만
remainder = pizza_price % people         # 남은 돈
print(f"몫: {whole_price}, 나머지: {remainder}")  # 몫: 6666, 나머지: 2

개념 2️⃣: 문자열과 연산자 - 예상 밖의 신기한 일!¶

산술 연산자는 숫자뿐만 아니라 문자열에도 사용할 수 있어요! 결과는 완전히 달라집니다.

  • + (연결): "Hello" + "World" → "HelloWorld"
  • * (반복): "하이" * 3 → "하이하이하이"

예시로 확인: 

# 문자열 연결과 반복
greeting = "Hi" + " " + "Python!"
print(greeting)  # Hi Python!

heart = "💛" * 5
print(heart)     # 💛💛💛💛💛

# 이것은 숫자가 아니라 문자열이에요!
result = "123" + "456"
print(result)    # 123456 (579가 아닙니다!)

🔨 따라하기¶

Step 1: 기본 산술 연산 체험하기¶

계산기처럼 파이썬을 사용해봅시다.

코드: 

# 기본 연산
print(10 + 5)      # 더하기
print(10 - 5)      # 빼기
print(10 * 5)      # 곱하기
print(10 / 3)      # 나누기 (소수점 포함)
print(10 // 3)     # 몫만
print(10 % 3)      # 나머지만
print(2 ** 10)     # 2의 10제곱

실행 결과: 

15
5
50
3.3333333333333335
3
1
1024

Step 2: 실제 상황으로 계산해보기 - 용돈 계산¶

코드: 

# 🎓 용돈 계산 시뮬레이션
my_allowance = 100000  # 용돈
coffee_price = 5500
books_count = 3
book_price = 15000

# 지출 계산
coffee_cost = coffee_price * 2
books_cost = books_count * book_price
total_spend = coffee_cost + books_cost

# 남은 용돈
remaining = my_allowance - total_spend

print(f"커피 지출: {coffee_cost}원")
print(f"책 지출: {books_cost}원")
print(f"총 지출: {total_spend}원")
print(f"남은 용돈: {remaining}원")

실행 결과: 

커피 지출: 11000원
책 지출: 45000원
총 지출: 56000원
남은 용돈: 44000원

Step 4: 우선순위 문제 - 괄호의 힘¶

계산식에는 순서가 있어요. 곱셈과 나눗셈이 먼저 계산됩니다!

코드: 

# ⚠️ 우선순위가 중요합니다!
result1 = 2 + 3 * 4
result2 = (2 + 3) * 4

print(f"2 + 3 * 4 = {result1}")      # 14 (곱셈 먼저)
print(f"(2 + 3) * 4 = {result2}")    # 20 (괄호가 먼저)

# 실제 사용 예: 할인 계산
original_price = 50000
discount_rate = 0.2  # 20%

# 잘못된 방식
wrong = original_price * discount_rate + 10000  # 50000*0.2 + 10000 = 20000
# 올바른 방식
correct = (original_price * discount_rate) + 10000  # = 20000

print(f"할인가: {correct}원")

실행 결과: 

2 + 3 * 4 = 14
(2 + 3) * 4 = 20
할인가: 20000원

Step 5: 쇼핑몰 할인 계산기 (완성 프로젝트)¶

코드: 

# 💳 쇼핑몰 할인 계산기
item_price = 35000      # 상품 가격
discount_percent = 25   # 할인율 (%)
tax_rate = 0.1          # 세금율 (10%)

# 할인 금액 계산
discount_amount = item_price * (discount_percent / 100)
price_after_discount = item_price - discount_amount

# 세금 포함 최종 가격
tax = price_after_discount * tax_rate
final_price = price_after_discount + tax

# 결과 출력
print("=" * 30)
print(f"원가: {item_price:,}원")
print(f"할인율: {discount_percent}%")
print(f"할인 금액: {discount_amount:,.0f}원")
print(f"할인 후: {price_after_discount:,.0f}원")
print(f"세금(10%): {tax:,.0f}원")
print(f"최종 가격: {final_price:,.0f}원")
print("=" * 30)

실행 결과: 

==============================
원가: 35,000원
할인율: 25%
할인 금액: 8,750원
할인 후: 26,250원
세금(10%): 2,625원
최종 가격: 28,875원
==============================

⚠️ 주의할 점¶

1️⃣ 나누기(/)와 몫(//)의 차이¶

print(10 / 3)    # 3.3333... (소수점 포함)
print(10 // 3)   # 3 (정수만)

언제 무엇을 쓸까? - 10 / 3: 정확한 값이 필요할 때 (예: 용돈 나누기) - 10 // 3: 정수만 필요할 때 (예: 몇 개씩 나눌 수 있는가)

2️⃣ 문자열과 숫자는 섞을 수 없습니다!¶

# ❌ 이것은 에러입니다!
result = "100" + 50  # TypeError!

# ✅ 이렇게 하세요
result = int("100") + 50  # 150
result = "100" + str(50)  # "10050"

✅ 점검하기¶

1. 다음 코드의 실행 결과는? 

print(15 / 4)
print(15 // 4)
print(15 % 4)

정답 확인 
3.75
3
3
**해석**: 15를 4로 나누면 3.75이고, 몫은 3, 나머지는 3입니다.

2. 다음 중 올바른 코드는?

# A)
print("2024년" + 2024)

# B)
print("2024년 " + str(2024))

# C)
print(2024 + 2024 + "년")
정답 확인 **정답: B)** A) 에러 발생 (문자열 + 숫자는 불가) B) 올바름 (숫자를 문자열로 변환) C) 에러 발생 (숫자 + 숫자 + 문자열은 불가)

3. 할인가 계산: 원가 50,000원에서 30% 할인한 가격은?

정답 확인 
price = 50000
discount_rate = 0.3
final_price = price * (1 - discount_rate)
print(final_price)  # 35000
또는 
final_price = 50000 - (50000 * 0.3)  # 35000
