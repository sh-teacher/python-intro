Chapter 09: True인가 False인가, 비교와 논리 연산¶

🎯 이 장에서 배우는 것¶

  • 비교 연산자를 사용해 두 값을 비교하고 True/False 결과를 얻을 수 있다
  • 논리 연산자(and, or, not)로 여러 조건을 조합할 수 있다

📚 핵심 개념¶

개념 1: 비교 연산자 (저울처럼 비교하기)¶

비유: 비교 연산자는 마치 저울 위에 두 개의 무게를 올려놓고 어느 쪽이 무거운지 판단하는 것과 같아요.

정의: 비교 연산자는 두 값을 비교하여 항상 True 또는 False 중 하나를 결과로 줍니다.

# 비교 연산자 6가지
5 == 5        # 같은가? → True
5 != 3        # 다른가? → True
5 > 3         # 크다? → True
5 < 3         # 작다? → False
5 >= 5        # 크거나 같다? → True
5 <= 3        # 작거나 같다? → False

실제 사례로 확인:

# 게임 캐릭터 레벨 체크
내_레벨 = 15
필요_레벨 = 20

레벨_충분 = 내_레벨 >= 필요_레벨
print(f"던전 입장 가능?: {레벨_충분}")  # False

개념 2: 논리 연산자 (여러 조건을 한 번에)¶

비유: 논리 연산자는 마치 "토요일이고 날씨가 좋으면 나갈 거야" 같은 여러 조건을 하나로 묶는 것과 같아요.

3가지 논리 연산자:

and (둘 다 참이어야 True) 

외출_시간 = 10
날씨_좋음 = True

나갈까 = (외출_시간 > 9) and 날씨_좋음
print(나갈까)  # True (두 조건 모두 True)

or (하나라도 참이면 True) 

토요일 = False
일요일 = True

쉬는날 = 토요일 or 일요일
print(쉬는날)  # True (하나라도 True)

not (반대로 뒤집기) 

숙제_있음 = True

숙제_없음 = not 숙제_있음
print(숙제_없음)  # False

🔨 따라하기¶

Step 1: 비교 연산자 실행해보기¶

코드: 

# 나이를 변수에 저장
내_나이 = 17

# 다양한 비교를 해봅시다
print("=== 비교 연산자 테스트 ===")
print(f"내 나이: {내_나이}")
print(f"성인인가? (18 이상): {내_나이 >= 18}")  # False
print(f"미성년자인가? (18 미만): {내_나이 < 18}")  # True
print(f"정확히 17세인가?: {내_나이 == 17}")  # True

실행 결과: 

=== 비교 연산자 테스트 ===
내 나이: 17
성인인가? (18 이상): False
미성년자인가? (18 미만): True
정확히 17세인가?: True

Step 2: 논리 연산자로 조건 조합하기¶

코드: 

# 영화관 입장 조건 확인
나이 = 15
부모동반 = True
돈 = 12000

# and: 두 조건 모두 만족해야 함
청소년영화_가능 = (나이 >= 12) and (돈 >= 10000)
print(f"청소년 영화 입장 가능?: {청소년영화_가능}")  # True

# or: 하나라도 만족하면 됨
돈_충분 = (돈 >= 15000) or (부모동반 == True)
print(f"입장 가능 (돈 많거나 부모동반)?: {돈_충분}")  # True

실행 결과: 

청소년 영화 입장 가능?: True
입장 가능 (돈 많거나 부모동반)?: True

Step 3: not으로 조건 반대로 만들기¶

코드: 

비가_온다 = False
우산_필요 = not 비가_온다

print(f"오늘 비옴: {비가_온다}")
print(f"우산 필요: {우산_필요}")  # True

실행 결과: 

오늘 비옴: False
우산 필요: True

Step 4: 복잡한 조건 만들기¶

코드: 

# 게임 미션 클리어 조건
적_처치 = True
보물_획득 = False
시간_내에_완료 = True

미션_성공 = 적_처치 and 시간_내에_완료
보너스_점수 = 미션_성공 and 보물_획득

print(f"기본 미션 성공: {미션_성공}")  # True
print(f"보너스 점수 획득: {보너스_점수}")  # False
print(f"다시 도전 필요?: {not 미션_성공}")  # False

실행 결과: 

기본 미션 성공: True
보너스 점수 획득: False
다시 도전 필요?: False

Step 5: 여러 조건을 순서대로 평가하기¶

코드: 

점수 = 85
출석률 = 95

# 여러 조건을 섞어서 사용
합격 = (점수 >= 60) and (출석률 >= 80)
우등생 = (점수 >= 90) or (출석률 >= 95)

print(f"합격: {합격}")  # True
print(f"우등생: {우등생}")  # True

실행 결과: 

합격: True
우등생: True

📝 전체 코드¶

"""
비교 연산자와 논리 연산자 완전 정복
실제 조건식을 코드로 표현해봅시다!
"""

print("=" * 50)
print("Part 1: 비교 연산자")
print("=" * 50)

# 1. 비교 연산자 기본
점수 = 75
합격선 = 60

print(f"점수: {점수}, 합격선: {합격선}")
print(f"합격했나? {점수 >= 합격선}")  # True
print(f"만점을 받았나? {점수 == 100}")  # False
print()

print("=" * 50)
print("Part 2: 논리 연산자 (and, or, not)")
print("=" * 50)

# 2. and 연산자 (둘 다 참)
나이 = 25
면허증_있음 = True

차_운전_가능 = (나이 >= 18) and 면허증_있음
print(f"차 운전 가능?: {차_운전_가능}")  # True

# 3. or 연산자 (하나라도 참)
주말 = True
휴일 = False

쉬는날 = 주말 or 휴일
print(f"쉬는 날?: {쉬는날}")  # True

# 4. not 연산자 (반대)
배고픔 = True
배부름 = not 배고픔

print(f"배고픔: {배고픔}, 배부름: {배부름}")

# 5. 복합 조건
날씨 = "맑음"
시간 = 14  # 오후 2시
친구_있음 = True

산책_가기 = (날씨 == "맑음") and (시간 > 12) and 친구_있음
print(f"산책 갈까?: {산책_가기}")  # True

⚠️ 주의할 점¶

1. 등호 기호 헷갈리기 

x = 5         # 대입 (할당)
x == 5        # 비교 (같은가?)
단 하나의 =는 값을 저장하고, 두 개의 ==는 비교합니다!

2. and/or 순서 이해하기 

# 틀린 예
(나이 >= 18) and or 면허증  # 문법 에러!

# 올바른 예
(나이 >= 18) and (면허증 == True)  # OK

✅ 점검하기¶

1. 다음 코드의 결과를 예측해보세요 (실행 전!) 

x = 10
y = 20
result = (x < y) and (x != y)
print(result)  # True일까? False일까?

정답 확인 **True**입니다. - `x < y` → `10 < 20` → True - `x != y` → `10 != 20` → True - `True and True` → **True**

2. 다음 조건식을 읽고 설명해보세요 

휴가_사용 = (월급 > 2000000) or (보너스 > 1000000)

정답 확인 "월급이 200만원 이상이거나, 보너스가 100만원 이상이면 휴가를 사용할 수 있다"는 의미입니다. 둘 중 하나라도 조건을 만족하면 True입니다.

3. 다음 코드를 실행했을 때 출력값은? 

a = 5
b = 3
print(not (a > b))

정답 확인 **False**입니다. - `a > b` → `5 > 3` → True - `not True` → **False**
