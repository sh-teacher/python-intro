    Chapter 11. elif로 여러 갈래 길 만들기¶

    🎯 이 장에서 배우는 것¶

    • elif를 사용하여 3개 이상의 조건을 순서대로 검사할 수 있다
    • 조건의 순서가 왜 중요한지 이해하고 활용할 수 있다
    • 등급 판정 프로그램을 만들 수 있다

    📚 핵심 개념¶

    개념 1: elif는 "여러 갈래 길" 만드는 도구¶

    지난 장에서 if-else는 두 갈래 길을 만들었어요. 하지만 현실에는 두 갈래보다 많은 선택지가 있습니다.

    elif는 마치 여행할 때 여러 갈림길을 만나는 것과 같아요. 첫 번째 길이 아니면 두 번째 길을 보고, 그것도 아니면 세 번째 길을 보고... 이렇게 위에서 아래로 순서대로 확인하다가, 맞는 길을 찾으면 거기서 멈춥니다.

    if 첫 번째 조건:
    # 첫 번째 조건이 참이면 여기만 실행
elif 두 번째 조건:
    # 첫 번째는 거짓, 두 번째가 참이면 여기만 실행
elif 세 번째 조건:
    # 위 둘 다 거짓, 세 번째가 참이면 여기만 실행
else:
    # 모든 조건이 거짓이면 여기 실행

    핵심: elif의 조건들은 위에서 아래로 순서대로 확인됩니다. 조건이 참이 되는 순간, 나머지는 보지 않고 넘어갑니다.

    개념 2: 조건의 순서가 결과를 바꾼다¶

    이것이 매우 중요한 포인트입니다! 같은 조건이라도 순서가 바뀌면 결과가 달라질 수 있어요.

    graph TD A["점수를 입력받음<br/>score = 80"] -->|첫 번째 경우| B["if score >= 80<br/>▶ A등급"] A -->|두 번째 경우| C["if score >= 60<br/>▶ B등급"] style B fill:#90EE90 style C fill:#FFB6C6

    위 다이어그램처럼 조건의 순서가 중요해요. 이는 실습에서 직접 확인할 수 있습니다.

    🔨 따라하기¶

    Step 1: 간단한 등급 판정 (elif 맛보기)¶

    시험 점수를 입력하면 등급을 알려주는 프로그램입니다.

    score = int(input("시험 점수를 입력하세요: "))

if score >= 90:
    print("A 등급입니다! 우수!")
elif score >= 80:
    print("B 등급입니다. 좋아요!")
elif score >= 70:
    print("C 등급입니다.")
elif score >= 60:
    print("D 등급입니다.")
else:
    print("F 등급입니다. 다시 도전하세요!")

    실행 결과: 

    시험 점수를 입력하세요: 85
B 등급입니다. 좋아요!

    왜 이렇게 동작하나요? - score = 85일 때, 첫 번째 조건 score >= 90은 거짓 → 다음으로 - 두 번째 조건 score >= 80은 참 → "B 등급입니다" 출력 후 더 이상 확인하지 않음

    Step 2: 조건 순서를 바꿔보면?¶

    같은 코드인데 elif 조건의 순서를 바꿔봅시다.

    score = int(input("시험 점수를 입력하세요: "))

if score >= 60:  # 조건 순서 바꿈!
    print("합격입니다!")
elif score >= 80:
    print("우수합니다!")
elif score >= 90:
    print("최고입니다!")
else:
    print("불합격입니다.")

    실행 결과 (점수 95일 때): 

    시험 점수를 입력하세요: 95
합격입니다!

    ⚠️ 문제: 점수가 95인데 "합격입니다"라고만 나와요! 왜냐하면 첫 번째 조건 score >= 60이 이미 참이므로, 나머지는 보지 않기 때문입니다.

    결론: 조건은 큰 것(좁은 것)부터 작은 것(넓은 것) 순서로 배열해야 합니다.

    Step 3: 올바른 순서로 수정하기¶

    score = int(input("시험 점수를 입력하세요: "))

if score >= 90:     # 좁은 범위부터!
    print("최고입니다!")
elif score >= 80:
    print("우수합니다!")
elif score >= 60:
    print("합격입니다!")
else:
    print("불합격입니다.")

    다양한 입력으로 테스트: 

    입력 95 → "최고입니다!"
입력 85 → "우수합니다!"
입력 75 → "합격입니다!"
입력 50 → "불합격입니다."

    ✅ 이제 모든 경우가 올바르게 동작합니다!

    Step 4: 날씨에 따른 추천 복장¶

    조금 더 실용적인 예제입니다.

    temp = int(input("지금 기온은? (℃): "))

if temp >= 28:
    print("반팔, 반바지를 입으세요!")
elif temp >= 20:
    print("얇은 긴팔을 입으세요!")
elif temp >= 10:
    print("가디건과 청바지를 입으세요!")
elif temp >= 0:
    print("두꺼운 겨울옷을 입으세요!")
else:
    print("방한용품까지 챙기세요!")

    실행 결과: 

    지금 기온은? (℃): 15
가디건과 청바지를 입으세요!

    Step 5: 최종 정리 - 성적 피드백 프로그램¶

    # 사용자로부터 점수와 이름 입력
name = input("이름을 입력하세요: ")
score = int(input("점수를 입력하세요: "))

# 등급 판정
if score >= 90:
    grade = "A"
    comment = "탁월한 성과입니다!"
elif score >= 80:
    grade = "B"
    comment = "좋은 성과입니다!"
elif score >= 70:
    grade = "C"
    comment = "평균 수준입니다."
elif score >= 60:
    grade = "D"
    comment = "기초를 다시 다지세요."
else:
    grade = "F"
    comment = "도움이 필요합니다."

# 결과 출력
print(f"{name}님의 성적:")
print(f"  점수: {score}점")
print(f"  등급: {grade}")
print(f"  피드백: {comment}")

    실행 결과: 

    이름을 입력하세요: 김철수
점수를 입력하세요: 87
김철수님의 성적:
  점수: 87점
  등급: B
  피드백: 좋은 성과입니다!

    📝 전체 코드¶

    # elif로 여러 갈래 길 만들기 - 완성 예제

print("=" * 40)
print("학생 성적 평가 시스템")
print("=" * 40)

name = input("\n학생 이름: ")
score = int(input("시험 점수: "))

# elif를 사용한 등급 판정
if score >= 90:
    grade = "A"
    feedback = "🌟 탁월합니다!"
elif score >= 80:
    grade = "B"
    feedback = "👍 좋습니다!"
elif score >= 70:
    grade = "C"
    feedback = "👌 보통입니다."
elif score >= 60:
    grade = "D"
    feedback = "📚 더 노력해요."
else:
    grade = "F"
    feedback = "💪 다시 도전하세요!"

# 결과 출력
print("\n" + "-" * 40)
print(f"이름: {name}")
print(f"점수: {score}점")
print(f"등급: {grade}")
print(f"평가: {feedback}")
print("-" * 40)

    ⚠️ 주의할 점¶

    1. 조건의 순서가 중요합니다

    # ❌ 잘못된 순서
if score >= 60:
    print("합격")
elif score >= 90:
    print("우수")  # 이 조건은 절대 실행되지 않음!

# ✅ 올바른 순서
if score >= 90:
    print("우수")
elif score >= 60:
    print("합격")

    2. elif는 elif 혹은 else와 함께 사용되어야 합니다

    # ❌ 문법 오류
if score >= 90:
    print("A")
elif score >= 80  # 콜론 빠짐!
    print("B")

# ✅ 올바른 문법
if score >= 90:
    print("A")
elif score >= 80:  # 콜론 필수
    print("B")

    ✅ 점검하기¶

    1. 다음 코드를 실행했을 때 점수 85점인 경우 출력 결과는? 
      score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
    정답 확인 출력: B - 첫 번째 조건 `score >= 90`은 거짓 (85는 90보다 작음) - 두 번째 조건 `score >= 80`은 참 (85는 80 이상) - "B"를 출력하고 나머지 조건은 확인하지 않음
    1. 조건을 역순으로 배열하면 어떤 문제가 생기나요?
    정답 확인 더 넓은 범위의 조건이 먼저 실행되어 뒤의 조건이 절대 실행되지 않습니다. 예) `if score >= 60:` 이 먼저 오면, 90점 이상도 "합격"이라고만 나옵니다.
    1. elif는 몇 개까지 사용할 수 있나요?
    정답 확인 제한이 없습니다! 필요한 만큼 elif를 추가할 수 있습니다. 다만 코드가 길어질수록 읽기 어려워지므로, 보통 3~5개 정도를 권장합니다.
