🎨 turtle로 그림 그리기¶

🎯 이 장에서 배우는 것¶

  • turtle 모듈을 설정하고 기본 명령어를 사용할 수 있다
  • 반복문과 함수를 결합해 도형을 그릴 수 있다
  • 색상, 펜 굵기 등을 조절해 창의적인 작품을 만들 수 있다
  • turtle로 패턴과 다각형을 체계적으로 구성할 수 있다

💡 왜 이걸 배우나요?¶

프로그래밍은 눈에 보이지 않는 로직일 수 있어서 답답할 때가 있습니다. 하지만 turtle 모듈은 당신의 코드를 즉시 시각화해줍니다. 수학, 미술, 논리력이 한 번에 어우러지는 경험!

초등학생 때 거북이가 움직이는 대로 그려지는 Logo 언어의 현대판이라고 생각하면 됩니다. 복잡한 수식을 몰라도 반복과 회전 같은 간단한 개념으로 아름다운 패턴을 만들 수 있어요. 🎨

📚 핵심 개념¶

개념 1: turtle이란 무엇인가?¶

비유: turtle을 마치 종이 위를 움직이는 펜을 조종하는 로봇이라고 생각해봅시다.

정의: turtle 모듈은 파이썬에서 그래픽을 그리기 위한 도구입니다. 좌표평면 위에서 거북이를 움직이면 그 경로에 선이 그려집니다.

기본 명령어: - forward(거리) : 거북이가 향한 방향으로 이동 - backward(거리) : 반대 방향으로 이동 - right(각도) : 시계방향으로 회전 - left(각도) : 반시계방향으로 회전 - penup() : 펜 들기 (선이 안 그려짐) - pendown() : 펜 내리기 (선이 그려짐)

import turtle

# 화면 설정
screen = turtle.Screen()
t = turtle.Turtle()

# 정사각형 그리기
for i in range(4):
    t.forward(100)   # 앞으로 100픽셀
    t.right(90)      # 시계방향 90도 회전

turtle.done()

첫 번째 실행 결과: 정사각형이 화면에 나타납니다! ✨

개념 2: 좌표계와 각도¶

turtle은 수학의 좌표계를 사용합니다.

    위(90도)
       ↑
좌(180도) ← → 우(0도)
       ↓
   아래(270도)

거북이는 처음 오른쪽(0도)을 향하고 있습니다. right(90)으로 회전하면 아래쪽을 향합니다.

직관적으로 이해하기: 

t.right(90)   # 시계방향 90도 → 아래쪽 향함
t.left(90)    # 반시계방향 90도 → 원래 방향으로

개념 3: 반복문으로 패턴 만들기¶

정규 다각형(모든 변의 길이와 각도가 같은 도형)을 그릴 때 반복문이 강력합니다.

n각형을 그리려면: - 한 번에 회전할 각도 = 360 ÷ n

예를 들어 육각형(6각형): - 회전각 = 360 ÷ 6 = 60도

# 육각형 그리기
for i in range(6):
    t.forward(100)
    t.right(60)

이 패턴을 여러 번 반복하면 별, 꽃, 나선 같은 복잡한 패턴이 만들어집니다! 🌟

개념 4: 색상과 스타일 조절¶

turtle의 색상 명령어: - pencolor(색상명) : 선의 색 변경 - fillcolor(색상명) : 채우기 색 변경 - begin_fill() / end_fill() : 도형 채우기 - pensize(굵기) : 펜의 굵기 지정

지원하는 색상: 'red', 'blue', 'green', 'yellow', 'purple' 등 140개 이상

t.pencolor('red')      # 빨간 선
t.pensize(3)           # 굵기 3
t.fillcolor('yellow')  # 채우기 색 노랑

# 도형 채우기
t.begin_fill()
for i in range(4):
    t.forward(100)
    t.right(90)
t.end_fill()

Step 1: 환경 설정 및 정사각형 그리기¶

먼저 turtle을 불러와 화면을 만드세요.

import turtle

# 화면 생성
screen = turtle.Screen()
screen.setup(width=800, height=600)
screen.title("My Turtle Art")

# 거북이 생성
t = turtle.Turtle()
t.speed(1)  # 속도: 1 (느림) ~ 10 (빠름)

# 정사각형 그리기
for i in range(4):
    t.forward(100)
    t.right(90)

turtle.done()

실행해보세요! 정사각형이 그려졌나요? 🟫

Step 2: 별 모양 그리기¶

5개의 삼각형을 반복해 별을 만듭니다.

import turtle

screen = turtle.Screen()
t = turtle.Turtle()
t.speed(5)

# 별 그리기: 5개 점 반복
for point in range(5):
    # 삼각형의 두 변 그리기
    t.forward(100)
    t.right(144)  # 360 ÷ 5 = 72, 외각은 180 - 72 = 108 (아님!)
                  # 별의 뾰족함을 위해 144도 사용

turtle.done()

패턴 분석: 

첫 번째 점: forward(100) → right(144)
두 번째 점: forward(100) → right(144)
...5번 반복하면 별 완성!

Step 3: 색깔 있는 꽃 그리기¶

여러 색상의 원을 겹쳐 꽃을 만듭니다.

import turtle
import math

screen = turtle.Screen()
t = turtle.Turtle()
t.speed(0)  # 가장 빠른 속도

colors = ['red', 'orange', 'yellow', 'green', 'blue', 'purple']

# 꽃 그리기: 6개 꽃잎
for i in range(6):
    t.pencolor(colors[i])
    t.fillcolor(colors[i])

    # 원을 근사하는 정36각형 그리기
    t.begin_fill()
    for j in range(36):
        t.forward(2)
        t.right(10)
    t.end_fill()

    # 다음 꽃잎을 위해 회전
    t.right(60)

turtle.done()

TIP: t.speed(0)으로 설정하면 거의 즉시 그려집니다!

Step 4: 나선 패턴 그리기¶

거리를 점점 늘려가며 사각형을 그리면 나선이 됩니다.

import turtle

screen = turtle.Screen()
t = turtle.Turtle()
t.speed(10)
t.pencolor('darkblue')

# 나선 그리기
distance = 5
for i in range(100):
    t.forward(distance)
    t.right(90)
    distance += 1  # 매번 거리를 1씩 증가

turtle.done()

효과: 시간이 지날수록 사각형이 점점 커지면서 나선 모양 형태를 만듭니다! 🌀

Step 5: 나만의 패턴 만들기 (함수 활용)¶

여러 도형을 쉽게 그리기 위해 함수로 만들어봅시다.

import turtle

screen = turtle.Screen()
t = turtle.Turtle()
t.speed(5)

# 다각형을 그리는 함수
def draw_polygon(sides, size, color):
    t.pencolor(color)
    t.fillcolor(color)
    t.begin_fill()

    angle = 360 / sides
    for i in range(sides):
        t.forward(size)
        t.right(angle)

    t.end_fill()

# 여러 다각형 그리기
draw_polygon(3, 100, 'red')      # 삼각형
t.penup()
t.forward(150)
t.pendown()

draw_polygon(6, 80, 'blue')      # 육각형
t.penup()
t.forward(150)
t.pendown()

draw_polygon(8, 60, 'green')     # 팔각형

turtle.done()

함수의 장점: 같은 코드를 반복하지 않고 매개변수만 바꿔 다양한 도형을 그릴 수 있습니다! 🎯

Step 6: 작은 별들로 우주 만들기¶

반복문과 난수를 조합한 창작 예제입니다.

import turtle
import random

screen = turtle.Screen()
screen.bgcolor('navy')
t = turtle.Turtle()
t.speed(0)

# 작은 별 그리기 함수
def draw_star(x, y, size, color):
    t.penup()
    t.goto(x, y)
    t.pendown()
    t.pencolor(color)

    for i in range(5):
        t.forward(size)
        t.right(144)

# 무작위 위치의 별 30개 그리기
for i in range(30):
    x = random.randint(-350, 350)
    y = random.randint(-250, 250)
    size = random.randint(5, 15)
    color = random.choice(['yellow', 'white', 'lightblue'])

    draw_star(x, y, size, color)

t.hideturtle()  # 거북이 숨기기
turtle.done()

실행 결과: 반짝이는 우주 장면이 만들어집니다! ✨🌌

📝 전체 코드¶

최종 완성 예제 - 무지개 꽃 정원

import turtle
import math

# 설정
screen = turtle.Screen()
screen.setup(width=800, height=600)
screen.bgcolor('lightgray')
screen.title("Rainbow Flower Garden")

t = turtle.Turtle()
t.speed(0)

# 꽃을 그리는 함수
def draw_flower(x, y, petal_count, color1, color2):
    t.penup()
    t.goto(x, y)
    t.pendown()

    angle = 360 / petal_count

    # 꽃잎 그리기
    for i in range(petal_count):
        t.pencolor(color1)
        t.fillcolor(color1)
        t.begin_fill()

        # 원을 근사하는 호 그리기
        for j in range(36):
            t.forward(3)
            t.right(10)

        t.end_fill()
        t.right(angle)

    # 꽃의 중심 (노란색)
    t.pencolor('yellow')
    t.fillcolor('yellow')
    t.begin_fill()
    for j in range(36):
        t.forward(1)
        t.right(10)
    t.end_fill()

# 꽃 3개 그리기
draw_flower(-200, 100, 6, 'red', 'pink')
draw_flower(0, -100, 8, 'purple', 'violet')
draw_flower(200, 50, 5, 'orange', 'yellow')

t.hideturtle()
turtle.done()

import turtle

해결책: 항상 마지막에 turtle.done()을 적어주세요!

2️⃣ 각도 계산 실수¶

# ❌ 잘못된 코드: 삼각형인데 90도 회전
for i in range(3):
    t.forward(100)
    t.right(90)  # 이건 사각형이 돼요!

# ✅ 올바른 코드: 삼각형은 120도 회전
for i in range(3):
    t.forward(100)
    t.right(120)  # 360 ÷ 3 = 120

팁: 다각형의 회전각 = 360 ÷ 변의 개수

3️⃣ 색상 이름 오타¶

# ❌ 잘못된 코드
t.pencolor('rad')  # typo!
t.fillcolor('blu')

# ✅ 올바른 코드
t.pencolor('red')
t.fillcolor('blue')

참고: 파이썬은 영어 색상명을 정확하게 인식합니다. 확인이 안 되면 '#FF0000'처럼 RGB 값을 사용할 수도 있습니다.

도전 3: 색상 그라데이션 효과¶

import turtle

screen = turtle.Screen()
t = turtle.Turtle()
t.speed(0)

colors = ['red', 'orange', 'yellow', 'green', 'blue', 'indigo', 'violet']

for i in range(7):
    t.pencolor(colors[i])
    t.pensize(i + 1)

    # 원 그리기
    for j in range(36):
        t.forward(2)
        t.right(10)

    t.penup()
    t.goto(0, 0)
    t.pendown()

turtle.done()

도전 4: 자신만의 창작물¶

위에서 배운 모든 기법을 조합해 자신만의 그림을 만드세요: - 집, 나무, 동물, 풍경 등 자유로운 주제 - 함수로 여러 부분을 조직화하기 - 색상과 패턴 창의적으로 활용하기

예시 아이디어: - 🏠 집과 나무가 있는 풍경 - 🌻 여러 종류의 꽃이 있는 정원 - 🎆 불꽃 축제 장면 - 🌈 무지개와 구름

🔗 다음 장으로¶

다음 장에서는 파일 입출력을 배웁니다. 당신이 그린 그림을 파일로 저장하고, 파일에서 데이터를 읽어오는 방법을 배울 거예요. turtle 그림도 이미지로 저장할 수 있습니다! 🖼️

ts = t.getscreen().getcanvas()
