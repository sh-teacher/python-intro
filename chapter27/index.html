Chapter 27: 파일 읽고 쓰기: 데이터를 저장하자¶

🎯 이 장에서 배우는 것¶

  • open() 함수로 파일을 읽고 쓸 수 있다
  • with문을 사용해 안전하게 파일을 처리할 수 있다
  • 텍스트 파일에 데이터를 저장하고 불러올 수 있다

📚 핵심 개념¶

개념 1: 파일 열고 닫기 (open/close)¶

비유: 파일 처리는 마치 일기장에 쓰고 읽기와 같아요. - 일기장을 펼쳐야 읽을 수 있고(open) - 다 읽으면 덮어야 합니다(close) - 덮지 않으면 먼지가 들어가요 (파일이 손상될 수 있음)

정의: open(파일명, 모드)는 파일을 메모리에 불러와 읽거나 쓸 수 있게 해줍니다.

모드의 종류: - 'r' (Read): 읽기만 가능 (기본값) - 'w' (Write): 파일을 새로 만들거나 덮어씀 - 'a' (Append): 파일 끝에 추가함

# 파일 읽기
file = open('diary.txt', 'r')
content = file.read()  # 전체 내용 읽기
file.close()  # 반드시 닫기!

# 파일 쓰기
file = open('diary.txt', 'w')
file.write('오늘은 날씨가 좋았어!')
file.close()

개념 2: with문을 사용한 안전한 처리¶

비유: with문은 자동 세이버 같아요. 일기장을 다 사용하면 자동으로 덮어줍니다.

정의: with 블록을 빠져나가면 자동으로 close()를 실행해주므로, 파일을 닫기 잊지 않아도 됩니다.

권장 방식: 

# ✅ 권장: with문 사용 (자동 close)
with open('diary.txt', 'r') as file:
    content = file.read()
    print(content)
# 블록을 나오면 자동으로 close됨

# ❌ 비권장: 수동 close (닫기 잊을 수 있음)
file = open('diary.txt', 'r')
content = file.read()
file.close()

🔨 따라하기¶

Step 1: 파일에 기분 일기 쓰기¶

# 기분 일기를 파일에 저장
mood = "오늘은 정말 행복했어! 프로그래밍이 재미있다 😊"

with open('mood_diary.txt', 'w') as file:
    file.write(mood)

print("✅ 일기가 저장되었어요!")

print(saved_mood)

Step 3: 여러 줄 쓰기 - 할 일 목록¶

코드: 

# 할 일 목록을 파일에 저장
todos = ["파이썬 공부하기", "코딩 문제 풀기", "운동하기"]

with open('todo_list.txt', 'w') as file:
    for todo in todos:
        file.write(todo + '\n')  # 각 항목 다음에 줄 바꿈

print("✅ 할 일 목록이 저장되었어요!")

실행 결과: 

✅ 할 일 목록이 저장되었어요!

todo_list.txt 파일 내용: 

파이썬 공부하기
코딩 문제 풀기
운동하기

Step 4: 파일에서 여러 줄 읽기¶

코드: 

# 할 일 목록 읽기
with open('todo_list.txt', 'r') as file:
    todos = file.readlines()  # 줄 단위로 읽기 (리스트로 반환)

print("📋 오늘의 할 일:")
for i, todo in enumerate(todos, 1):
    print(f"{i}. {todo.strip()}")  # strip()으로 줄 바꿈 제거

실행 결과: 

📋 오늘의 할 일:
1. 파이썬 공부하기
2. 코딩 문제 풀기
3. 운동하기

Step 5: 기존 파일에 내용 추가하기¶

코드: 

# 기존 파일 끝에 추가 (덮어쓰지 않음!)
new_todo = "잠자기"

with open('todo_list.txt', 'a') as file:  # 'a' 모드 사용
    file.write(new_todo + '\n')

print("✅ 새로운 할 일이 추가되었어요!")

# 확인해보기
with open('todo_list.txt', 'r') as file:
    print(file.read())

실행 결과: 

✅ 새로운 할 일이 추가되었어요!
파이썬 공부하기
코딩 문제 풀기
운동하기
잠자기

📝 전체 코드¶

# 📌 일기장 프로그램: 기분과 할 일 관리하기

# 1단계: 오늘의 기분 저장
mood = input("오늘의 기분을 알려주세요: ")
with open('my_diary.txt', 'w') as file:
    file.write(mood)
print("✅ 기분이 저장되었어요!")

# 2단계: 할 일 추가
print("\n할 일을 입력하세요 (끝내려면 '완료' 입력):")
with open('my_todo.txt', 'w') as file:
    while True:
        todo = input("→ ")
        if todo == "완료":
            break
        file.write(todo + '\n')
print("✅ 할 일이 저장되었어요!")

# 3단계: 저장된 데이터 읽기
print("\n📖 저장된 정보:")
with open('my_diary.txt', 'r') as file:
    print(f"오늘의 기분: {file.read()}")

with open('my_todo.txt', 'r') as file:
    todos = file.readlines()
    if todos:
        print("오늘의 할 일:")
        for todo in todos:
            print(f"  • {todo.strip()}")
    else:
        print("할 일이 없어요!")

⚠️ 주의할 점¶

1️⃣ 'w' 모드는 기존 파일을 덮어쓴다

# 첫 번째 실행
with open('file.txt', 'w') as f:
    f.write('처음 내용')

# 두 번째 실행
with open('file.txt', 'w') as f:
    f.write('두 번째 내용')
# 결과: '처음 내용'이 사라짐! '두 번째 내용'만 남음

# 💡 기존 내용 유지하려면 'a' 모드 사용!
with open('file.txt', 'a') as f:
    f.write('추가된 내용')

2️⃣ with문을 안 쓰면 파일이 열린 상태로 남을 수 있다

# ❌ 파일이 열린 상태로 남음
file = open('data.txt', 'r')
data = file.read()
# file.close() 없으면 위험!

# ✅ 안전함
with open('data.txt', 'r') as file:
    data = file.read()

✅ 점검하기¶

1. 다음 코드의 실행 결과는? 

with open('test.txt', 'w') as f:
    f.write('처음')
with open('test.txt', 'w') as f:
    f.write('두 번째')
with open('test.txt', 'r') as f:
    print(f.read())

정답 확인 **출력**: `두 번째` **설명**: 첫 번째 'w' 모드로 '처음'을 쓰고, 두 번째 'w' 모드로 다시 열면 파일이 비워지고 '두 번째'만 남습니다.

2. 파일에 여러 줄을 추가하려면 어떤 모드를 써야 할까요?

정답 확인 **답**: 'a' (Append) 모드 기존 내용을 유지하면서 끝에 추가할 때는 'a'를 사용합니다. 
with open('file.txt', 'a') as f:
    f.write('새로운 줄\n')

3. with문을 쓰는 가장 큰 이유는?

정답 확인 **답**: 파일을 자동으로 닫기 위해 (close() 자동 호출) with 블록을 빠져나가면 자동으로 파일이 닫히므로, 닫기를 잊지 않아도 됩니다. 이는 메모리 누수를 방지합니다.

🔗 다음 장 미리보기¶

다음 장에서는 JSON 형식으로 파일에 저장하는 방법을 배워요. 딕셔너리나 리스트 같은 복잡한 데이터를 파일에 쉽게 저장할 수 있답니다!

📌 예: 사용자 정보를 JSON으로 저장해서 다시 불러오기

import json

user = {"이름": "멍이", "나이": 10, "취미": ["산책", "공부"]}

# JSON으로 저장
with open('user.json', 'w') as f:
    json.dump(user, f)

# JSON에서 불러오기
with open('user.json', 'r') as f:
    loaded_user = json.load(f)
