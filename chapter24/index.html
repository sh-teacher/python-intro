🎮 미니 프로젝트: 가위바위보 대회 프로그램¶

🎯 이 장에서 배우는 것¶

  • 게임의 각 기능을 함수로 모듈화하고 설계할 수 있다
  • 사용자 입력, 컴퓨터 선택, 판정, 출력 함수를 조합하여 완성된 프로그램을 만들 수 있다
  • 반복문과 함수를 결합하여 여러 라운드를 관리할 수 있다
  • 점수 집계와 최종 통계를 계산하는 로직을 구현할 수 있다

💡 왜 이걸 배우나요?¶

지금까지 배운 함수, 반복문, 조건문, 리스트 모든 개념을 한 번에 사용하는 프로젝트입니다.

실제 개발에서는 큰 프로젝트를 작은 함수로 나누어 구현합니다. 예를 들어, 게임 회사에서 게임을 만들 때도: - 플레이어 입력 받는 함수 ✓ - 게임 로직 처리하는 함수 ✓ - 결과를 표시하는 함수 ✓

이렇게 기능별로 함수를 분리합니다. 이 프로젝트에서 정확히 이 방식을 배웁니다! 🎯

📚 핵심 개념¶

개념 1: 함수 설계하기 - "요리사처럼 조리 단계를 나누기"¶

비유: 요리사가 한 접시를 만들 때, 각 재료를 준비하고(input), 조리하고(process), 담아낸다(output). 프로그램도 동일합니다.

정의: 프로그램을 작은 함수들로 나누어, 각 함수가 하나의 책임만 지도록 설계하는 것을 모듈화라고 합니다.

예시: 

[가위바위보 게임]
  ├─ 플레이어 입력 함수 (input)
  ├─ 컴퓨터 선택 함수 (random)
  ├─ 승패 판정 함수 (logic)
  ├─ 결과 출력 함수 (output)
  └─ 메인 함수 (orchestrate)

개념 2: 반환값으로 데이터 흐름 연결하기¶

함수들이 독립적이면서도 협력하려면 반환값이 중요합니다. 한 함수의 결과가 다른 함수의 입력이 되는 "파이프라인" 구조입니다.

# 함수 A의 반환값 → 함수 B의 입력
result = 함수_A()      # 결과 생성
판정값 = 함수_B(result) # 그 결과를 다음 단계에 사용

개념 3: 상태 관리 - "게임의 전체 상황 기록하기"¶

여러 라운드를 진행할 때, 누가 이겼는지 누적으로 기록해야 합니다. 이를 상태 관리라고 합니다.

wins = 0  # 플레이어 승수
losses = 0  # 컴퓨터 승수

# 매 라운드마다 업데이트
if 플레이어_승리:
    wins += 1
else:
    losses += 1

개념 4: 함수를 호출하는 순서 (함수 실행 흐름)¶

프로그램은 함수 정의 → 메인 함수 호출의 구조를 가집니다.

[순서]
1. 보조 함수 정의 (판정, 출력 등)
2. 메인 함수 정의 (전체 게임 로직)
3. 메인 함수 호출

🔨 따라하기¶

Step 1: 기본 함수 4개 만들기¶

먼저 1라운드 게임에 필요한 함수 4개를 만듭니다.

import random

# 함수 1: 플레이어 입력받기
def get_player_choice():
    while True:
        choice = input("가위, 바위, 보 중 선택: ").strip()
        if choice in ['가위', '바위', '보']:
            return choice
        print("❌ 가위, 바위, 보만 입력하세요!")

# 함수 2: 컴퓨터 선택
def get_computer_choice():
    return random.choice(['가위', '바위', '보'])

# 함수 3: 승패 판정
def judge(player, computer):
    if player == computer:
        return "무승부"

    # 플레이어가 이기는 경우
    if (player == '가위' and computer == '보') or \
       (player == '바위' and computer == '가위') or \
       (player == '보' and computer == '바위'):
        return "승리"

    return "패배"

# 함수 4: 결과 출력
def print_result(player, computer, result):
    print(f"\n👤 당신: {player} vs 🤖 컴퓨터: {computer}")
    if result == "승리":
        print("✅ 이겼습니다!")
    elif result == "패배":
        print("❌ 졌습니다!")
    else:
        print("🔄 비겼습니다!")

핵심: 각 함수가 하나의 일만 합니다. 이것이 코드를 깔끔하게 유지하는 비결입니다! ✨

Step 2: 1라운드 게임 실행하기¶

보조 함수들을 조합해 1라운드를 완성합니다.

def play_one_round():
    player = get_player_choice()
    computer = get_computer_choice()
    result = judge(player, computer)
    print_result(player, computer, result)
    return result

# 테스트
play_one_round()

Step 3: 여러 라운드 진행하기¶

상태 관리를 추가해 여러 라운드를 반복합니다.

def play_tournament(rounds=3):
    """여러 라운드 진행하기"""
    wins = 0
    losses = 0

    for round_num in range(1, rounds + 1):
        print(f"\n【 라운드 {round_num} 】")
        result = play_one_round()

        # 상태 업데이트
        if result == "승리":
            wins += 1
        elif result == "패배":
            losses += 1

    return wins, losses

# 테스트: 3라운드 게임
wins, losses = play_tournament(3)
print(f"\n【 최종 결과 】")
print(f"당신: {wins}승 {losses}패")

Step 4: 최종 통계 계산하기¶

승률, 전적 등을 계산하는 함수를 추가합니다.

def calculate_stats(wins, losses):
    """게임 통계 계산"""
    total = wins + losses

    if total == 0:
        win_rate = 0
    else:
        win_rate = (wins / total) * 100

    return {
        'total': total,
        'win_rate': win_rate,
        'record': f"{wins}승 {losses}패"
    }

def print_stats(stats):
    """통계를 보기 좋게 출력"""
    print("\n" + "="*30)
    print("🏆 게임 결과 통계")
    print("="*30)
    print(f"전적: {stats['record']}")
    print(f"승률: {stats['win_rate']:.1f}%")
    print("="*30)

# 테스트
stats = calculate_stats(2, 1)
print_stats(stats)

Step 5: 메인 함수로 통합하기¶

모든 함수를 조합해 완성된 게임을 만듭니다.

def main():
    """가위바위보 대회 메인 프로그램"""
    print("\n🎮 가위바위보 대회에 오신 것을 환영합니다!")

    # 라운드 수 입력
    while True:
        try:
            rounds = int(input("몇 라운드를 진행하시겠습니까? "))
            if rounds > 0:
                break
            print("❌ 1 이상의 숫자를 입력하세요!")
        except ValueError:
            print("❌ 숫자를 입력해주세요!")

    # 게임 진행
    wins, losses = play_tournament(rounds)

    # 통계 출력
    stats = calculate_stats(wins, losses)
    print_stats(stats)

# 프로그램 시작
if __name__ == "__main__":
    main()

Step 6: 5판 3선승제 구현하기 (선택)¶

더 게임다운 기능을 추가합니다.

def play_best_of_five():
    """5판 3선승제"""
    wins = 0
    losses = 0
    round_num = 0

    print("\n🎮 5판 3선승제 시작!")

    while wins < 3 and losses < 3:
        round_num += 1
        print(f"\n【 라운드 {round_num} 】")
        result = play_one_round()

        if result == "승리":
            wins += 1
        elif result == "패배":
            losses += 1

        print(f"현재 전적: 당신 {wins}승 vs 컴퓨터 {losses}승")

    # 최종 결과
    print("\n" + "🏆"*15)
    if wins == 3:
        print("축하합니다! 🎉 대회에서 우승했습니다!")
    else:
        print("아쉽습니다. 😢 다시 도전하세요!")
    print("🏆"*15)

    return wins, losses

# 테스트
play_best_of_five()

import random

# ===== 보조 함수들 =====
def get_player_choice():
    """플레이어 입력받기"""
    while True:
        choice = input("가위, 바위, 보 중 선택: ").strip()
        if choice in ['가위', '바위', '보']:
            return choice
        print("❌ 가위, 바위, 보만 입력하세요!")

def get_computer_choice():
    """컴퓨터 선택"""
    return random.choice(['가위', '바위', '보'])

def judge(player, computer):
    """승패 판정"""
    if player == computer:
        return "무승부"

    if (player == '가위' and computer == '보') or \
       (player == '바위' and computer == '가위') or \
       (player == '보' and computer == '바위'):
        return "승리"

    return "패배"

def print_result(player, computer, result):
    """결과 출력"""
    print(f"\n👤 당신: {player} vs 🤖 컴퓨터: {computer}")
    if result == "승리":
        print("✅ 이겼습니다!")
    elif result == "패배":
        print("❌ 졌습니다!")
    else:
        print("🔄 비겼습니다!")

def play_one_round():
    """1라운드 진행"""
    player = get_player_choice()
    computer = get_computer_choice()
    result = judge(player, computer)
    print_result(player, computer, result)
    return result

def play_tournament(rounds=3):
    """여러 라운드 진행"""
    wins = 0
    losses = 0

    for round_num in range(1, rounds + 1):
        print(f"\n【 라운드 {round_num} 】")
        result = play_one_round()

        if result == "승리":
            wins += 1
        elif result == "패배":
            losses += 1

    return wins, losses

def calculate_stats(wins, losses):
    """게임 통계 계산"""
    total = wins + losses
    win_rate = (wins / total * 100) if total > 0 else 0

    return {
        'total': total,
        'wins': wins,
        'losses': losses,
        'win_rate': win_rate
    }

def print_stats(stats):
    """통계 출력"""
    print("\n" + "="*35)
    print("🏆 게임 결과 통계")
    print("="*35)
    print(f"전적: {stats['wins']}승 {stats['losses']}패")
    print(f"승률: {stats['win_rate']:.1f}%")
    print("="*35)

# ===== 메인 함수 =====
def main():
    """가위바위보 대회 메인"""
    print("\n🎮 가위바위보 대회에 오신 것을 환영합니다!")

    while True:
        try:
            rounds = int(input("몇 라운드를 진행하시겠습니까? "))
            if rounds > 0:
                break
            print("❌ 1 이상의 숫자를 입력하세요!")
        except ValueError:
            print("❌ 숫자를 입력해주세요!")

    wins, losses = play_tournament(rounds)
    stats = calculate_stats(wins, losses)
    print_stats(stats)

# ===== 프로그램 시작 =====
if __name__ == "__main__":
    main()

⚠️ 자주 하는 실수¶

실수 1: 함수를 정의하지 않고 계속 같은 코드 복사하기¶

❌ 잘못된 예: 

# 반복되는 코드
player1 = input("선택: ")
computer1 = random.choice(['가위', '바위', '보'])
# ... 판정 로직 ...

player2 = input("선택: ")
computer2 = random.choice(['가위', '바위', '보'])
# ... 판정 로직 ... (똑같음!)

✅ 올바른 예: 

# 함수로 정의하고 재사용
def play_one_round():
    player = get_player_choice()
    computer = get_computer_choice()
    return judge(player, computer)

# 여러 번 호출
result1 = play_one_round()
result2 = play_one_round()

교훈: 같은 로직이 2번 이상 나타나면 함수로 만들기! 🎯

실수 2: 함수가 책임을 너무 많이 가지기¶

❌ 잘못된 예: 

def play_game():
    # 입력, 판정, 출력을 모두 한 함수에서
    player = input("선택: ")
    computer = random.choice(['가위', '바위', '보'])
    if player == computer:
        result = "무승부"
    # ... 더 많은 로직 ...
    print(f"당신: {player}, 컴퓨터: {computer}")
    return result

✅ 올바른 예: 

# 각 함수가 하나의 책임만
def get_player_choice():  # 입력만
    return input("선택: ")

def judge(p, c):  # 판정만
    return "승리" if p == c else "패배"

def print_result(p, c, r):  # 출력만
    print(f"{p} vs {c}: {r}")

교훈: SRP 원칙 - 하나의 함수는 하나의 책임만! 📌

실수 3: 반환값을 받지 않고 함수만 호출하기¶

❌ 잘못된 예: 

result = play_one_round()  # 함수 호출했는데
print(result)  # None이 출력됨!

💡 원인: play_one_round() 함수가 return을 하지 않았을 가능성

✅ 확인하기: 

def play_one_round():
    player = get_player_choice()
    computer = get_computer_choice()
    result = judge(player, computer)
    print_result(player, computer, result)
    return result  # ← 이 부분이 필수!

교훈: 함수의 결과를 사용할 땐 반드시 return으로 반환하기! ↩️

도전 3: 가위바위보보 확장하기 (암호 선택지 추가)¶

def judge_extended(player, computer):
    """확장된 판정 로직"""
    choices = ['가위', '바위', '보']

    if player == computer:
        return "무승부"

    # 가위 > 보 > 바위 > 가위 순환
    player_idx = choices.index(player)
    computer_idx = choices.index(computer)

    # (플레이어 - 컴퓨터) % 3이 1이면 플레이어 승리
    if (player_idx - computer_idx) % 3 == 1:
        return "승리"

    return "패배"
