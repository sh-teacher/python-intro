🎮 미니 프로젝트: 나만의 단어 퀴즈 게임¶

🎯 이 장에서 배우는 것¶

  • 딕셔너리와 리스트를 조합하여 퀴즈 데이터를 구성할 수 있다
  • 반복문과 조건문으로 퀴즈 진행 로직을 구현할 수 있다
  • 사용자 입력을 처리하고 점수를 집계할 수 있다
  • 최종 결과를 점수와 등급으로 표현할 수 있다

💡 왜 이걸 배우나요?¶

지금까지 배운 리스트, 딕셔너리, 반복문, 조건문을 모두 합쳐서 '진짜 쓸 수 있는' 프로그램을 만들어봅시다!

퀴즈 게임은 우리 주변에 흔합니다. 영어 단어 앱, OX 퀴즈, 객관식 시험 등이 모두 같은 원리로 작동해요. 이 프로젝트를 완성하면:

✅ 프로그래밍의 '대물림' 구조 이해: 데이터 → 처리 → 결과
✅ 실제 앱처럼 동작하는 프로그램 제작
✅ 자신만의 콘텐츠로 커스터마이징 가능

📚 핵심 개념¶

개념 1: 자료구조로 퀴즈 데이터 설계하기¶

비유: 퀴즈 게임은 마치 카드 카드박스처럼 생각할 수 있습니다. 앞면에는 문제, 뒷면에는 정답이 적혀있죠.

정의: 딕셔너리의 키를 문제, 값을 정답으로 설정하면 됩니다.

# 단어 퀴즈 데이터
quiz_data = {
    "사과의 영어 단어는?": "apple",
    "고양이를 영어로?": "cat",
    "학교의 영어 단어는?": "school"
}

이렇게 하면 문제-정답이 쌍으로 묶여 있어서 관리하기 쉬워요.

개념 2: 반복문으로 문제를 하나씩 제시하기¶

비유: 카드박스에서 한 장씩 꺼내서 사용자에게 보여주는 것처럼, for 루프로 각 문제를 순회합니다.

for question in quiz_data:
    print(f"Q: {question}")
    user_answer = input("답: ")

개념 3: 조건문으로 정답 비교하기¶

비유: 학생의 답안과 정답 카드를 맞춰보는 채점 선생님처럼, if 문으로 맞고 틀림을 판단합니다.

if user_answer == quiz_data[question]:
    print("✅ 정답입니다!")
    score += 1
else:
    print(f"❌ 틀렸습니다. 정답은 {quiz_data[question]}입니다.")

개념 4: 최종 점수와 등급 계산하기¶

비유: 100점 만점 시험처럼 점수를 계산하고, 점수에 따라 학점을 매기는 것처럼 등급을 부여합니다.

correct_count = 3
total_questions = len(quiz_data)
percentage = (correct_count / total_questions) * 100

if percentage >= 80:
    grade = "🌟 훌륭해요!"
elif percentage >= 60:
    grade = "👍 좋아요!"
else:
    grade = "💪 다시 도전해보세요!"

🔨 따라하기¶

Step 1: 기본 틀 만들기 - 퀴즈 데이터 정의¶

먼저 변하지 않는 부분부터 만들어봅시다.

# 영어 단어 퀴즈 데이터
quiz_data = {
    "사과는 영어로?": "apple",
    "책은 영어로?": "book",
    "집은 영어로?": "house",
    "나무는 영어로?": "tree",
    "별은 영어로?": "star"
}

# 점수 저장 변수
score = 0

💡 핵심: 퀴즈 데이터를 딕셔너리로 저장하면 나중에 문제와 정답을 쉽게 꺼낼 수 있습니다.

Step 2: 게임 시작 화면 만들기¶

print("=" * 40)
print("🎮 단어 퀴즈 게임에 오신 것을 환영합니다!")
print("=" * 40)
print(f"총 {len(quiz_data)}개의 문제가 있습니다.\n")

💡 핵심: len(quiz_data)로 총 문제 개수를 자동으로 계산합니다. 나중에 문제를 추가해도 이 코드는 변경할 필요가 없어요!

Step 3: 반복문으로 문제 제시하고 채점하기¶

score = 0
question_number = 1

for question in quiz_data:
    print(f"\n[문제 {question_number}] {question}")
    user_answer = input(">>> 답을 입력하세요: ").strip().lower()

    correct_answer = quiz_data[question]

    if user_answer == correct_answer:
        print("✅ 정답입니다!")
        score += 1
    else:
        print(f"❌ 틀렸습니다.")
        print(f"   정답: {correct_answer}")

    question_number += 1

⚠️ 주의점: - .strip(): 사용자가 실수로 입력한 공백 제거 - .lower(): 대소문자 상관없이 채점 (사용자 편의) - score += 1: 정답일 때만 점수 증가

Step 4: 최종 결과 계산하기¶

total_questions = len(quiz_data)
percentage = (score / total_questions) * 100

print("\n" + "=" * 40)
print("🎉 게임 종료!")
print("=" * 40)
print(f"맞은 문제: {score}개 / 총 {total_questions}개")
print(f"정답률: {percentage:.1f}%")

💡 핵심: f"{percentage:.1f}%"는 소수점 첫째 자리까지만 표시합니다.

📝 전체 코드¶

완성된 전체 프로그램입니다. 복사해서 바로 실행하세요!

# ========================================
# 🎮 단어 퀴즈 게임
# ========================================

def run_quiz():
    """퀴즈 게임 실행 함수"""

    # 퀴즈 데이터 정의
    quiz_data = {
        "사과는 영어로?": "apple",
        "책은 영어로?": "book",
        "집은 영어로?": "house",
        "나무는 영어로?": "tree",
        "별은 영어로?": "star"
    }

    # 게임 시작
    print("=" * 50)
    print("🎮 단어 퀴즈 게임에 오신 것을 환영합니다!")
    print("=" * 50)
    print(f"총 {len(quiz_data)}개의 문제가 있습니다.\n")

    # 채점 변수
    score = 0
    question_number = 1

    # 문제 출제 및 채점
    for question in quiz_data:
        print(f"[문제 {question_number}] {question}")
        user_answer = input(">>> 답을 입력하세요: ").strip().lower()

        correct_answer = quiz_data[question]

        if user_answer == correct_answer:
            print("✅ 정답입니다!\n")
            score += 1
        else:
            print(f"❌ 틀렸습니다.")
            print(f"   정답: {correct_answer}\n")

        question_number += 1

    # 결과 계산 및 출력
    total_questions = len(quiz_data)
    percentage = (score / total_questions) * 100

    print("=" * 50)
    print("🎉 게임 종료!")
    print("=" * 50)
    print(f"맞은 문제: {score}개 / 총 {total_questions}개")
    print(f"정답률: {percentage:.1f}%")

    # 등급 부여
    if percentage == 100:
        grade = "🏆 완벽합니다!"
    elif percentage >= 80:
        grade = "🌟 훌륭해요!"
    elif percentage >= 60:
        grade = "👍 좋아요!"
    else:
        grade = "💪 다시 도전해보세요!"

    print(f"평가: {grade}")
    print("=" * 50)

# 게임 반복 실행
while True:
    run_quiz()

    play_again = input("\n다시 하시겠습니까? (yes/no): ").strip().lower()
    if play_again != "yes":
        print("\n게임을 종료합니다. 안녕히가세요! 👋")
        break

⚠️ 자주 하는 실수¶

실수 1: 정답 비교 시 대소문자 무시 안 하기¶

# ❌ 나쁜 예
if user_answer == quiz_data[question]:
    # "Apple"과 "apple"이 다르므로 틀렸다고 판정됨

# ✅ 좋은 예
if user_answer.lower() == quiz_data[question].lower():
    # 모두 소문자로 변환 후 비교

실수 2: 문제 데이터 수정 후 총 개수 재계산 안 하기¶

# ❌ 나쁜 예
total_questions = 5  # 문제가 4개로 줄어든 후에도 그대로!
percentage = (score / 5) * 100  # 잘못된 계산

# ✅ 좋은 예
total_questions = len(quiz_data)  # 항상 자동 계산
percentage = (score / total_questions) * 100

실수 3: 점수 증가를 조건 밖에 두기¶

# ❌ 나쁜 예
if user_answer == correct_answer:
    print("✅ 정답입니다!")
score += 1  # 틀렸을 때도 증가함!

# ✅ 좋은 예
if user_answer == correct_answer:
    print("✅ 정답입니다!")
    score += 1  # 정답일 때만 증가

✅ 스스로 점검하기¶

다음 항목들을 확인해보세요!

□ 게임을 실행하면 인사말과 문제 개수가 표시되는가?
□ 문제를 하나씩 풀 수 있는가?
□ 정답을 맞으면 ✅가, 틀리면 ❌가 표시되는가?
□ 정답 개수와 정답률이 올바르게 계산되는가?
□ 점수에 따라 적절한 등급이 부여되는가?
□ "다시 하시겠습니까?"에서 yes를 입력하면 다시 진행되는가?
□ no를 입력하면 게임이 종료되는가?

score = 0
for question in quiz_data:
    # ... 기존 코드 ...

        score += 10
    else:
        score -= 5

final_score = max(0, score)  # 음수가 되지 않도록

도전 3: 정답 기록하기¶

# 사용자의 정답 저장하기
results = []
for question in quiz_data:
    # ... 퀴즈 진행 코드 ...
    results.append({
        "문제": question,
        "사용자 답": user_answer,
        "정답": correct_answer,
        "정답 여부": user_answer == correct_answer
    })

# 게임 후 틀린 문제만 다시 보기
print("\n틀린 문제:")
for result in results:
    if not result["정답 여부"]:
        print(f"- {result['문제']} (정답: {result['정답']})")
