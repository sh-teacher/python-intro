    파이썬이 뭐야? 냥이와 멍이의 첫 만남¶

    🎯 이 장에서 배우는 것¶

    • 파이썬이 무엇인지, 어디에 쓰이는지 설명할 수 있다
    • 블록 코딩과 텍스트 코딩의 차이를 이해할 수 있다
    • 파이썬으로 만들 수 있는 것들을 3가지 이상 말할 수 있다

    📚 핵심 개념¶

    개념 1️⃣: 파이썬(Python)은 뭔가요?¶

    냥이가 멍이에게 설명하는 방식:

    "멍아, 파이썬이 뭐냐고? 우리가 매일 명령을 내리잖아. '밥 줘!', '산책 가자!' 이런 식으로. 파이썬은 컴퓨터에게 명령을 내리는 언어야. 마치 우리가 한국어로 대화하는 것처럼, 파이썬으로 컴퓨터와 대화하는 거지!"

    정확한 정의:

    파이썬은 프로그래밍 언어입니다. 사람이 컴퓨터에게 "이걸 해줘, 저걸 계산해줘"라고 지시하기 위해 만들어진 언어예요. 특징은 쉽고 간단하다는 것! 다른 언어들에 비해 마치 일상 언어에 가까워서 초보자도 배우기 좋습니다.

    실제 사례:

    • 🎵 유튜브 뮤직의 "취향저격 플레이리스트" → 파이썬으로 만들어진 추천 시스템
    • 📸 인스타그램의 얼굴 인식 필터 → 파이썬으로 분석한 이미지 데이터
    • 📊 학교의 성적 분석 프로그램 → 파이썬으로 처리한 통계
    • 🤖 챗봇 (응답하는 AI) → 파이썬이 가장 많이 쓰임

    개념 2️⃣: 블록 코딩 vs 텍스트 코딩¶

    냥이와 멍이의 요리 비유:

    냥이: "멍아, 우리가 케이크를 만든다고 생각해봐. 어떻게 배웠어?"

    멍이: "어? 그림으로 된 레시피? 계란 그림, 버터 그림, 밀가루 그림... 이런 식으로!"

    냥이: "정확해! 그게 블록 코딩이야. 그림처럼 생긴 블록들을 끼워 맞추는 거지. 근데 이제 우리가 배울 텍스트 코딩은?"

    멍이: "글자로 된 레시피?"

    냥이: "맞아! 이제는 글씨로 '계란 2개, 버터 100g, 밀가루 200g...' 이렇게 쓰는 거야. 처음엔 어렵지만, 더 복잡한 요리를 만들 수 있어!"

    블록 코딩 (초급자 단계)
┌─────────────────────┐
│  [마우스 클릭]      │
│  [오른쪽으로 이동]  │
│  [90도 회전]        │
│  [앞으로 이동]      │
└─────────────────────┘
       ↓↓↓
  시각적이고 직관적!
  하지만 복잡한 작업은 제한적

텍스트 코딩 (고급 단계)
┌─────────────────────┐
│ for i in range(4):  │
│   forward(100)      │
│   turn_right(90)    │
└─────────────────────┘
       ↓↓↓
  글자로 표현하고 강력함!
  큰 프로젝트도 가능

    🔨 따라하기: 첫 파이썬 만나기¶

    Step 1: 파이썬 실행 환경 열기¶

    선택지: - 온라인: replit.com 접속 → Python 선택 → Create - 또는 로컬: Python 설치 후 IDLE 열기

    새 파일을 만들고 다음을 입력하세요:

    print("안녕, 나는 파이썬이야!")

    Step 2: 코드 실행하기¶

    실행 버튼 누르기 (또는 F5 / Ctrl+Enter)

    실행 결과: 

    안녕, 나는 파이썬이야!

    💡 print() 함수: 화면에 글자를 띄우는 가장 기본적인 명령어예요!

    Step 3: 우리 정보 출력하기¶

    블록 코딩에서 본 것처럼, 파이썬도 순서대로 실행돼요:

    print("냥이입니다")
print("멍이입니다")
print("함께 파이썬을 배웁니다!")

    실행 결과: 

    냥이입니다
멍이입니다
함께 파이썬을 배웁니다!

    Step 4: 계산하기¶

    파이썬은 계산기처럼 작동해요:

    print(10 + 5)
print(20 - 3)
print(4 * 6)
print(100 / 4)

    실행 결과: 

    15
17
24
25.0

    Step 5: 자신만의 인사말 만들기¶

    이름 = "넌 누구니?"
print(이름)
print("파이썬을 배우고 있어!")

    실행 결과: 

    넌 누구니?
파이썬을 배우고 있어!

    📝 전체 코드¶

    # 1단계: 기본 인사
print("안녕, 나는 파이썬이야!")

# 2단계: 순서대로 출력
print("냥이입니다")
print("멍이입니다")
print("함께 파이썬을 배웁니다!")

# 3단계: 계산하기
print(10 + 5)
print(20 - 3)
print(4 * 6)
print(100 / 4)

# 4단계: 변수 사용
이름 = "넌 누구니?"
print(이름)
print("파이썬을 배우고 있어!")

    ⚠️ 주의할 점¶

    1️⃣ 한글 변수명은 가능하지만, 전문적으로는 영어를 추천합니다

    # 작동하긴 하지만...
이름 = "파이썬"

# 전문적 스타일 (권장)
name = "파이썬"

    2️⃣ 괄호와 따옴표를 빠뜨리면 안 돼요!

    # ❌ 틀린 예
print "안녕"        # 괄호 빠짐
print(안녕)         # 따옴표 빠짐

# ✅ 맞는 예
print("안녕")

    ✅ 점검하기¶

    1. 파이썬이 쓰이는 곳을 2가지 이상 말해보세요.

    정답 확인 - 유튜브 같은 영상 앱의 추천 시스템 - 인스타그램 필터 (얼굴 인식) - 데이터 분석 (성적표, 통계) - 챗봇 같은 AI - 게임 개발 - 웹사이트 제작 *정답이 다르더라도, 컴퓨터가 실제로 하는 일들이면 모두 맞습니다!*

    2. 블록 코딩과 텍스트 코딩의 가장 큰 차이점은?

    정답 확인 - **블록 코딩**: 그림/블록을 끼워 맞추는 방식 (초급, 직관적) - **텍스트 코딩**: 글자로 명령을 쓰는 방식 (고급, 강력함) 둘 다 컴퓨터에 명령을 내리는 방식이지만, 텍스트 코딩이 더 복잡하고 강력한 일들을 할 수 있어요!

    3. 아래 코드의 실행 결과는?

    print(50 + 10)
print("50 + 10")
    정답 확인 
    60
50 + 10
    **왜 다를까?** - `print(50 + 10)` → 파이썬이 계산 후 결과 60 출력 - `print("50 + 10")` → 따옴표 안은 그냥 글자이므로 그대로 출력
