    📦 변수는 이름표가 붙은 상자!¶

    🎯 이 장에서 배우는 것¶

    • 변수를 선언하고 값을 저장할 수 있다
    • 변수 이름 짓기 규칙을 이해하고 올바른 이름을 작성할 수 있다
    • 변수에 저장된 값을 변경하고 출력할 수 있다

    📚 핵심 개념¶

    개념 1️⃣: 변수란?¶

    변수는 마치 이름표가 붙은 상자와 같아요. 📦

    데이터를 보관하기 위해 컴퓨터 메모리 어딘가에 공간을 만들어두고, 그 공간에 이름을 붙인 것입니다. 나중에 그 이름으로 상자를 열어 안에 든 값을 꺼내거나 새로운 값을 넣을 수 있습니다.

    name = "멍이"  # "name" 상자에 "멍이"를 저장
age = 8        # "age" 상자에 8을 저장

    상자의 구조: 

    ┌─────────────────┐
│ name: "멍이"     │ ← 변수명(이름표)
└─────────────────┘
      ↓ 저장된 값

    개념 2️⃣: 변수 이름 짓기 규칙¶

    프로그래밍 언어마다 변수 이름을 지을 때 지켜야 할 규칙이 있습니다. 틀린 이름으로는 에러가 발생해요! ❌

    꼭 지켜야 할 규칙:

    필수 ⭐ - 영문자, 숫자, 언더스코어(_)만 사용 - 숫자로 시작하면 안 됨 (2name ❌) - 공백이 있으면 안 됨 (my name ❌) - 예약어(언어가 미리 정한 단어) 사용 금지 (print, if, while 등)

    권장 👍 - 의미 있는 이름 짓기 (age O, a ❌) - 소문자로 시작 (관례) - 여러 단어는 언더스코어로 연결 (user_age, favorite_color)

    비교해보세요:

    # ✅ 좋은 예
name = "냥이"
user_age = 5
favorite_food = "생선"

# ❌ 나쁜 예
2name = "냥이"        # 숫자로 시작 (SyntaxError)
my name = "냥이"      # 공백 포함 (SyntaxError)
class = "고등학교"    # 예약어 사용 (SyntaxError)
x = 5                 # 의미 불명확 (작동하지만 추천 안 함)

    TIP: 변수명 앞에 어떤 데이터인지 힌트를 넣으면 좋습니다! - user_ : 사용자 정보 - _age : 나이 - is_ : 참/거짓 값

    🔨 따라하기¶

    Step 1: 첫 번째 변수 만들기¶

    프로그래밍 첫 경험! 멍이의 정보를 변수에 저장해봅시다.

    # 변수 선언과 값 할당
name = "멍이"
age = 8

    실행 결과: 

    (아직 출력 명령이 없어서 화면에 나타나지 않음)

    Step 2: 변수 값 출력하기¶

    저장한 값을 화면에 출력해봅시다!

    name = "멍이"
age = 8

print(name)
print(age)

    실행 결과: 

    멍이
8

    Step 3: 변수 값 변경하기¶

    변수의 진짜 멋진 점! 상자에 새로운 값을 넣을 수 있습니다.

    name = "멍이"
age = 8
print(f"처음: {name}은 {age}살입니다")

age = 9  # 생일이 지났어요!
print(f"이제: {name}은 {age}살입니다")

    실행 결과: 

    처음: 멍이은 8살입니다
이제: 멍이은 9살입니다

    NOTE: f"..." 형태를 f-string이라고 부릅니다. {변수명}으로 문자 안에 변수값을 끼워넣을 수 있어요!

    Step 4: 여러 변수 조합하기¶

    여러 변수를 함께 사용해 자기소개를 만들어봅시다.

    name = "냥이"
age = 3
favorite = "치킨"

# 자기소개 문장 만들기
introduction = f"안녕! 난 {name}이고, {age}살이야. 좋아하는 음식은 {favorite}야!"
print(introduction)

    실행 결과: 

    안녕! 난 냥이이고, 3살이야. 좋아하는 음식은 치킨이야!

    Step 5: 잘못된 변수명 찾아보기¶

    다음 코드를 직접 실행하면서 어떤 에러가 나는지 확인해봅시다!

    # 에러 코드 1 - 숫자로 시작
# 2name = "멍이"

# 에러 코드 2 - 공백 포함
# my age = 8

# 에러 코드 3 - 예약어 사용
# class = "강아지"

# 위의 주석을 풀고 하나씩 실행해보세요!

    각각을 풀면 SyntaxError가 나옵니다. 이렇게 하나씩 테스트해보면서 규칙을 몸으로 익혀요!

    📝 전체 코드¶

    # 1단계: 변수 선언
name = "멍이"
age = 8
favorite_food = "소시지"

# 2단계: 값 출력
print("=== 멍이 프로필 ===")
print(f"이름: {name}")
print(f"나이: {age}")
print(f"좋아하는 음식: {favorite_food}")

# 3단계: 값 변경
print("\n=== 생일 축하합니다! ===")
age = 9
print(f"{name}은 이제 {age}살입니다")

# 4단계: 여러 변수 조합
introduction = f"안녕! 난 {name}이고, {age}살이야. {favorite_food}를 좋아해!"
print(f"\n자기소개: {introduction}")

    실행 결과: 

    === 멍이 프로필 ===
이름: 멍이
나이: 8
좋아하는 음식: 소시지

=== 생일 축하합니다! ===
멍이은 이제 9살입니다

자기소개: 안녕! 난 멍이이고, 9살이야. 소시지를 좋아해!

    ⚠️ 주의할 점¶

    1️⃣ 변수 이름 규칙 꼭 지키기 - 숫자로 시작하면 에러! - 공백은 절대 금지! - 한글로 변수명을 쓸 수도 있지만 권장하지 않음

    2️⃣ 값을 바꿀 때 =을 다시 써야 함 

    age = 8
age = age + 1  # 이렇게 다시 할당해야 변경됨
print(age)     # 9 출력

    ✅ 점검하기¶

    1. 다음 중 올바른 변수명은?

    A) user_name    B) 2user    C) user name    D) class_info
    정답 확인 **정답: A, D** - A) `user_name` ✅ (언더스코어로 연결, 영문자만 사용) - B) `2user` ❌ (숫자로 시작) - C) `user name` ❌ (공백 포함) - D) `class_info` ✅ (예약어 `class`를 포함하지만, 변수명 자체는 OK)

    2. 다음 코드의 출력 결과는?

    x = 10
y = 3
x = x + y
print(f"x는 {x}입니다")
    정답 확인 **정답**: 
    x는 13입니다
    **설명**: - `x = 10` → x에 10 저장 - `y = 3` → y에 3 저장 - `x = x + y` → x에 기존값(10) + y값(3) = 13을 다시 저장 - f-string으로 13을 출력

    3. 다음 중 변수 값을 올바르게 바꾼 것은?

    A) age = 8
   age + 1

B) age = 8
   age = age + 1
    정답 확인 **정답: B** - A) ❌ `age + 1`은 계산만 할 뿐 결과를 변수에 저장하지 않음 - B) ✅ `age = age + 1`로 계산 결과를 다시 age에 저장함
