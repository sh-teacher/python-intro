🎮 미니 프로젝트: 숫자 야구 게임¶

🎯 이 장에서 배우는 것¶

  • 반복문으로 게임 턴을 관리할 수 있다
  • 조건문으로 스트라이크/볼/아웃을 판정할 수 있다
  • 랜덤 숫자 생성과 사용자 입력을 결합해 게임 로직을 구현할 수 있다
  • 반복문 탈출(break)로 게임 종료 조건을 제어할 수 있다

💡 왜 이걸 배우나요?¶

지금까지 배운 if, while, for는 따로 따로 사용했습니다. 하지만 현실의 게임이나 앱은 이 모든 것을 섞어서 만들어집니다. 숫자 야구는 다음과 같은 구조입니다:

  • 반복: "다시 숫자를 입력하세요" ← while 반복문
  • 판정: 스트라이크인가? 볼인가? ← if 조건문
  • 탈출: 정답을 맞췄으면 게임 끝! ← break

이 프로젝트를 완성하면, 작은 게임이라도 직접 만들 수 있는 프로그래머가 됩니다! 🚀

📚 핵심 개념¶

개념 1: 게임 구조 설계하기¶

비유: 보드게임의 규칙처럼, 프로그램도 "언제 시작? 언제 끝? 어떻게 판정?" 등의 순서를 미리 정해야 합니다.

정의: 게임 구조는 초기화 → 반복(입력 → 판정 → 결과 출력) → 종료의 순서입니다.

┌─ 게임 시작 (컴퓨터가 숫자 정함)
│
├─ while 반복 시작
│  ├─ 사용자가 숫자 입력
│  ├─ 입력값 검증
│  ├─ 스트라이크/볼 판정
│  ├─ 결과 출력
│  └─ 정답이면 break (반복 탈출)
│
└─ 게임 종료 (점수 표시)

예시: 

# 초기화
answer = [1, 2, 3]  # 정답
attempts = 0

# 반복
while True:
    user_input = input("숫자 입력: ")
    attempts += 1

    # 판정 및 출력
    if user_input == answer:
        print(f"{attempts}번 만에 맞혔어요!")
        break  # 게임 끝!

개념 2: 스트라이크/볼 판정 로직¶

비유: "1이 맞는 자리에 있음 = 스트라이크", "1이 틀린 자리에 있음 = 볼"이라고 생각하세요.

정의: - 스트라이크: 숫자와 자리가 모두 일치 (예: 답 1 2 3, 입력 1 2 3 → 3스트라이크!) - 볼: 숫자는 맞지만 자리가 다름 (예: 답 1 2 3, 입력 2 1 3 → 2볼 1스트라이크)

알고리즘: 

def judge(answer, guess):
    strikes = 0
    balls = 0

    # 스트라이크 세기
    for i in range(3):
        if answer[i] == guess[i]:
            strikes += 1

    # 볼 세기 (있지만 자리가 다른 수)
    for num in guess:
        if num in answer and guess[guess.index(num)] != answer[answer.index(num)]:
            balls += 1

    return strikes, balls

개념 3: break로 반복 탈출하기¶

비유: 게임판에서 목표에 도달하면 "더 이상 말을 움직이지 않음" = 반복 탈출

정의: break는 반복문을 즉시 멈추고 바깥쪽으로 나갑니다.

while True:
    guess = input("숫자: ")

    if guess == answer:
        print("정답!")
        break  # ← 여기서 while 반복 끝!

    print("다시 시도하세요")

print("게임 종료")  # ← break 후 여기로 옴

개념 4: 입력값 검증하기¶

비유: 신분증 확인처럼, 사용자가 입력한 값이 "규칙에 맞는지" 확인합니다.

정의: 게임을 시작하기 전에 입력값이 유효한지 확인하는 과정입니다.

def is_valid(user_input):
    # 3자리 숫자인가?
    if len(user_input) != 3:
        return False

    # 숫자인가?
    if not user_input.isdigit():
        return False

    # 중복된 숫자가 없는가?
    if len(set(user_input)) != 3:
        return False

    return True

Step 2: 입력값 검증 함수 만들기¶

사용자가 입력한 값이 "3자리 서로 다른 숫자"인지 확인합니다.

def is_valid(user_input):
    # 3자리인가?
    if len(user_input) != 3:
        print("❌ 정확히 3자리 숫자를 입력하세요")
        return False

    # 숫자인가?
    if not user_input.isdigit():
        print("❌ 숫자만 입력하세요")
        return False

    # 중복이 있는가?
    if len(set(user_input)) != 3:
        print("❌ 중복된 숫자는 안 됩니다")
        return False

    return True

# 테스트
print(is_valid("123"))   # True
print(is_valid("12"))    # False (2자리)
print(is_valid("aaa"))   # False (숫자 아님)
print(is_valid("112"))   # False (중복)

Step 3: 스트라이크/볼 판정 함수 만들기¶

입력값과 정답을 비교해 스트라이크와 볼의 개수를 계산합니다.

def judge(answer, guess):
    """답: [3,7,2], 입력: "372" → 3스트라이크, 0볼"""
    strikes = 0
    balls = 0

    # 숫자 문자열을 정수 리스트로 변환
    guess_list = [int(x) for x in guess]

    # 스트라이크 카운트
    for i in range(3):
        if answer[i] == guess_list[i]:
            strikes += 1

    # 볼 카운트 (정답에 있지만, 자리가 다른 숫자)
    for i, num in enumerate(guess_list):
        if num in answer and answer.index(num) != i:
            balls += 1

    return strikes, balls

# 테스트
print(judge([3, 7, 2], "372"))  # (3, 0) - 3스트라이크
print(judge([3, 7, 2], "237"))  # (0, 3) - 3볼
print(judge([3, 7, 2], "735"))  # (1, 2) - 1스트라이크 2볼

Step 4: 게임 로직 완성하기¶

Step 1의 기본 틀에 Step 2, 3을 넣어 전체 게임을 만듭니다.

import random

def is_valid(user_input):
    if len(user_input) != 3 or not user_input.isdigit() or len(set(user_input)) != 3:
        return False
    return True

def judge(answer, guess):
    strikes = 0
    balls = 0
    guess_list = [int(x) for x in guess]

    for i in range(3):
        if answer[i] == guess_list[i]:
            strikes += 1

    for i, num in enumerate(guess_list):
        if num in answer and answer.index(num) != i:
            balls += 1

    return strikes, balls

# 게임 시작
print("🎮 숫자 야구 게임 시작!")
answer = random.sample(range(10), 3)
attempts = 0

while True:
    attempts += 1
    user_input = input(f"\n[{attempts}번째] 3자리 숫자 입력: ")

    # 입력값 검증
    if not is_valid(user_input):
        print("⚠️  잘못된 입력입니다")
        attempts -= 1
        continue

    # 판정
    strikes, balls = judge(answer, user_input)

    # 결과 출력
    if strikes == 3:
        print(f"🎉 정답입니다! {attempts}번 만에 맞혔어요!")
        break
    elif strikes == 0 and balls == 0:
        print("아웃!")
    else:
        print(f"스트라이크: {strikes}, 볼: {balls}")

📝 전체 코드¶

import random

def is_valid(user_input):
    """입력값 검증: 3자리 서로 다른 숫자"""
    if len(user_input) != 3:
        return False
    if not user_input.isdigit():
        return False
    if len(set(user_input)) != 3:
        return False
    return True

def judge(answer, guess):
    """스트라이크/볼 판정"""
    strikes = 0
    balls = 0
    guess_list = [int(x) for x in guess]

    # 스트라이크
    for i in range(3):
        if answer[i] == guess_list[i]:
            strikes += 1

    # 볼
    for i, num in enumerate(guess_list):
        if num in answer and answer.index(num) != i:
            balls += 1

    return strikes, balls

# 게임 실행
print("=" * 40)
print("🎮 숫자 야구 게임에 오신 것을 환영합니다!")
print("=" * 40)

answer = random.sample(range(10), 3)
attempts = 0

while True:
    attempts += 1
    user_input = input(f"\n[{attempts}번째] 3자리 숫자 입력 (0~9, 중복 없음): ")

    if not is_valid(user_input):
        print("❌ 3자리 서로 다른 숫자를 입력하세요")
        attempts -= 1
        continue

    strikes, balls = judge(answer, user_input)

    if strikes == 3:
        print(f"\n🎉 정답입니다!")
        if attempts <= 5:
            print("⭐⭐⭐ 천재 수준이네요!")
        elif attempts <= 10:
            print("⭐⭐ 좋은 성적입니다!")
        else:
            print("⭐ 다음엔 더 빨리 맞혀보세요!")
        print(f"📊 총 {attempts}번 시도")
        break
    elif strikes == 0 and balls == 0:
        print("🔴 아웃! (숫자가 하나도 없습니다)")
    else:
        print(f"📌 스트라이크: {strikes}, 볼: {balls}")

⚠️ 자주 하는 실수¶

실수 1: break를 안 쓰면 무한 반복된다¶

❌ 잘못된 코드: 

while True:
    user_input = input("숫자: ")
    if user_input == answer:
        print("정답!")
        # break가 없으면 계속 반복됨!

✅올바른 코드: 

while True:
    user_input = input("숫자: ")
    if user_input == answer:
        print("정답!")
        break  # 반복을 빠져나감

실수 2: 문자열과 리스트 섞어서 비교하기¶

❌ 잘못된 코드: 

answer = [3, 7, 2]
guess = "372"
if answer[0] == guess[0]:  # [3] == "3" → False!
    print("맞음")

✅ 올바른 코드: 

answer = [3, 7, 2]
guess = "372"
guess_list = [int(x) for x in guess]  # "372" → [3, 7, 2]
if answer[0] == guess_list[0]:  # 3 == 3 → True!
    print("맞음")

실수 3: 검증 후에도 attempts 카운트를 잘못 한다¶

❌ 잘못된 코드: 

attempts = 0
while True:
    attempts += 1  # 먼저 증가
    user_input = input("숫자: ")

    if not is_valid(user_input):
        continue  # 다시 반복하는데, attempts는 증가됨!

✅ 올바른 코드: 

attempts = 0
while True:
    user_input = input("숫자: ")

    if not is_valid(user_input):
        continue  # 검증 실패 시 attempts 증가 안 함

    attempts += 1  # 유효한 입력일 때만 카운트

  6. 반복 제어: break 없이는 정답을 맞혀도 게임이 계속 되나요?

  7. 네, break가 없으면 무한 반복됩니다

  8. 테스트: judge([3,7,2], "237")의 결과는?

  9. (0, 3): 스트라이크 0, 볼 3
