    Chapter 15: while문: 조건이 맞을 때까지 반복!¶

    🎯 이 장에서 배우는 것¶

    • while문으로 조건이 참인 동안 코드를 반복 실행할 수 있다
    • break와 continue로 반복을 제어할 수 있다
    • 무한 루프의 원인을 이해하고 방지할 수 있다

    📚 핵심 개념¶

    개념 1: while문의 구조와 동작¶

    while문은 마치 "놀이공원 회전문"과 같아요.

    회전문은 조건이 만족될 때까지 계속 도네요. 조건이 거짓이 되는 순간 밖으로 나갑니다. while문도 마찬가지입니다.

    구조: 

    while 조건:
    조건이 참인 동안 실행할 코드
    ↑ 이 부분을 반복

    흐름도:

    flowchart TD A["조건 확인"] --> B{"조건이<br/>참인가?"} B -->|YES| C["코드 실행"] C --> A B -->|NO| D["반복 종료"]

    정의: while문은 조건식이 참(True)인 동안 들여쓰기된 코드 블록을 반복 실행하는 반복문입니다.

    🔨 따라하기¶

    Step 1: 가장 간단한 while문 만들기¶

    코드: 

    count = 1

while count <= 3:
    print(f"{count}번째 반복입니다!")
    count = count + 1  # 중요! 조건을 변경해야 탈출 가능

print("반복 완료!")

    실행 결과: 

    1번째 반복입니다!
2번째 반복입니다!
3번째 반복입니다!
반복 완료!

    💡 핵심: count = count + 1이 없으면 무한 루프에 빠집니다!

    Step 2: break로 반복 탈출하기¶

    코드: 

    password_attempts = 0

while password_attempts < 3:
    pwd = input("비밀번호를 입력하세요: ")

    if pwd == "1234":
        print("✓ 로그인 성공!")
        break  # 반복 즉시 종료
    else:
        password_attempts += 1
        print(f"틀렸습니다. ({password_attempts}회 시도)")

if password_attempts == 3:
    print("✗ 3회 틀렸습니다. 계정이 잠깁니다.")

    실행 결과 (정답 입력 시): 

    비밀번호를 입력하세요: 1234
✓ 로그인 성공!

    Step 3: continue로 특정 구간 건너뛰기¶

    코드: 

    num = 0

while num < 5:
    num += 1

    if num == 3:
        print("3은 건너뜁니다!")
        continue  # 이 반복만 건너뛰고 다음 반복으로

    print(f"{num}을 출력했습니다.")

print("끝!")

    실행 결과: 

    1을 출력했습니다.
2을 출력했습니다.
3은 건너뜁니다!
4을 출력했습니다.
5을 출력했습니다.
끝!

    Step 4: 숫자 맞추기 게임 만들기¶

    코드: 

    secret = 7
guess = None

while guess != secret:
    guess = int(input("1~10 사이의 숫자를 맞춰보세요: "))

    if guess < secret:
        print("더 큽니다!")
    elif guess > secret:
        print("더 작습니다!")
    else:
        print("🎉 정답입니다!")

    실행 결과 (예시): 

    1~10 사이의 숫자를 맞춰보세요: 5
더 큽니다!
1~10 사이의 숫자를 맞춰보세요: 9
더 작습니다!
1~10 사이의 숫자를 맞춰보세요: 7
🎉 정답입니다!

    Step 5: 종합 프로젝트 - 간단한 ATM 시뮬레이터¶

    코드: 

    balance = 10000
menu_open = True

while menu_open:
    print(f"\n현재 잔액: {balance}원")
    choice = input("1)출금  2)입금  3)종료 선택: ")

    if choice == "1":
        amount = int(input("출금액: "))
        if amount > balance:
            print("✗ 잔액이 부족합니다!")
            continue
        balance -= amount
        print(f"✓ {amount}원 출금했습니다.")

    elif choice == "2":
        amount = int(input("입금액: "))
        balance += amount
        print(f"✓ {amount}원 입금했습니다.")

    elif choice == "3":
        print("감사합니다!")
        menu_open = False
    else:
        print("✗ 잘못된 선택입니다!")

    📝 전체 코드¶

    # 숫자 맞추기 게임 + 재시작 기능
import random

play_game = True

while play_game:
    secret = random.randint(1, 10)
    guess = None
    attempts = 0

    print("\n🎮 숫자 맞추기 게임 시작!")

    while guess != secret:
        guess = int(input("1~10 숫자 입력: "))
        attempts += 1

        if guess < secret:
            print("▲ 더 큽니다")
        elif guess > secret:
            print("▼ 더 작습니다")
        else:
            print(f"🎉 정답! ({attempts}회 시도)")

    restart = input("\n다시 플레이하시겠어요? (y/n): ")
    if restart.lower() != 'y':
        play_game = False

print("게임 종료!")

    ⚠️ 주의할 점¶

    1️⃣ 무한 루프 방지 

    # ❌ 나쁜 예 - 조건을 변경하지 않음
count = 1
while count <= 3:
    print("계속 반복됨!")  # count가 변하지 않아 영원히 반복

# ✅ 좋은 예
count = 1
while count <= 3:
    print(f"{count}번")
    count += 1  # 조건을 변경해야 탈출 가능

    2️⃣ break vs continue 구분

    • break: 반복문 전체를 빠져나감
    • continue: 현재 반복만 건너뛰고 다음 반복으로

    ✅ 점검하기¶

    1. 다음 코드를 실행하면 몇 번 출력될까요? 

    x = 0
while x < 5:
    x += 2
    print(x)

    정답 확인 3번 출력됩니다. - x = 0 → x = 2 (출력) → x = 4 (출력) → x = 6 (출력) → x > 5 (종료) - 출력: 2, 4, 6

    2. break와 continue의 차이를 설명해보세요.

    정답 확인 - **break**: while 반복문 전체를 즉시 종료하고 다음 코드로 이동 - **continue**: 현재 반복 사이클을 건너뛰고 조건 확인으로 돌아감 
    # break 예시
while True:
    if condition:
        break  # 반복문 탈출

# continue 예시  
while True:
    if skip_condition:
        continue  # 이 반복만 건너뜀

    3. 비밀번호를 최대 3번까지만 입력받는 코드를 작성해보세요.

    정답 확인 
    attempts = 0
max_attempts = 3

while attempts < max_attempts:
    pwd = input("비밀번호: ")

    if pwd == "secret123":
        print("✓ 맞습니다!")
        break

    attempts += 1
    remaining = max_attempts - attempts

    if remaining > 0:
        print(f"✗ 틀렸습니다. (남은 시도: {remaining}회)")
    else:
        print("✗ 계정 잠금!")
