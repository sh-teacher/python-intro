🎮 미니 프로젝트: 운세 뽑기 프로그램¶

🎯 이 장에서 배우는 것¶

  • 지금까지 배운 변수, 자료형, 입출력을 종합적으로 활용할 수 있다
  • random 모듈의 choice() 함수를 사용해 리스트에서 무작위 선택할 수 있다
  • random 모듈의 randint() 함수를 사용해 범위 내 무작위 숫자를 생성할 수 있다
  • 완성된 프로그램을 실행하고 검증할 수 있다

💡 왜 이걸 배우나요?¶

지금까지 변수에 데이터를 저장하고, 입력받은 정보를 처리했죠. 하지만 실제 프로그램은 같은 입력에도 다른 결과를 내보여야 할 때가 많습니다. 게임, 추천 시스템, 시뮬레이션 등 거의 모든 현대 소프트웨어에 '무작위성'이 필요합니다.

이 장에서는 Part 2의 모든 개념(변수, 자료형, 입출력)을 한 번에 사용하는 실제 프로그램을 만들어 봅니다. 운세 뽑기 프로그램을 완성하면서 코드로 문제를 해결하는 경험을 쌓을 수 있습니다. 🎯

📚 핵심 개념¶

개념 1️⃣: Python의 random 모듈이란?¶

비유: 운세 책에서 임의로 한 페이지를 펴는 것처럼, 컴퓨터가 여러 선택지 중에서 하나를 무작위로 고르는 일을 도와주는 도구입니다.

정의: random 모듈은 파이썬의 표준 라이브러리로, 무작위 데이터를 생성합니다. 먼저 사용하려면 다음과 같이 import(임포트) 해야 합니다.

import random

TIP: 파이썬은 기본으로 제공하는 모듈들이 많습니다. import로 필요한 도구를 "꺼내서" 사용하는 방식입니다.

개념 2️⃣: random.choice() - 리스트에서 무작위 선택¶

정의: 리스트에 들어있는 요소 중에서 하나를 무작위로 선택해 반환합니다.

문법: 

random.choice(리스트)

예시로 확인:

import random

# 운세 문구들을 리스트로 관리
fortunes = ["대길! 오늘은 좋은 일이 있을 거예요 🌟", 
            "중길! 평범하지만 행운이 있을 것 같아요 ✨",
            "소길! 조심해야 할 날이네요 ⚠️",
            "흉! 집에만 있는 게 낫겠어요 😅"]

# 매번 다른 운세가 출력됨
today_fortune = random.choice(fortunes)
print(today_fortune)

동작 원리: - 처음 실행: "대길! 오늘은 좋은 일이 있을 거예요 🌟" - 두 번째 실행: "중길! 평범하지만 행운이 있을 것 같아요 ✨" - 세 번째 실행: "소길! 조심해야 할 날이네요 ⚠️"

NOTE: 실행할 때마다 결과가 달라집니다. 같은 운세가 나올 수도 있습니다.

개념 3️⃣: random.randint() - 범위 내 무작위 숫자 생성¶

정의: 지정한 범위(시작 ~ 끝, 포함) 사이의 무작위 정수를 생성합니다.

문법: 

random.randint(시작, 끝)

예시로 확인:

import random

# 1부터 100 사이의 럭키 번호 생성
lucky_number = random.randint(1, 100)
print(f"당신의 럭키 번호는 {lucky_number}입니다!")

# 운세의 정확도를 0~100으로 표현
accuracy = random.randint(0, 100)
print(f"이 운세의 정확도: {accuracy}%")

⚠️ 주의: random.randint(1, 10)은 1과 10을 모두 포함합니다. (1, 2, 3, ..., 9, 10)

개념 4️⃣: 문자열 f-string (다시 한 번)¶

정의: 변수를 문자열에 바로 삽입하는 파이썬의 편리한 문법입니다. Part 1에서 배웠지만 미니 프로젝트에서 자주 쓰이므로 다시 강조합니다.

형식: 

f"텍스트 {변수명} 텍스트"

예시: 

name = "민준"
fortune = "대길"
print(f"{name}님의 오늘 운세는 {fortune}입니다!")
# 출력: 민준님의 오늘 운세는 대길입니다!

Step 5: 상세 메시지 추가하기¶

import random

name = input("당신의 이름을 입력하세요: ")
print(f"{name}님, 환영합니다!\n")

fortunes = [
    "대길 ⭐⭐⭐⭐⭐",
    "중길 ⭐⭐⭐",
    "소길 ⭐⭐",
    "흉 🔴"
]

messages = [
    "오늘은 정말 행운의 날입니다! 새로운 것에 도전하세요 💪",
    "무난한 하루가 될 것 같습니다. 평소처럼 지내면 좋아요 😊",
    "조심해야 할 날입니다. 안전하게 행동하세요 ⚠️",

index = random.randint(0, 3)  # 0~3 사이의 숫자로 인덱스 생성

print(f"\n📢 운세: {today_fortune}")

print(f"🔢 럭키 번호: {lucky_number}")
print(f"🎨 럭키 컬러: {lucky_color}")

    "오늘은 특별한 활동은 피하는 게 좋겠어요 😅"
]

colors = ["빨강", "파랑", "노랑", "초록", "보라", "핑크", "검정"]

print("=" * 50)
print(f"🎰 {name}님의 오늘 운세를 뽑습니다!")
print("=" * 50)

index = random.randint(0, 3)
today_fortune = fortunes[index]
message = messages[index]
lucky_number = random.randint(1, 100)
lucky_color = random.choice(colors)

print(f"\n📢 운세: {today_fortune}")
print(f"💬 조언: {message}")
print(f"🔢 럭키 번호: {lucky_number}")
print(f"🎨 럭키 컬러: {lucky_color}")
print("\n" + "=" * 50)
print("좋은 하루 보내세요! 👋")

⚠️ 자주 하는 실수¶

실수 1️⃣: import random 을 작성 안 함¶

❌ 틀린 코드: 

# import random 을 쓰지 않았음
fortune = random.choice(["대길", "중길", "소길", "흉"])

에러 메시지: NameError: name 'random' is not defined

✅ 올바른 코드: 

import random  # 반드시 먼저 선언!

fortune = random.choice(["대길", "중길", "소길", "흉"])

핵심: 모든 파이썬 파일의 맨 위에 필요한 import를 먼저 써주세요.

실수 2️⃣: random.choice()에 문자열을 직접 넣기¶

❌ 틀린 코드: 

# choice()는 리스트를 받아야 함
color = random.choice("빨강 파랑 노랑")

결과: 공백까지 개별 문자로 인식되어 예상과 다른 결과가 나옵니다.

✅ 올바른 코드: 

# 리스트로 만들어야 함
color = random.choice(["빨강", "파랑", "노랑"])

핵심: choice()는 리스트를 받습니다. []로 감싸세요.

실시 3️⃣: random.randint() 범위를 잘못 이해하기¶

❌ 헷갈리는 부분: 

# randint(1, 10)은 1부터 10까지 모두 포함!
number = random.randint(1, 10)
# 1, 2, 3, ..., 9, 10이 모두 가능합니다.
# (10은 제외되지 않음)

✅ 0부터 99까지 원한다면: 

number = random.randint(0, 99)

핵심: randint(a, b)는 a와 b를 모두 포함합니다.

실수 4️⃣: 리스트와 인덱스의 불일치¶

❌ 틀린 코드: 

fortunes = ["대길", "중길", "소길", "흉"]  # 4개 요소 (인덱스 0~3)

index = random.randint(0, 4)  # 0~4가 나올 수 있음!
print(fortunes[index])  # 만약 4가 나오면 에러!

에러: IndexError: list index out of range

✅ 올바른 코드: 

fortunes = ["대길", "중길", "소길", "흉"]  # 4개 요소 (인덱스 0~3)

index = random.randint(0, 3)  # 0~3만 가능
print(fortunes[index])

또는 choice()를 사용하면 인덱스 걱정 안 해도 됩니다:

fortune = random.choice(fortunes)  # 더 간단!

프로그램 실행 관련 - [ ] 프로그램을 실행했을 때 이름을 입력하라는 메시지가 나온다 - [ ] 이름을 입력하면 운세, 럭키 번호, 럭키 컬러가 모두 출력된다 - [ ] 프로그램을 다시 실행하면 다른 운세가 나온다

개념 이해 관련 - [ ] import random의 의미를 설명할 수 있다 - [ ] random.choice(리스트)와 random.randint(a, b)의 차이를 안다 - [ ] 왜 messages와 fortunes의 요소가 같은 개수여야 하는지 이해한다
