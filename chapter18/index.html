Chapter 18. 딕셔너리: 이름표가 붙은 데이터 보관함¶

🎯 이 장에서 배우는 것¶

  • 키-값 쌍으로 딕셔너리를 생성하고 접근할 수 있다
  • 딕셔너리의 정보를 추가, 수정, 삭제할 수 있다
  • for문과 메서드로 딕셔너리를 순회할 수 있다

📚 핵심 개념¶

개념 1: 딕셔너리란 무엇인가?¶

영어사전에 비유하면 📖

  • 영어사전을 펼치면 '단어(키)' → '뜻(값)'이 써있죠?
  • 딕셔너리는 이와 정확히 같은 구조입니다
  • {키: 값, 키: 값, ...} 형태로 쌍을 이루고 있어요

정확한 정의:

딕셔너리는 이름표(키)가 붙은 값들의 모음입니다. 리스트는 위치(0, 1, 2...)로 찾지만, 딕셔너리는 의미 있는 이름(키)으로 찾습니다.

예시로 확인: 

# 리스트: 위치로 접근
student = ["김철수", "2005-03-15", "서울"]
print(student[0])  # 0번째 = 이름인가? 확실하지 않음

# 딕셔너리: 이름으로 접근
student = {"name": "김철수", "birth": "2005-03-15", "city": "서울"}
print(student["name"])  # 훨씬 명확함! 🎯

개념 2: 딕셔너리의 기본 조작¶

딕셔너리는 4가지 기본 동작을 합니다: 조회, 추가, 수정, 삭제

# 딕셔너리 생성
idol = {"name": "뷔", "group": "BTS", "age": 27}

# 1️⃣ 조회: 키로 값 가져오기
print(idol["name"])  # "뷔" 출력

# 2️⃣ 추가: 새로운 키-값 추가
idol["position"] = "보컬"

# 3️⃣ 수정: 기존 값 변경
idol["age"] = 28

# 4️⃣ 삭제: 키 제거
del idol["position"]

print(idol)  # {"name": "뷔", "group": "BTS", "age": 28}

🔨 따라하기¶

Step 1: 나만의 딕셔너리 만들기¶

코드: 

# 좋아하는 유튜버 정보를 딕셔너리로!
youtuber = {
    "name": "우아한형제들",
    "subscribers": 1500000,
    "content": "먹방",
    "active": True
}

print(youtuber)
print(f"채널명: {youtuber['name']}")

실행 결과: 

{'name': '우아한형제들', 'subscribers': 1500000, 'content': '먹방', 'active': True}
채널명: 우아한형제들

Step 2: 정보 추가하고 수정하기¶

코드: 

youtuber = {"name": "우아한형제들", "subscribers": 1500000}

# 새로운 정보 추가
youtuber["start_year"] = 2010

# 기존 정보 수정
youtuber["subscribers"] = 1800000

print(youtuber)

실행 결과: 

{'name': '우아한형제들', 'subscribers': 1800000, 'start_year': 2010}

Step 3: 딕셔너리 순회하기¶

코드: 

profile = {"name": "뷔", "group": "BTS", "birth": 1995}

# keys(): 모든 키 가져오기
for key in profile.keys():
    print(f"키: {key}")

# values(): 모든 값 가져오기
for value in profile.values():
    print(f"값: {value}")

# items(): 키-값 쌍 가져오기 ⭐
for key, value in profile.items():
    print(f"{key} → {value}")

실행 결과: 

키: name
키: group
키: birth
값: 뷔
값: BTS
값: 1995
name → 뷔
group → BTS
birth → 1995

Step 4: in 키워드로 존재 확인하기¶

코드: 

user = {"id": "user123", "email": "test@mail.com"}

# 키가 존재하는지 확인
if "id" in user:
    print("아이디가 있어요!")

if "phone" in user:
    print("이 줄은 실행 안 됨")
else:
    print("전화번호가 없어요")

실행 결과: 

아이디가 있어요!
전화번호가 없어요

Step 5: 실제 활용 - 단어장 프로그램¶

코드: 

# 영단어 저장소
vocabulary = {
    "apple": "사과",
    "book": "책",
    "cat": "고양이"
}

# 1. 전체 단어 출력
print("=== 단어장 ===")
for english, korean in vocabulary.items():
    print(f"{english}: {korean}")

# 2. 새 단어 추가
vocabulary["dog"] = "개"
print(f"\n'dog'가 추가되었어요!")

# 3. 특정 단어 뜻 확인
search = "book"
if search in vocabulary:
    print(f"\n'{search}'의 뜻: {vocabulary[search]}")
else:
    print(f"'{search}'은(는) 없는 단어입니다")

실행 결과: 

=== 단어장 ===
apple: 사과
book: 책
cat: 고양이

'dog'가 추가되었어요!

'book'의 뜻: 책

📝 전체 코드¶

# === 딕셔너리 완벽 활용 예제 ===

# 1단계: 딕셔너리 생성
student = {
    "이름": "박서연",
    "학년": 3,
    "과목": ["수학", "영어", "과학"],
    "성적": 85
}

# 2단계: 조회
print(f"학생명: {student['이름']}")
print(f"성적: {student['성적']}")

# 3단계: 수정
student["성적"] = 92
print(f"수정된 성적: {student['성적']}")

# 4단계: 추가
student["담임"] = "김선생님"

# 5단계: 순회 및 출력
print("\n=== 학생 정보 ===")
for key, value in student.items():
    print(f"{key}: {value}")

# 6단계: 존재 확인
if "담임" in student:
    print(f"\n담임: {student['담임']}")

# 7단계: 삭제
del student["과목"]
print(f"\n과목 삭제 후: {student}")

⚠️ 주의할 점¶

1️⃣ 존재하지 않는 키에 접근하면 에러 발생!

person = {"name": "철수"}
print(person["age"])  # ❌ KeyError 발생!

# 안전하게 하려면:
if "age" in person:
    print(person["age"])
else:
    print("나이 정보가 없어요")

2️⃣ 키는 반드시 고유해야 합니다 (중복 불가)

# ❌ 같은 키를 두 번 쓰면 나중 값으로 덮어씀
data = {"color": "빨강", "color": "파랑"}
print(data)  # {"color": "파랑"} ← 파랑만 남음!

✅ 점검하기¶

1. 다음 코드의 실행 결과를 예상하세요: 

café = {"name": "카페오", "price": 4500, "time": 8}
café["time"] = 10
café["wifi"] = True
print(len(café))

정답 확인 **답: 4** - 초기: `name`, `price`, `time` (3개) - `time` 수정 (개수 변화 없음) - `wifi` 추가 (4개) - `len(café)` = 4

2. 다음 코드에서 출력되지 않는 줄은? 

dog = {"name": "뽀삐", "age": 5}
for key in dog.keys():
    print(key)

정답 확인 **답: 아무것도 출력 안 되는 줄은 없습니다** - `name` 출력 - `age` 출력 키(.keys())를 순회하는 for문이므로 키 2개를 모두 출력합니다.

3. 딕셔너리와 리스트의 차이점을 설명하세요

정답 확인 **리스트**: 순서가 있고, **위치**(0, 1, 2...)로 접근 **딕셔너리**: 순서 상관없이, **의미 있는 이름**(키)로 접근 
# 리스트
person = ["철수", 25]  # 위치 기반
print(person[0])       # 0번째가 뭔지 문맥으로만 알아야 함

# 딕셔너리
person = {"name": "철수", "age": 25}  # 이름 기반
print(person["name"])  # 명확함!
