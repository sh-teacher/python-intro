Chapter 05. 숫자와 문자, 데이터에도 종류가 있어!¶

🎯 이 장에서 배우는 것¶

  • 정수(int), 실수(float), 문자열(str), 불리언(bool)을 구분할 수 있다
  • type() 함수로 데이터의 자료형을 확인할 수 있다
  • 같은 기호도 자료형에 따라 다르게 작동함을 이해한다

📚 핵심 개념¶

개념 1️⃣: 자료형(Data Type)이란?¶

데이터에도 종류가 있어요. 마치 마트의 음식처럼요.

🥩 고기 코너, 🥬 채소 코너, 🧈 유제품 코너... 같은 "물건"이지만 카테고리가 다르면 보관 방법도, 사용 방법도 달라집니다.

프로그래밍도 마찬가지. 데이터의 자료형에 따라 컴퓨터가 어떻게 처리할지 달라집니다.

Python의 기본 자료형 4가지:

정수 (int): 123, -5, 0 - 소수점이 없는 수

실수 (float): 3.14, -2.5, 0.0 - 소수점이 있는 수

문자열 (str): "안녕", '파이썬', "123" - 따옴표로 감싼 텍스트 (숫자도 따옴표 안에 있으면 문자열!)

불리언 (bool): True, False - 참 또는 거짓만 가능

개념 2️⃣: 같은 +인데 결과가 달라진다?¶

이게 자료형이 중요한 이유입니다.

# 정수끼리
10 + 20  # → 30 (더하기)

# 문자열끼리
"10" + "20"  # → "1020" (붙이기!)

# 실수
3.5 + 2.1  # → 5.6

# 불리언
True + True  # → 2 (True는 1, False는 0으로 계산)

같은 +기호도 자료형에 따라 완전히 다르게 작동합니다! 🤯

🔨 따라하기¶

Step 1: 자료형 확인하기 - type() 함수¶

# 각 데이터의 자료형을 확인해봅시다
print(type(100))           # <class 'int'>
print(type(3.14))          # <class 'float'>
print(type("안녕하세요"))   # <class 'str'>
print(type(True))          # <class 'bool'>

실행 결과: 

<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>

💡 type()함수: 괄호 안의 데이터가 어떤 자료형인지 알려줍니다.

Step 2: 숫자 문자열의 비밀을 풀어보자¶

num1 = 10
num2 = 20
str1 = "10"
str2 = "20"

print(num1 + num2)  # → 30 (수학 덧셈)
print(str1 + str2)  # → 1020 (문자 연결)

# 확인해봅시다
print(type(num1))   # <class 'int'>
print(type(str1))   # <class 'str'>

실행 결과: 

30
1020
<class 'int'>
<class 'str'>

😲 같은 숫자 10, 20이지만 따옴표가 있으면 완전히 다르게 작동합니다!

Step 3: 실수는 정수와 어떻게 다를까?¶

print(10 / 5)       # → 2.0 (정수 2가 아니라 실수 2.0!)
print(type(10 / 5)) # <class 'float'>

print(10 // 3)      # → 3 (몫만 구하기, int)
print(10 / 3)       # → 3.333... (나누기, float)
print(type(10 // 3))  # <class 'int'>

실행 결과: 

2.0
<class 'float'>
3
3.3333333333333335
<class 'int'>

📌 중요: Python에서 나누기 /는 항상 실수(float)를 반환합니다.

Step 4: 불리언으로 조건 표현하기¶

x = 10
y = 20

print(x > y)        # → False
print(x < y)        # → True
print(x == y)       # → False
print(type(True))   # <class 'bool'>

# 불리언은 숫자처럼도 작동
print(True + True)  # → 2

실행 결과: 

False
True
False
<class 'bool'>
2

📝 전체 코드¶

# === 자료형의 종류 확인 ===
print("=== 정수(int) ===")
age = 25
print(f"값: {age}, 자료형: {type(age)}")

print("\n=== 실수(float) ===")
height = 175.5
print(f"값: {height}, 자료형: {type(height)}")

print("\n=== 문자열(str) ===")
name = "파이썬"
print(f"값: {name}, 자료형: {type(name)}")

print("\n=== 불리언(bool) ===")
is_student = True
print(f"값: {is_student}, 자료형: {type(is_student)}")

# === 연산 결과가 달라지는 모습 ===
print("\n=== + 기호의 다양한 작동 ===")
print(f"정수: 10 + 20 = {10 + 20}")
print(f"문자열: '10' + '20' = {'10' + '20'}")
print(f"실수: 3.14 + 2.86 = {3.14 + 2.86}")
print(f"불리언: True + False = {True + False}")

# === 자료형 변환 미리보기 ===
print("\n=== 자료형 확인 게임 ===")
mystery_data = "100"
print(f"수수께끼: {mystery_data}")
print(f"정답: {type(mystery_data)}")  # 문자열!

실행 결과: 

=== 정수(int) ===
값: 25, 자료형: <class 'int'>

=== 실수(float) ===
값: 175.5, 자료형: <class 'float'>

=== 문자열(str) ===
값: 파이썬, 자료형: <class 'str'>

=== 불리언(bool) ===
값: True, 자료형: <class 'bool'>

=== + 기호의 다양한 작동 ===
정수: 10 + 20 = 30
문자열: '10' + '20' = 1020
실수: 3.14 + 2.86 = 5.0
불리언: True + False = 1

=== 자료형 확인 게임 ===
수수께끼: 100
정답: <class 'str'>

⚠️ 주의할 점¶

⚠️ 주의 1: 따옴표가 모든 것을 결정한다¶

# 이건 정수
x = 100
print(type(x))  # <class 'int'>

# 이건 문자열 (따옴표 때문에!)
y = "100"
print(type(y))  # <class 'str'>

# 100과 "100"은 보기는 같지만 완전히 다른 데이터!

⚠️ 주의 2: 연산 불가능한 경우가 있다¶

# ❌ 문자열과 정수는 더할 수 없습니다
print("5" + 5)  # TypeError 발생!

# ✅ 같은 자료형끼리만 가능
print("5" + "5")  # "55" (가능)
print(5 + 5)      # 10 (가능)

✅ 점검하기¶

1. 다음 각 데이터의 자료형을 예상하고 type()으로 확인해보세요.

a = 42
b = 3.14
c = "Hello"
d = True
e = "200"
정답 확인 
a = 42           # <class 'int'>
b = 3.14         # <class 'float'>
c = "Hello"      # <class 'str'>
d = True         # <class 'bool'>
e = "200"        # <class 'str'> (따옴표 있음!)
**핵심**: 따옴표 있으면 무조건 문자열!

2. 다음 코드의 실행 결과를 예상해보세요. (실행 후 확인!)

print("2024" + "년")
print(2024 + 1)
print(type(2024))
print(type("2024"))
정답 확인 
2024년
2025
<class 'int'>
<class 'str'>
**해설**: - 문자열 + 문자열 = 연결됨 - 정수 + 정수 = 더해짐 - 따옴표 유무가 자료형을 결정함

3. 이 코드의 문제점을 찾고 수정해보세요.

# 문제 코드
score = 85
print("당신의 점수는 " + score + "점입니다")  # ❌ 실행되지 않음
정답 확인 **문제점**: 문자열과 정수를 `+`로 연결할 수 없습니다. **해결 방법 1** (f-string 사용 - 권장): 
score = 85
print(f"당신의 점수는 {score}점입니다")
**해결 방법 2** (str() 함수로 변환): 
score = 85
print("당신의 점수는 " + str(score) + "점입니다")
두 방법 모두 같은 결과: `당신의 점수는 85점입니다`
