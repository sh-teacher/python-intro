    코딩 준비 완료! 환경 설정하기¶

    🎯 이 장에서 배우는 것¶

    • 구글 코랩에 접속해서 첫 코드를 실행할 수 있다
    • 파이썬 코드를 입력하고 실행하는 기본 흐름을 이해한다

    📚 핵심 개념¶

    개념 1: 구글 코랩(Google Colab)¶

    구글 코랩은 인터넷 브라우저에서 바로 파이썬 코드를 작성하고 실행할 수 있는 온라인 노트북입니다. 마치 "종이 노트에 쓰고 지우며 정리하듯" 코드도 작성하고 수정하고 실행하는 공간이죠.

    특징: - 💻 설치 불필요 (구글 계정만 있으면 OK!) - ⚡ 바로 시작 가능 (지금 바로 시작하기 좋음) - 📱 어떤 기기에서나 접속 가능 - 💾 구글 드라이브에 자동 저장

    개념 2: 셀(Cell)과 실행¶

    코랩 노트북은 셀(Cell)이라는 상자 모양의 영역들로 이루어져 있습니다.

    • 코드 셀: 파이썬 코드를 쓰는 곳 (▶️ 버튼으로 실행)
    • 텍스트 셀: 설명이나 메모를 쓰는 곳 (코드 실행 안 함)
    ┌─────────────────────────┐
│  코드 셀 (파이썬 코드)   │  ◀── ▶️ 버튼으로 실행
│  print("안녕!")        │
└─────────────────────────┘

┌─────────────────────────┐
│  텍스트 셀 (설명)       │
│  이것은 코드가 아닙니다  │
└─────────────────────────┘

    🔨 따라하기¶

    Step 1: 구글 코랩 접속하기¶

    1. 구글 검색창에 "colab.research.google.com" 입력 또는 직접 방문
    2. "새 노트북" 버튼 클릭
    3. 구글 계정으로 로그인 (없으면 생성)

    👉 결과: 하얀 화면에 [ ] 모양의 코드 셀 1개가 나타남

    Step 2: 첫 번째 코드 실행하기¶

    코드 셀 안에 다음을 입력하세요:

    print("안녕하세요!")

    셀 왼쪽의 ▶️ 버튼을 클릭 또는 Ctrl + Enter (Mac은 Cmd + Enter)를 누르세요.

    실행 결과: 

    안녕하세요!

    ✨ 축하합니다! 첫 파이썬 코드를 실행했습니다!

    Step 3: 간단한 계산 실행해보기¶

    새로운 코드 셀을 만들어봅시다. 이전 셀 아래에서 + 코드 버튼을 클릭하거나, 셀 위에 마우스를 올려 [+ 코드] 를 선택합니다.

    # 간단한 계산
print(5 + 3)
print(10 * 2)

    실행 결과: 

    8
20

    Step 4: 오류 처리 (당황하지 않아도 돼요!)¶

    의도적으로 이 코드를 실행해보세요:

    print("실수를 만들어봅시다)

    💥 오류가 나타납니다! 이건 정상입니다. 따옴표를 빠뜨렸거든요. 수정하면 됩니다:

    print("실수를 만들어봅시다")

    배운 것: 오류는 파이썬이 "뭔가 이상해"라고 알려주는 친절한 신호예요!

    Step 5: 노트북 저장하기¶

    1. 좌상단의 노트북 이름("제목 없는 노트북") 클릭
    2. 이름 입력: "나의 첫 파이썬" (또는 원하는 이름)
    3. Enter 누르면 자동으로 구글 드라이브에 저장됨 ✅

    📝 전체 코드¶

    이 장에서 배운 모든 코드를 한 번에 볼 수 있습니다:

    # 1단계: 인사하기
print("안녕하세요!")

# 2단계: 계산하기
print(5 + 3)
print(10 * 2)

# 3단계: 문자와 숫자 섞기
print("나이: " + str(25))

    ⚠️ 주의할 점¶

    1. 따옴표 짝 맞추기 

    # ❌ 틀림
print("안녕)

# ✅ 맞음
print("안녕")

    2. 대문자/소문자 구분 

    # ❌ 틀림 (Print는 없어요!)
Print("안녕")

# ✅ 맞음
print("안녕")

    ✅ 점검하기¶

    1. 구글 코랩에서 코드를 실행하는 방법은?

    정답 확인 코드 셀 왼쪽의 ▶️ 버튼을 클릭하거나, **Ctrl + Enter** (또는 Mac의 **Cmd + Enter**)를 누릅니다.

    2. 다음 코드의 실행 결과는? 

    print(3 * 4)
print("반복" * 2)

    정답 확인 
    12
반복반복
    `*` 기호는 숫자끼리는 곱셈, 문자와 숫자는 반복을 의미합니다!

    3. "제목 없는 노트북"의 이름을 바꾸려면?

    정답 확인 좌상단의 노트북 이름을 클릭해서 새로운 이름을 입력하면 됩니다. 자동으로 저장됩니다!

    🔗 다음 장 미리보기¶

    다음 장에서는 파이썬의 기본 도구들을 배웁니다. 숫자와 문자 같은 "데이터" 종류들을 만나고, 변수라는 상자에 값을 저장하는 방법을 배워요. 지금 배운 print() 함수는 계속 자주 쓸 거니까 잘 기억해두세요! 🚀
