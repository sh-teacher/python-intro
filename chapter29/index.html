Chapter 29: 프로젝트 구현: 코드로 만들어보자! (1)¶

🎯 이 장에서 배우는 것¶

  • 기획서를 바탕으로 프로젝트의 핵심 기능을 파이썬으로 구현할 수 있다
  • 함수를 활용하여 코드를 기능별로 체계적으로 분리할 수 있다
  • 코드를 작게 만들고 자주 테스트하는 개발 방식을 실천할 수 있다
  • 발생하는 오류를 읽고 스스로 디버깅할 수 있다

💡 왜 이걸 배우나요?¶

지금까지 배운 파이썬 문법과 라이브러리 지식이 모두 의미 있는 이유는 실제 문제를 해결하기 위함입니다.

상상해봅시다. 요리사는 레시피를 알고 있어도, 실제 요리를 할 때는 재료 준비 → 밑작업 → 익히기 → 맛 확인 → 플레이팅 순서대로 진행하며 중간중간 맛을 봅니다. 프로그래밍도 정확히 같습니다.

이 장에서는 설계 → 핵심 기능 구현 → 테스트 → 개선이라는 실무의 흐름을 경험합니다. 버그를 만나는 것도, 그것을 고치는 경험도 모두 개발자가 되기 위한 필수 과정입니다.

📚 핵심 개념¶

개념 1: 기획서 → 구현의 사이클¶

비유: 집을 지을 때 건축 설계도가 있어야 벽돌을 쌓을 수 있습니다. 프로그래밍도 마찬가지입니다.

정확한 정의: 프로젝트 구현이란 기획 단계에서 정의한 요구사항을 작은 단위로 나누어, 하나씩 코드로 표현하는 과정입니다.

흐름도:

graph LR A["📋 기획서 작성<br/>기능 정의"] --> B["🔨 핵심 기능<br/>구현"] B --> C["🧪 테스트<br/>& 디버깅"] C --> D["✨ 코드 개선<br/>& 추가 기능"] D -->|반복| B

예시: '간단한 성적 관리 프로그램'을 만든다면 - 기획: 학생명, 점수 저장 → 평균 계산 → 등급 판정 - 1단계 구현: 입력받은 점수 저장 함수 - 1단계 테스트: 실제로 데이터가 저장되는가? - 2단계 구현: 평균 계산 함수 - 2단계 테스트: 계산이 올바른가?

개념 2: 함수로 기능 분리하기¶

비유: 복잡한 문제를 한꺼번에 풀지 말고, 단계적으로 나누어 푸는 것처럼, 코드도 기능별로 함수로 나눕니다.

정의: 하나의 함수는 하나의 일만 잘하도록 설계해야 유지보수와 테스트가 쉬워집니다.

좋은 함수 vs 나쁜 함수:

개념 3: 작게 만들고 자주 테스트하기¶

원칙: 한 번에 10줄을 작성하고 실행해서 오류를 바로 잡는 게, 100줄을 작성하고 나중에 디버깅하는 것보다 훨씬 빠릅니다.

개념 4: 오류 메시지는 최고의 선생님¶

정의: 파이썬의 오류 메시지는 어디서 무엇이 잘못됐는지 알려주는 선물입니다.

오류 읽는 법:

>>> scores = [90, 85, 95]
>>> average = sum(scores) / len(scores)
>>> print(f"평균: {avarage}")  # 오타!

NameError: name 'avarage' is not defined

오류 메시지가 말하는 것: "avarage라는 이름의 변수가 없어요. 9번째 줄을 확인하세요."

Step 2: 핵심 함수 골격 만들기¶

# book_manager.py - 프로젝트의 첫 번째 버전

books = []  # 전체 책 정보를 저장할 리스트

def add_book(title, author, pages, rating):
    """새로운 책을 리스트에 추가하는 함수"""
    book = {
        "title": title,
        "author": author,
        "pages": pages,
        "rating": rating
    }
    books.append(book)
    print(f"✅ '{title}' 책이 추가되었습니다!")

def show_books():
    """저장된 모든 책을 출력하는 함수"""
    if not books:
        print("📚 저장된 책이 없습니다.")
        return

    for i, book in enumerate(books, 1):
        print(f"{i}. {book['title']} / {book['author']} ({book['rating']}⭐)")

def get_average_rating():
    """모든 책의 평균 평점을 계산하는 함수"""
    if not books:
        return 0
    total = sum(book['rating'] for book in books)
    return total / len(books)

def find_book(title):
    """제목으로 책을 검색하는 함수"""
    for book in books:
        if book['title'] == title:
            return book
    return None

Step 4: 입력 검증 함수 추가하기¶

프로그램이 잘못된 데이터를 받으면 어떻게 될까요? 일찍 오류를 발견하는 함수를 만들어봅시다.

def validate_input(title, author, pages, rating):
    """입력값이 유효한지 확인하는 함수"""
    if not title or not author:
        print("❌ 제목과 저자는 필수입니다!")
        return False

    if not isinstance(pages, int) or pages <= 0:
        print("❌ 쪽수는 양수여야 합니다!")
        return False

    if not (1 <= rating <= 5):
        print("❌ 평점은 1~5 사이여야 합니다!")
        return False

    return True

# 개선된 add_book 함수
def add_book(title, author, pages, rating):
    if not validate_input(title, author, pages, rating):
        return  # 유효하지 않으면 함수 종료

    book = {
        "title": title,
        "author": author,
        "pages": pages,
        "rating": rating
    }
    books.append(book)
    print(f"✅ '{title}' 책이 추가되었습니다!")

📝 전체 코드¶

# book_manager.py - 최종 버전 (Step 1~6 통합)

books = []

def validate_input(title, author, pages, rating):
    """입력값 검증"""
    if not title or not author:
        print("❌ 제목과 저자는 필수입니다!")
        return False
    if not isinstance(pages, int) or pages <= 0:
        print("❌ 쪽수는 양수여야 합니다!")
        return False
    if not (1 <= rating <= 5):
        print("❌ 평점은 1~5 사이여야 합니다!")
        return False
    return True

def add_book(title, author, pages, rating):
    """새 책 추가"""
    if not validate_input(title, author, pages, rating):
        return
    book = {"title": title, "author": author, "pages": pages, "rating": rating}
    books.append(book)
    print(f"✅ '{title}' 책이 추가되었습니다!")

def show_books():
    """책 목록 표시"""
    if not books:
        print("📚 저장된 책이 없습니다.")
        return
    for i, book in enumerate(books, 1):
        print(f"{i}. {book['title']} / {book['author']} ({book['rating']}⭐)")

def get_average_rating():
    """평균 평점 계산"""
    return sum(b['rating'] for b in books) / len(books) if books else 0

def find_book(title):
    """책 검색"""
    return next((b for b in books if b['title'] == title), None)

# 프로그램 실행
if __name__ == "__main__":
    add_book("파이썬 기초", "홍길동", 350, 4.5)
    add_book("데이터 분석", "김영희", 420, 4.8)
    show_books()
    print(f"평균 평점: {get_average_rating():.2f}⭐")

실시 3: 빈 리스트에서 평균 계산하기¶

# ❌ 위험한 코드
def get_average_rating():
    return sum(b['rating'] for b in books) / len(books)
    # books가 비어있으면 ZeroDivisionError!

# ✅ 안전한 코드
def get_average_rating():
    return sum(b['rating'] for b in books) / len(books) if books else 0
    # 비어있으면 0 반환

해결: 경계 조건(edge case)을 항상 생각하세요. 빈 리스트, None, 음수 등.
