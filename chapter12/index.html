🎮 미니 프로젝트: 텍스트 어드벤처 게임¶

Part 3: [1권] Part 3. 갈림길에서 선택하기, 조건문

🎯 이 장에서 배우는 것¶

  • 조건문을 연결하여 여러 갈림길을 구현할 수 있다
  • 사용자 입력에 따라 다른 스토리로 분기하는 게임을 만들 수 있다
  • 변수, 입출력, 조건문을 종합적으로 활용하여 프로젝트를 완성할 수 있다
  • 게임 로직을 단계별로 설계하고 테스트할 수 있다

💡 왜 이걸 배우나요?¶

지금까지 배운 기능들을 따로따로 사용했다면, 이제 함께 사용할 차례입니다. 텍스트 어드벤처 게임은 '프로그래밍으로 이야기를 만드는' 경험이에요.

게임처럼 보이지만, 알고 보면 변수(등장인물의 상태) → 입출력(플레이어 선택) → 조건문(분기)의 조합일 뿐입니다. 이 구조는 게임뿐 아니라 앱, 웹사이트, 모든 대화형 프로그램의 기초입니다. 당신이 만드는 작은 게임이 큰 소프트웨어의 첫 걸음이 되는 거죠. 🚀

📚 핵심 개념¶

개념 1: 분기 구조 (Branching Flow)¶

비유: 숲속의 갈림길을 생각해봐요. 왼쪽으로 가면 성에 도달하고, 오른쪽으로 가면 숨겨진 보물을 찾아요. 길을 고르는 순간, 이야기가 완전히 달라집니다.

정의: 프로그램이 여러 경로 중 하나를 선택하여 진행하는 것. if-elif-else 조건문을 중첩하거나 연결하여 만듭니다.

예시:

# 간단한 분기 구조
print("깊은 숲에서 길을 잃었다.")
print("1: 왼쪽 길로 간다")
print("2: 오른쪽 길로 간다")

choice = input("선택: ")

if choice == "1":
    print("→ 성이 나타났다! 왕이 나를 반겨준다.")
elif choice == "2":
    print("→ 보물 상자를 발견했다! 게임 클리어!")
else:
    print("→ 정해지지 않은 길은 없다...")

개념 2: 게임 상태 관리¶

정의: 게임이 진행되면서 바뀌는 정보(캐릭터의 체력, 소유한 아이템, 방문한 장소)를 변수로 추적하는 것.

# 게임 상태를 변수로 관리
health = 100  # 체력
items = []    # 가진 아이템 목록
location = "숲"  # 현재 위치

# 선택에 따라 상태가 바뀐다
if choice == "1":
    health -= 10  # 체력 감소
    items.append("열쇠")  # 아이템 획득
    location = "성"  # 위치 변경

개념 3: 중첩된 조건문 (Nested If)¶

정의: 조건문 안에 또 다른 조건문을 넣는 것. 게임의 깊이를 만들어요.

# 성에 도착했을 때
if location == "성":
    print("성 앞에 수호자가 서 있다.")
    print("1: 싸운다 / 2: 말을 건넨다")

    action = input("선택: ")

    if action == "1":
        print("→ 싸워서 이겼다!")
    else:  # action == "2"
        print("→ 수호자가 길을 열어준다.")

📝 전체 코드¶

아래는 3개의 선택지와 여러 결말을 포함한 완성된 게임입니다. 복사해서 바로 실행하세요!

# 냥이와 멍이의 모험 - 최종 버전
print("=" * 60)
print("🎮 냥이와 멍이의 모험 - 신비의 섬")
print("=" * 60)
print()

# 게임 상태
score = 0
inventory = []
ending = ""

print("당신은 냥이와 멍이를 데리고 신비로운 섬에 도착했다.")
print("이곳에는 무언가 특별한 것이 있다는 전설이 있다.")
print()
print("1️⃣ : 해변 방향으로 간다")
print("2️⃣ : 산 방향으로 간다")
print("3️⃣ : 숲 방향으로 간다")
print()

first_choice = input("🗺️  어디로 갈까? (1, 2, 3): ")
print()

# ===== 첫 번째 분기 =====
if first_choice == "1":
    print("🏖️ 해변으로 향했다...")
    print("하얀 모래사장에서 반짝이는 유리 병을 발견했다!")
    inventory.append("신비의 병")
    score += 10
    print()
    print("병을 열어볼까?")
    print("1️⃣ : 열어본다")
    print("2️⃣ : 가져만 간다")

    second_choice = input("선택: ")

    if second_choice == "1":
        print("✨ 요정이 나타났다!")
        print("1️⃣ : 소원을 빈다")
        print("2️⃣ : 그냥 놔둔다")
        final_choice = input("선택: ")
        if final_choice == "1":
            print("🎉 소원이 이루어졌다!")
            score += 100
            ending = "해피 엔딩 (해변)"
        else:
            print("요정은 하늘로 사라졌다.")
            score += 30
            ending = "평범한 엔딩 (해변)"
    else:
        print("보물처럼 소중히 가져간다.")
        score += 20
        ending = "신비로운 엔딩 (해변)"

elif first_choice == "2":
    print("⛰️ 산으로 향했다...")
    print("산 위에는 오래된 사당이 있었다.")
    score += 15
    print()
    print("사당에 들어갈까?")
    print("1️⃣ : 들어간다")
    print("2️⃣ : 그냥 내려온다")

    second_choice = input("선택: ")

    if second_choice == "1":
        print("🏯 사당 안에 금색 조각상이 있다!")
        inventory.append("금조각상")
        print("1️⃣ : 가져간다")
        print("2️⃣ : 놔두고 나온다")
        final_choice = input("선택: ")
        if final_choice == "1":
            print("💰 부자가 되었다!")
            score += 120
            ending = "해피 엔딩 (산)"
        else:
            print("조각상은 제자리에 있다.")
            score += 40
            ending = "도덕적 엔딩 (산)")
    else:
        print("나쁜 예감이 든다...")
        score += 5
        ending = "불안한 엔딩 (산)")

elif first_choice == "3":
    print("🌲 숲으로 향했다...")
    print("숲속 깊은 곳에서 반딧불이들이 춤을 춘다!")
    score += 25
    print()
    print("반딧불이를 따라갈까?")
    print("1️⃣ : 따라간다")
    print("2️⃣ : 반대 방향으로 간다")

    second_choice = input("선택: ")

    if second_choice == "1":
        print("🌟 숨겨진 마법의 숲에 도착했다!")
        inventory.append("마법의 씨앗")
        print("1️⃣ : 씨앗을 심는다")
        print("2️⃣ : 씨앗을 가져간다")
        final_choice = input("선택: ")
        if final_choice == "1":
            print("🌳 신비한 나무가 자라났다!")
            score += 110
            ending = "자연 조화 엔딩 (숲)"
        else:
            print("씨앗의 가치를 알게 된다.")
            score += 60
            ending = "지혜로운 엔딩 (숲)")
    else:
        print("숲을 빠져나왔다.")
        score += 35
        ending = "탈출 엔딩 (숲)")

else:
    print("❌ 올바른 선택을 해주세요!")
    ending = "게임 오버"

print()

⚠️ 자주 하는 실수¶

실수 1: 문자열 비교 실수¶

# ❌ 잘못된 예
choice = input("1 또는 2: ")
if choice = "1":  # = 는 대입, == 는 비교!
    print("선택됨")

# ✅ 올바른 예
if choice == "1":
    print("선택됨")

💡 TIP: 비교할 때는 항상 ==를 사용하세요!

실수 2: 들여쓰기 누락¶

# ❌ 잘못된 예
if choice == "1":
print("선택됨")  # 들여쓰기 없음 - 에러!

# ✅ 올바른 예
if choice == "1":
    print("선택됨")  # 들여쓰기 필수

💡 TIP: if 다음의 코드는 반드시 4칸 들여쓰기!

실수 3: 변수를 문자열로 만들기¶

# ❌ 잘못된 예
score = 0
score = "0"  # 숫자가 아니라 문자가 됨
score = score + 10  # TypeError 발생!

# ✅ 올바른 예
score = 0
score = score + 10  # 정상 작동
print(f"점수: {score}")  # 10

💡 TIP: 계산할 값은 문자가 아니라 숫자(int)로 선언하세요!

✅ 스스로 점검하기¶

다음 질문에 답할 수 있나요?

1. 기본 - [ ] if, elif, else의 차이를 설명할 수 있다 - [ ] 조건문 안에 조건문을 넣을 수 있다 (중첩) - [ ] 게임 상태를 변수로 관리하는 이유를 안다

2. 실습 - [ ] 2개 이상의 분기가 있는 게임을 만들 수 있다 - [ ] 사용자 입력값을 여러 번 받을 수 있다 - [ ] 게임의 결과를 점수나 아이템으로 표현할 수 있다

3. 심화 - [ ] 3단계 이상의 깊은 분기(중첩)를 만들 수 있다 - [ ] 자신의 스토리로 게임을 수정할 수 있다 - [ ] 게임의 흐름도를 그릴 수 있다

🚀 더 해보기¶

도전 1️⃣: 자신의 스토리 만들기¶

위 게임의 스토리와 선택지를 당신의 것으로 바꿔보세요. 예: - 배경: 신비의 섬 → 미래도시, 마법학교, 해적선 등 - 등장인물: 냥이와 멍이 → 당신이 만든 캐릭터 - 아이템: 보물, 왕관 → 당신의 창의적인 아이템

Part 4: 반복해서 효율적으로, 반복문으로 나아갑니다.

지금까지 우리는 각 선택을 한 번씩만 처리했어요. 하지만 게임이 커지면? 같은 질문을 여러 번 해야 하고, 같은 코드를 계속 반복해야 합니다.

다음 장에서 배울 for와 while 반복문을 사용하면: - 플레이어가 틀린 입력을 할 때마다 다시 물을 수 있어요 - 여러 아이템을 한 번에 처리할 수 있어요 - 게임을 무한정 진행할 수도 있어요 (예: 던전 깊숙이 내려가기)
