    Chapter 28. 프로젝트 기획: 무엇을 만들까?¶

    🎯 이 장에서 배우는 것¶

    • 자신의 관심사에 맞는 프로젝트 주제를 선택할 수 있다
    • 필요한 기능을 목록으로 정리하고 우선순위를 정할 수 있다
    • 간단한 프로젝트 기획서를 작성할 수 있다

    📚 핵심 개념¶

    개념 1️⃣: 프로젝트 스코프 (Scope) 정하기¶

    프로젝트 스코프는 마치 요리 전에 레시피를 정하는 것과 같아요.

    무엇을 만들지, 언제까지 만들지, 어디까지 만들지를 명확히 정하지 않으면 중간에 헤맬 수 있습니다.

    # ❌ 스코프가 불명확한 경우
# "게임을 만들겠습니다"

# ✅ 스코프가 명확한 경우
# "2주 안에 숫자 맞히기 게임을 만든다.
#  - 컴퓨터가 1~100 사이의 숫자를 정한다
#  - 사용자가 숫자를 맞힌다
#  - 시도 횟수를 표시한다"

    스코프가 명확하면: - 🎯 목표가 흔들리지 않음 - ⏱️ 예상 시간을 세울 수 있음 - ✨ 완성도를 높일 수 있음

    개념 2️⃣: 기능 우선순위 정하기 (MoSCoW 방법)¶

    기능을 우선순위로 분류하는 것은 마치 번거운 짐을 챙기기 전에 꼭 필요한 것부터 고르는 것과 같아요.

    Must (필수) → Should (중요) → Could (추가) → Won't (나중에)

    # 📱 일정 관리 앱의 경우

# ✨ Must (필수 기능)
# - 일정을 입력할 수 있어야 함
# - 일정 목록을 볼 수 있어야 함

# 🌟 Should (중요 기능)
# - 일정을 삭제할 수 있음
# - 완료 표시를 할 수 있음

# 💡 Could (추가하면 좋음)
# - 일정을 검색할 수 있음
# - 날짜별로 정렬할 수 있음

# ⏳ Won't (지금은 안 함)
# - 스마트폰 앱으로 만들기
# - 다른 사람과 공유하기

    🔨 따라하기: 나만의 프로젝트 기획서 작성하기¶

    Step 1️⃣: 프로젝트 주제 선택하기¶

    관심 있는 분야를 3가지 선택하세요:

    # 📝 선택 예시

# 추천 주제들:
project_ideas = {
    "게임": "숫자 맞히기, 가위바위보, 미니 RPG",
    "도구": "일정 관리, 계산기, 할일 목록",
    "테스트": "성격 테스트, 심리 테스트, 재미있는 퀴즈",
    "분석": "설문조사 분석, 통계 계산, 성적 분석",
    "생활": "가계부, 영어 단어 외우기, 공부 타이머"
}

# ✅ 당신의 선택
my_choice = "숫자 맞히기 게임"  # 예시

    선택 기준: - 🎨 내가 재미있다고 느껴야 함 - 📚 배운 개념으로 충분히 만들 수 있음 - ⏱️ 50분~2주 안에 완성할 수 있음

    Step 2️⃣: 프로젝트 한 문장 정의하기¶

    # 😊 명확하고 구체적으로 표현하세요

my_project = """
사용자가 1~100 사이의 숫자를 맞히는 게임을 만든다.
컴퓨터가 정한 숫자보다 큰지 작은지 알려주고, 
맞힐 때까지 시도 횟수를 세어준다.
"""

# ✨ 더 구체적으로:
# - 게임 규칙은 뭔가?
# - 사용자는 누가 사용할 건가?
# - 언제까지 완성해야 하나?

    Step 3️⃣: 필수 기능 나열하기¶

    # 🎯 꼭 필요한 기능만 정리하세요

must_have_features = [
    "① 1~100 사이 난수 생성",
    "② 사용자 입력받기",
    "③ 입력 값과 정답 비교",
    "④ 시도 횟수 세기",
    "⑤ 정답 시 종료"
]

# 처음부터 다 만들 필요 없습니다.
# 필수 기능만 완성하는 게 목표입니다!

    Step 4️⃣: 추가 기능 생각해보기¶

    # 💡 나중에 추가할 기능들

nice_to_have_features = [
    "□ 힌트 기능 (5번 틀렸을 때 ±5 범위 알려주기)",
    "□ 난이도 선택 (쉬움: 1~50, 어려움: 1~1000)",
    "□ 전적 기록 (이전 게임 기록 저장)",
    "□ 최고기록 보여주기"
]

# 👉 필수 기능부터 완성한 후
#    시간이 남으면 추가하세요!

    Step 5️⃣: 필요한 파이썬 개념 정리하기¶

    # 🛠️ 이 프로젝트에 필요한 개념들

required_concepts = {
    "문법": ["if/else", "while 반복", "변수"],
    "함수": ["input()", "print()", "random.randint()"],
    "라이브러리": ["random 모듈"],
    "추가": ["문자열 처리"]
}

# ✅ 체크리스트
concepts_checklist = """
□ 변수와 자료형 - 이미 배웠나요? YES
□ if/else - 이미 배웠나요? YES
□ while 반복 - 이미 배웠나요? YES
□ random 모듈 - 이미 배웠나요? (배우면 됨)
"""

    ✅ 점검하기¶

    1. 내가 선택한 주제를 한 문장으로 설명할 수 있는가?

    정답 확인 "숫자 맞히기 게임을 만든다. 컴퓨터가 정한 1~100 사이 숫자를 사용자가 맞히고, 시도 횟수를 센다." 처럼 구체적으로 설명할 수 있으면 됩니다!

    2. 필수 기능 3개 이상을 나열할 수 있는가?

    정답 확인 게임 규칙에 맞는 필수 기능이면 됩니다. 예: "입력받기, 비교하기, 횟수 세기" 등

    3. 이 프로젝트에 필요한 파이썬 개념 2개를 말할 수 있는가?

    정답 확인 "if/else로 입력값을 비교하고, while로 게임을 반복한다" 같이 연결할 수 있으면 완벽합니다!
