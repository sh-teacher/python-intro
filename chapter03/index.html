    Hello, World! 나의 첫 파이썬 코드¶

    🎯 이 장에서 배우는 것¶

    • print() 함수로 화면에 텍스트를 출력할 수 있다
    • 오류가 발생했을 때 메시지를 읽고 대처할 수 있다
    • 주석(#)으로 코드에 설명을 남길 수 있다

    📚 핵심 개념¶

    개념 1️⃣: print() 함수는 "확성기"¶

    비유로 시작: print 함수는 마치 확성기와 같아요. 괄호 안에 무엇을 넣으면, 파이썬이 그것을 화면에 크게 외쳐줍니다!

    정확한 정의: print()는 컴퓨터가 우리에게 정보를 전달하는 가장 기본적인 방법입니다. 괄호 안에 우리가 보고 싶은 것을 넣으면, 그것이 화면에 나타납니다.

    예시로 확인: 

    print("안녕하세요!")
    실행 결과: 
    안녕하세요!

    그냥 텍스트를 입력하는 것이 아니라, print()라는 함수를 통해 명령을 내리는 거죠!

    개념 2️⃣: 따옴표의 중요성¶

    비유로 시작: 따옴표는 마치 편지의 봉투와 같아요. 따옴표 안에만 텍스트가 있어야 파이썬이 "아, 이건 출력할 문장이구나"라고 인식합니다.

    정확한 정의: - 큰따옴표: "Hello" - 작은따옴표: 'Hello' - 둘 다 같은 역할을 합니다 (혼용하지만 않으면 됨!)

    예시로 확인: 

    print("Hello, World!")    # 큰따옴표 사용
print('Hello, World!')    # 작은따옴표 사용 (똑같이 작동!)

    🔨 따라하기¶

    Step 1: 첫 번째 코드 실행하기¶

    코드: 

    print("Hello, World!")

    실행 결과: 

    Hello, World!

    파일을 저장하고 실행하면(또는 IDLE에서 바로 실행하면) 화면에 "Hello, World!"가 나타납니다. 축하합니다! 🎉

    Step 2: 여러 문장 출력하기¶

    코드: 

    print("안녕하세요!")
print("저는 파이썬 학습자입니다.")
print("코딩이 재미있어요!")

    실행 결과: 

    안녕하세요!
저는 파이썬 학습자입니다.
코딩이 재미있어요!

    각 print()는 새로운 줄에 출력됩니다. 줄 바꿈이 자동으로 일어나요!

    Step 3: 의도적으로 오류 만들기 (배우기)¶

    처음엔 오류가 무섭지만, 오류를 이해하는 것이 프로그래머의 능력입니다!

    잘못된 코드 (따옴표 빠짐): 

    print(Hello, World!)  # ❌ 오류 발생

    오류 메시지: 

    NameError: name 'Hello' is not defined

    해석: "안녕하세요. Hello라는 변수를 정의하지 않았는데요?" → 따옴표를 빼먹었다는 뜻입니다!

    올바른 코드: 

    print("Hello, World!")  # ✅ 따옴표 추가

    Step 4: 주석(#)으로 설명 남기기¶

    코드: 

    # 이것은 주석입니다. 파이썬이 실행하지 않습니다.
print("Hello, World!")  # 화면에 인사말을 출력합니다

# 여러 줄의 설명도 가능합니다
# 각 줄마다 #를 붙여야 합니다
print("코딩을 배워봅시다!")

    실행 결과: 

    Hello, World!
코딩을 배워봅시다!

    주석은 코드 설명이나 메모를 남길 때 사용합니다. 파이썬이 실행하지 않습니다.

    Step 5: 자기소개 출력하기¶

    코드: 

    # 나의 첫 파이썬 자기소개 프로그램
print("안녕하세요!")
print("제 이름은 김멍이입니다.")
print("저는 파이썬 공부를 시작했습니다.")
print("반갑습니다!")

    실행 결과: 

    안녕하세요!
제 이름은 김멍이입니다.
저는 파이썬 공부를 시작했습니다.
반갑습니다!

    📝 전체 코드¶

    # ============================================
# Hello, World! - 첫 파이썬 프로그램
# ============================================

# 인사말 출력
print("Hello, World!")

# 자기소개
print("안녕하세요!")
print("저는 파이썬 학습자입니다.")

# 마지막 인사
print("코딩을 시작해봅시다!")

    ⚠️ 주의할 점¶

    1️⃣ 따옴표를 반드시 닫기

    print("Hello")    # ✅ 올바름 (따옴표 쌍 맞춤)
print("Hello      # ❌ 오류 (따옴표 닫지 않음)

    2️⃣ 괄호 쌍 맞추기

    print("Hello")    # ✅ 올바름 (괄호 쌍 맞춤)
print("Hello"     # ❌ 오류 (닫는 괄호 빠짐)

    ✅ 점검하기¶

    1. 다음 코드를 실행하면 어떤 결과가 나올까요? 

    print("파이썬")
print("재미있어요")

    정답 확인 
    파이썬
재미있어요
    각 print()는 새로운 줄에 출력됩니다.

    2. 다음 오류가 발생했을 때 무엇이 잘못되었을까요? 

    print(Hello)
# NameError: name 'Hello' is not defined

    정답 확인 따옴표를 빼먹었습니다! 올바른 코드: 
    print("Hello")

    3. 주석(#)은 어떤 역할을 할까요?

    정답 확인 코드에 메모나 설명을 남기는 역할입니다. 파이썬이 실행하지 않으므로, 우리가 나중에 코드를 이해하기 쉽도록 도와줍니다.

    🔗 다음 장 미리보기¶

    다음 장에서는 변수(Variable)를 배웁니다. 변수는 데이터를 담는 "상자"처럼 작동합니다.

    예를 들어: 

    name = "멍이"
print(name)

    한 번의 print()로 여러 번 다양한 정보를 출력할 수 있게 돼요! 🚀
