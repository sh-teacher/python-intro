Chapter 23: 함수 활용: 코드를 깔끔하게 정리하자¶

📚 핵심 개념¶

개념 1️⃣: 함수로 프로그램을 레고 블록처럼 조합하기¶

함수는 마치 레고 블록과 같습니다. 작은 블록 여러 개를 조합하면 큰 성을 만들 수 있듯이, 작은 함수 여러 개를 조합하면 복잡한 프로그램을 깔끔하게 만들 수 있어요.

왜 함수로 나눌까?

# ❌ 함수 없이 짜면: 코드가 길고, 같은 코드가 반복됨
score = int(input("점수: "))
if score >= 90:
    print("A등급")
elif score >= 80:
    print("B등급")
else:
    print("C등급")

score2 = int(input("점수: "))
if score2 >= 90:
    print("A등급")
elif score2 >= 80:
    print("B등급")
else:
    print("C등급")

# ✅ 함수로 나누면: 깔끔하고 재사용 가능
def get_grade(score):
    if score >= 90:
        return "A등급"
    elif score >= 80:
        return "B등급"
    else:
        return "C등급"

score1 = int(input("학생1 점수: "))
print(get_grade(score1))

score2 = int(input("학생2 점수: "))
print(get_grade(score2))

이렇게 함수로 구분하면: - 🔹 코드가 짧아진다 - 🔹 수정할 때 한 곳만 바꾸면 된다 - 🔹 코드를 이해하기 쉬워진다

개념 2️⃣: 지역 변수 vs 전역 변수 (변수의 범위 scope)¶

변수에도 사용 가능한 범위(scope)가 있어요. 마치 편지가 "그 사무실 안에서만 유효"하듯이요.

# 전역 변수: 함수 밖에서 선언 (모든 함수가 사용 가능)
game_title = "숫자 맞추기"

def game_start():
    # 지역 변수: 함수 안에서만 사용 가능
    secret_number = 42
    print(f"{game_title}: {secret_number} 입니다")
    # ✅ game_title 사용 가능 (전역)
    # ✅ secret_number 사용 가능 (지역)

def game_end():
    print(f"{game_title} 종료")
    # ✅ game_title 사용 가능 (전역)
    # ❌ secret_number 사용 불가 (game_start의 지역변수)

game_start()  # 실행 결과: 숫자 맞추기: 42 입니다
game_end()    # 실행 결과: 숫자 맞추기 종료

비유로 이해하기: - 전역 변수: 학교 전체에 알려진 규칙 (모든 교실에서 따름) - 지역 변수: 한 교실만의 규칙 (다른 교실에선 모름)

graph TB A["전역 변수<br/>game_title"] -->|사용 가능| B["함수: game_start"] A -->|사용 가능| C["함수: game_end"] B -->|생성| D["지역 변수<br/>secret_number"] D -->|오직 B에서만<br/>사용 가능| B D -->|C에서는<br/>불가| C

🔨 따라하기: 간단한 계산 프로그램 리팩토링¶

Step 1: 처음 코드 (함수 없이)¶

# 두 수를 더하기
num1 = int(input("첫 번째 수: "))
num2 = int(input("두 번째 수: "))
result = num1 + num2
print(f"더하기: {result}")

# 두 수를 빼기
num1 = int(input("첫 번째 수: "))
num2 = int(input("두 번째 수: "))
result = num1 - num2
print(f"빼기: {result}")

# 두 수를 곱하기
num1 = int(input("첫 번째 수: "))
num2 = int(input("두 번째 수: "))
result = num1 * num2
print(f"곱하기: {result}")

문제점: 같은 코드가 3번 반복됨 😫

Step 2: 함수로 리팩토링하기¶

def get_numbers():
    """두 수를 입력받는 함수"""
    num1 = int(input("첫 번째 수: "))
    num2 = int(input("두 번째 수: "))
    return num1, num2

def add(a, b):
    """더하기"""
    return a + b

def subtract(a, b):
    """빼기"""
    return a - b

def multiply(a, b):
    """곱하기"""
    return a * b

# 메인 프로그램
num1, num2 = get_numbers()
print(f"더하기: {add(num1, num2)}")

num1, num2 = get_numbers()
print(f"빼기: {subtract(num1, num2)}")

num1, num2 = get_numbers()
print(f"곱하기: {multiply(num1, num2)}")

개선된 점: - ✅ 입력 받는 로직이 한 곳에만 있음 - ✅ 각 함수가 하나의 일만 함 - ✅ 새로운 연산을 추가하기 쉬움

Step 3: 한 단계 더 나아가기 (함수 조합)¶

def get_numbers():
    num1 = int(input("첫 번째 수: "))
    num2 = int(input("두 번째 수: "))
    return num1, num2

def perform_operation(operation_name, result):
    """연산 결과를 깔끔하게 출력"""
    print(f"{operation_name}: {result}")

# 메인 프로그램
num1, num2 = get_numbers()
perform_operation("더하기", num1 + num2)

num1, num2 = get_numbers()
perform_operation("빼기", num1 - num2)

num1, num2 = get_numbers()
perform_operation("곱하기", num1 * num2)

실행 결과:

두 번째 수: 5

첫 번째 수: 10
두 번째 수: 5
빼기: 5
첫 번째 수: 10
두 번째 수: 5
곱하기: 50

📝 전체 코드: 계산기 프로그램 완성본¶

# 계산기 프로그램: 함수로 구조화된 버전

def get_numbers():
    """사용자로부터 두 수를 입력받음"""
    num1 = int(input("첫 번째 수: "))
    num2 = int(input("두 번째 수: "))
    return num1, num2

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "0으로 나눌 수 없습니다"
    return a / b

def perform_calculation(op_name, operation, num1, num2):
    """계산을 수행하고 결과를 출력"""
    result = operation(num1, num2)
    print(f"{op_name}: {result}")

# 메인 프로그램 (프로그램의 흐름이 한눈에 보임)
print("=== 계산기 ===")

num1, num2 = get_numbers()
perform_calculation("더하기", add, num1, num2)
perform_calculation("빼기", subtract, num1, num2)
perform_calculation("곱하기", multiply, num1, num2)
perform_calculation("나누기", divide, num1, num2)

⚠️ 주의할 점¶

🔴 주의 1: 전역 변수 남용하지 않기¶

# ❌ 나쁜 예: 전역 변수를 함수 안에서 수정
total = 0

def add_score(score):
    global total  # 이렇게 하면 코드가 복잡해짐
    total = total + score

# ✅ 좋은 예: 함수가 값을 반환하고 받아서 사용
def add_score(current_total, score):
    return current_total + score

total = 0
total = add_score(total, 10)

💡 팁: 가능하면 함수는 값을 받아서 새로운 값을 반환하도록 만들기!

🔴 주의 2: 함수가 너무 많은 일을 하지 않기¶

# ❌ 나쁜 예: 함수가 여러 일을 동시에
def process_student(name, score):
    # 등급 판정
    if score >= 90:
        grade = "A"
    else:
        grade = "B"
    # 파일에 저장
    with open("result.txt", "a") as f:
        f.write(f"{name}: {grade}\n")
    # 출력
    print(f"{name}의 등급: {grade}")

# ✅ 좋은 예: 함수가 하나의 일만
def get_grade(score):
    return "A" if score >= 90 else "B"

grade = get_grade(85)
print(f"등급: {grade}")

✅ 점검하기¶

1. 다음 코드의 실행 결과는?

x = 10  # 전역 변수

def modify_x():
    x = 20  # 지역 변수
    print(f"함수 안: {x}")

modify_x()
print(f"함수 밖: {x}")
정답 확인 
함수 안: 20
함수 밖: 10
**설명**: 함수 안의 `x = 20`은 지역 변수를 만드는 것이지, 전역 변수를 수정하는 게 아닙니다. 따라서 함수 밖의 x는 여전히 10입니다.

2. 아래 코드의 문제점은?

def calculate():
    a = int(input("수1: "))
    b = int(input("수2: "))
    result = a + b

    c = a * b
    d = a - b

    print(result)
    print(c)
    print(d)

calculate()
정답 확인 함수가 **여러 계산을 동시에 수행**하고 있습니다. 다음과 같이 나누는 것이 좋습니다: 
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

def subtract(a, b):
    return a - b

a = int(input("수1: "))
b = int(input("수2: "))
print(add(a, b))
print(multiply(a, b))
print(subtract(a, b))
각 함수가 **하나의 책임**만 가지도록 분리합니다.

3. 다음 코드를 함수로 리팩토링하세요

# 사용자로부터 3개의 점수를 입력받아 평균을 출력
score1 = int(input("점수1: "))
score2 = int(input("점수2: "))
score3 = int(input("점수3: "))
average = (score1 + score2 + score3) / 3
print(f"평균: {average}")
정답 확인 
def get_scores():
    """3개의 점수를 입력받음"""
    score1 = int(input("점수1: "))
    score2 = int(input("점수2: "))
    score3 = int(input("점수3: "))
    return score1, score2, score3

def calculate_average(s1, s2, s3):
    """평균을 계산"""
    return (s1 + s2 + s3) / 3

def print_result(avg):
    """결과를 출력"""
    print(f"평균: {avg}")

# 메인 프로그램
s1, s2, s3 = get_scores()
avg = calculate_average(s1, s2, s3)
print_result(avg)
**더 간단한 버전:** 
def get_average():
    scores = [int(input(f"점수{i+1}: ")) for i in range(3)]
    return sum(scores) / 3

print(f"평균: {get_average()}")
