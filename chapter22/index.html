Chapter 22. 매개변수와 반환값: 함수에 주고받기¶

🎯 이 장에서 배우는 것¶

  • 매개변수로 함수에 데이터를 전달할 수 있다
  • return 키워드로 함수의 결과를 반환할 수 있다
  • 기본값 매개변수를 사용해 유연한 함수를 만들 수 있다

📚 핵심 개념¶

개념 1: 매개변수 (Parameter)¶

비유: 매개변수는 마치 자판기에 넣는 동전이에요. 동전이 없으면 음료가 나올 수 없죠?

함수도 마찬가지입니다. 함수에 데이터를 전달해야 할 때 괄호 안에 변수를 선언하는데, 이것이 매개변수입니다.

함수 정의:  def greet(name):         ← name이 매개변수
함수 호출:  greet("철수")            ← "철수"가 인자(argument)

예시로 확인:

# name이라는 매개변수를 받는 함수
def greet(name):
    print(f"안녕하세요, {name}님!")

# "민지"라는 인자를 전달
greet("민지")  # 안녕하세요, 민지님!
greet("철수")  # 안녕하세요, 철수님!

여러 개의 매개변수도 받을 수 있습니다:

def add(a, b):  # a, b 두 개의 매개변수
    print(f"{a} + {b} = {a + b}")

add(5, 3)  # 5 + 3 = 8

개념 2: 반환값 (Return Value)¶

비유: 반환값은 자판기에서 나오는 음료예요. 함수가 처리한 결과를 우리에게 돌려주는 것입니다.

return 키워드를 사용하면 함수의 계산 결과를 호출한 곳으로 보낼 수 있습니다.

# return 없는 경우
def greet(name):
    print(f"안녕하세요, {name}님!")

result = greet("민지")  # None이 저장됨
print(result)  # None


# return 있는 경우
def greet_with_return(name):
    message = f"안녕하세요, {name}님!"
    return message  # 문자열을 돌려줌

result = greet_with_return("민지")
print(result)  # 안녕하세요, 민지님!

핵심 차이: - print(): 화면에 출력하기만 함 - return: 함수 밖에서 사용할 수 있는 값으로 변환

🔨 따라하기¶

Step 1: 간단한 함수부터 시작 - 두 수의 합 계산¶

def add(a, b):
    result = a + b
    return result

total = add(10, 20)
print(f"합계: {total}")  # 합계: 30

실행 결과: 

합계: 30

Step 2: 함수를 여러 번 활용하기¶

def add(a, b):
    return a + b

# 같은 함수를 다양한 값으로 호출
print(add(5, 3))      # 8
print(add(100, 200))  # 300
print(add(1.5, 2.5))  # 4.0

실행 결과: 

8
300
4.0

Step 3: 여러 매개변수와 함께 사용하기¶

def calculate_average(math, english, science):
    average = (math + english + science) / 3
    return average

avg = calculate_average(85, 90, 88)
print(f"평균: {avg:.1f}점")  # 평균: 87.7점

실행 결과: 

평균: 87.7점

Step 4: 기본값 매개변수 활용하기¶

매개변수에 기본값을 설정하면, 인자를 생략해도 됩니다.

# greeting이 기본값을 가짐
def greet(name, greeting="안녕하세요"):
    return f"{greeting}, {name}님!"

# 인자가 1개일 때
print(greet("철수"))  # 기본값 사용

# 인자가 2개일 때
print(greet("민지", "반갑습니다"))  # 기본값 무시

실행 결과: 

안녕하세요, 철수님!
반갑습니다, 민지님!

Step 5: 실전 예제 - BMI 계산 함수¶

def calculate_bmi(weight, height):
    """
    체중(kg)과 키(cm)를 받아 BMI를 계산하고 반환
    """
    height_m = height / 100  # cm → m 변환
    bmi = weight / (height_m ** 2)
    return round(bmi, 1)  # 소수점 1자리까지 반올림

# 여러 사람의 BMI 계산
bmi1 = calculate_bmi(70, 175)
bmi2 = calculate_bmi(55, 165)

print(f"사람1 BMI: {bmi1}")  # 22.9
print(f"사람2 BMI: {bmi2}")  # 20.2

실행 결과: 

사람1 BMI: 22.9
사람2 BMI: 20.2

📝 전체 코드¶

# 매개변수와 반환값을 모두 활용한 완전한 예제

def calculate_bmi(weight, height):
    """체중(kg)과 키(cm)를 받아 BMI를 반환"""
    height_m = height / 100
    bmi = weight / (height_m ** 2)
    return round(bmi, 1)

def get_bmi_status(bmi):
    """BMI 값에 따라 상태를 반환"""
    if bmi < 18.5:
        return "저체중"
    elif bmi < 25:
        return "정상체중"
    elif bmi < 30:
        return "과체중"
    else:
        return "비만"

# 프로그램 실행
people = [
    {"name": "철수", "weight": 70, "height": 175},
    {"name": "민지", "weight": 55, "height": 165},
    {"name": "영희", "weight": 85, "height": 170}
]

for person in people:
    bmi = calculate_bmi(person["weight"], person["height"])
    status = get_bmi_status(bmi)
    print(f"{person['name']}: BMI {bmi}, {status}")

실행 결과: 

철수: BMI 22.9, 정상체중
민지: BMI 20.2, 정상체중
영희: BMI 29.4, 과체중

⚠️ 주의할 점¶

1. 매개변수와 인자는 다르다 

def add(a, b):      # a, b는 매개변수 (함수 정의할 때)
    return a + b

add(5, 3)           # 5, 3은 인자 (함수 호출할 때)

2. return은 함수를 즉시 종료한다 

def check_age(age):
    if age >= 18:
        return "성인"
    return "미성년자"  # 위의 return이 실행되지 않으면 여기 실행

print(check_age(25))  # "성인"만 출력됨

✅ 점검하기¶

1. 다음 함수를 호출했을 때 출력 결과는? 

def multiply(a, b=2):
    return a * b

print(multiply(5))      # ①
print(multiply(5, 3))   # ②

정답 확인 ① `10` (b의 기본값이 2이므로 5 × 2) ② `15` (b가 3으로 설정되므로 5 × 3)

2. 이 코드의 문제점을 찾으세요: 

def get_double(num):
    print(num * 2)  # return이 없음!

result = get_double(5)
print(result + 10)  # ← 에러 발생

정답 확인 `return`이 없어서 `result`에 `None`이 저장됩니다. `None + 10`은 불가능하므로 TypeError가 발생합니다. **수정:** 
def get_double(num):
    return num * 2  # return 추가

3. 이 함수를 완성하세요: 

def greet(name, age=0):
    # 이름과 나이(옵션)를 받아 인사말을 반환
    # 예: "안녕! 난 민지, 20살이야"
    pass

# 테스트
print(greet("민지", 20))    # 나이 포함
print(greet("철수"))        # 나이 미포함

정답 확인 
def greet(name, age=0):
    if age == 0:
        return f"안녕! 난 {name}이야"
    else:
        return f"안녕! 난 {name}, {age}살이야"

print(greet("민지", 20))    # 안녕! 난 민지, 20살이야
print(greet("철수"))        # 안녕! 난 철수이야
