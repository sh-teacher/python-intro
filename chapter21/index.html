Chapter 21: 함수란? 나만의 명령어 만들기¶

🎯 이 장에서 배우는 것¶

  • 함수의 개념을 이해하고 필요성을 깨달을 수 있다
  • def 키워드로 나만의 함수를 정의하고 호출할 수 있다
  • 내장 함수와 사용자 정의 함수의 차이를 구분할 수 있다

📚 핵심 개념¶

개념 1️⃣: 함수 = 나만의 명령어¶

비유로 시작: 함수는 자판기 버튼과 같아요!

자판기에서 "콜라 버튼"을 누르면 복잡한 내부 메커니즘이 모두 작동해서 콜라가 나옵니다. 당신은 버튼만 누르면 되고, 그 안의 복잡한 과정은 신경 쓸 필요가 없습니다.

함수도 똑같습니다. 복잡한 코드들을 한 묶음으로 정의하고, 한 줄의 명령어(함수 호출)로 모든 동작을 실행할 수 있습니다.

graph LR A["함수 정의<br/>(def 블록)"] -->|한 번만| B["메모리에 저장"] C["함수 호출<br/>(함수명())"] -->|여러 번| B B -->|매번| D["함수 실행<br/>원하는 작업 수행"]

정확한 정의: 함수는 특정 작업을 수행하도록 미리 정의된 코드 묶음입니다.

  • 정의(Define): def 키워드로 함수를 만드는 행위
  • 호출(Call): 정의된 함수를 실제로 실행하는 행위

개념 2️⃣: 함수가 필요한 이유¶

멍이가 인사 메시지를 출력하는 코드를 봅시다.

# 함수 없이 같은 코드를 3번 반복
print("안녕하세요!")
print("저는 멍이입니다")
print("-" * 20)

print("안녕하세요!")
print("저는 멍이입니다")
print("-" * 20)

print("안녕하세요!")
print("저는 멍이입니다")
print("-" * 20)

😫 반복되는 코드의 문제점: - 작성하기 번거로움 - 수정할 때 모든 곳을 일일이 고쳐야 함 - 코드가 길어지고 복잡해짐

함수로 해결하면:

def greet():
    print("안녕하세요!")
    print("저는 멍이입니다")
    print("-" * 20)

# 한 줄로 3번 실행
greet()
greet()
greet()

✨ 함수의 장점: - 코드 작성이 짧아짐 - 수정이 한 곳에서만 이루어짐 - 코드가 읽기 쉬워짐

🔨 따라하기¶

Step 1: 가장 간단한 함수 만들기¶

코드: 

# 1️⃣ 함수 정의
def say_hello():
    print("Hello, Python!")

# 2️⃣ 함수 호출
say_hello()
say_hello()

실행 결과: 

Hello, Python!
Hello, Python!

💡 포인트: def say_hello(): 다음 줄부터는 4칸 들여쓰기를 꼭 해야 합니다!

Step 2: 함수 안에 여러 줄의 코드 넣기¶

코드: 

def print_separator():
    print("=" * 30)
    print("구분선입니다")
    print("=" * 30)

# 함수 호출
print_separator()

실행 결과: 

==============================
구분선입니다
==============================

⚠️ 들여쓰기 규칙: 함수 안의 모든 코드는 같은 수준의 들여쓰기를 유지해야 합니다.

Step 3: 내장 함수 vs 사용자 정의 함수¶

코드: 

# 내장 함수 (Python이 이미 만들어준 것)
print("내장 함수 사용")
length = len("Hello")
user_input = input("이름을 입력하세요: ")

# 사용자 정의 함수 (우리가 직접 만든 것)
def welcome():
    print("환영합니다!")

welcome()

🔍 차이 이해하기:

내장 함수: print(), len(), input() 등 - 파이썬에서 미리 제공

사용자 정의 함수: 우리가 def로 직접 만드는 함수

Step 4: 실전 예제 - 응원 함수¶

코드: 

def cheer_up(name):
    print(f"{name}님을 응원합니다!")
    print("화이팅! 💪")

# 함수 호출 (뒤에서 배울 '매개변수' 미리 체험)
cheer_up("멍이")
cheer_up("냥이")

실행 결과: 

멍이님을 응원합니다!
화이팅! 💪
냥이님을 응원합니다!
화이팅! 💪

Step 5: 함수 정의와 호출 타이밍 이해하기¶

코드: 

# ✅ 올바른 방식: 먼저 정의, 그 다음 호출
def introduce():
    print("저는 프로그래머입니다")

introduce()  # OK!

# ❌ 잘못된 방식: 정의하기 전에 호출
# hello()  # NameError 발생! (정의되지 않음)
# def hello():
#     print("Hi!")

💡 핵심: 함수는 정의한 후에만 호출할 수 있습니다!

📝 전체 코드¶

이 코드를 실행하며 함수의 흐름을 이해해봅시다.

# 📌 예제 1: 인사 함수
def greet():
    print("-" * 20)
    print("안녕하세요!")
    print("프로그래밍 시간입니다")
    print("-" * 20)

greet()
greet()

# 📌 예제 2: 응원 함수
def cheer(person):
    print(f"\n{person}님, 화이팅! 🎉")

cheer("멍이")
cheer("냥이")

# 📌 예제 3: 구분선 출력 함수
def line():
    print("=" * 40)

line()
print("함수는 코드를 깔끔하게 만들어요!")
line()

--------------------
--------------------

프로그래밍 시간입니다
--------------------

멍이님, 화이팅! 🎉

⚠️ 주의할 점¶

1️⃣ 들여쓰기(Indentation) 반드시 해야 합니다¶

def wrong():
print("들여쓰기 없음")  # ❌ IndentationError 발생!

def right():
    print("들여쓰기 4칸")  # ✅ 정상

2️⃣ 정의와 호출은 별개입니다¶

# 함수를 정의만 하면 아무것도 실행되지 않습니다
def my_function():
    print("This will print only when called")

# 호출해야만 실행됩니다
my_function()  # 이 줄이 있어야 실행됨

✅ 점검하기¶

1. 다음 코드의 실행 결과는? 

def show_message():
    print("함수는 재미있어요!")

show_message()
show_message()

✏️ 정답 확인 
함수는 재미있어요!
함수는 재미있어요!
**설명**: `show_message()` 함수가 2번 호출되므로, 메시지가 2번 출력됩니다.

2. 어떤 것이 사용자 정의 함수일까요?

A) print("Hello") B) len("Python") C) def my_func(): print("Hi") D) input("Enter name: ")

✏️ 정답 확인 **정답: C** - A, B, D는 모두 파이썬의 내장 함수입니다 - C는 우리가 직접 `def`로 정의한 사용자 정의 함수입니다
