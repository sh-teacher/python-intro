Chapter 14. for문 심화: 리스트와 함께 반복하기¶

🎯 이 장에서 배우는 것¶

  • 리스트를 만들고 여러 데이터를 하나에 담을 수 있다
  • for문으로 리스트의 모든 요소를 순회할 수 있다
  • enumerate()로 인덱스와 값을 동시에 다룰 수 있다

📚 핵심 개념¶

개념 1: 리스트(List)¶

리스트는 마치 줄을 서 있는 사람들과 같아요. 🎯

한 명 한 명은 '이름'이라는 변수로 저장하고, 여러 사람을 한 줄에 세우는 것처럼, 파이썬의 리스트는 여러 데이터를 하나의 변수에 저장합니다.

정의: 리스트는 대괄호 [ ] 안에 쉼표로 구분된 값들을 저장하는 자료구조입니다.

# 좋아하는 아이돌 멤버들
members = ["민지", "하니", "다니엘", "해린"]

# 좋아하는 음식들
foods = ["떡볶이", "김밥", "우동", "쌀국수"]

# 테스트 점수들
scores = [95, 87, 92, 78, 88]

핵심 특징: - 순서가 있어요: 첫 번째, 두 번째... 순서대로 저장됨 - 인덱스로 접근: 0번째부터 시작 (0, 1, 2, 3...) - 섞여 있어도 괜찮아요: 문자, 숫자 모두 함께 저장 가능

members = ["민지", "하니", "다니엘"]
print(members[0])  # "민지" (첫 번째)
print(members[1])  # "하니" (두 번째)
print(members[-1]) # "다니엘" (마지막, -1부터 역순)

개념 2: for문으로 리스트 순회하기¶

리스트 순회는 줄 서 있는 사람들에게 차례로 물어보는 것과 같아요. 🚶

members = ["민지", "하니", "다니엘"]

# 각 멤버에게 하나씩 "안녕?"이라고 인사하기
for member in members:
    print(f"{member}야, 안녕?")

실행 결과: 

민지야, 안녕?
하니야, 안녕?
다니엘야, 안녕?

작동 원리: 1. 리스트의 첫 번째 요소 "민지"를 member에 저장 2. 블록 실행 (print 문) 3. 두 번째 요소 "하니"를 member에 저장 4. 블록 실행 5. 계속 반복... 리스트가 끝날 때까지

🔨 따라하기¶

Step 1: 나의 버킷리스트 만들기¶

코드: 

# 이번 달에 꼭 하고 싶은 것들
bucket_list = ["영화 보기", "책 읽기", "산책하기", "친구 만나기"]

print("✨ 내 버킷리스트 ✨")
for item in bucket_list:
    print(f"- {item}")

실행 결과: 

✨ 내 버킷리스트 ✨
- 영화 보기
- 책 읽기
- 산책하기
- 친구 만나기

Step 2: 리스트 길이(len) 활용하기¶

코드: 

bucket_list = ["영화 보기", "책 읽기", "산책하기"]

# 몇 개의 목표가 있나?
print(f"총 {len(bucket_list)}개의 목표가 있어요!")

# 모두 해결했을 때
completed = 2
print(f"진행률: {completed}/{len(bucket_list)}")

실행 결과: 

총 3개의 목표가 있어요!
진행률: 2/3

Step 3: 인덱스와 함께 순회하기 (enumerate)¶

코드: 

bucket_list = ["영화 보기", "책 읽기", "산책하기", "친구 만나기"]

# enumerate()는 인덱스와 값을 함께 줍니다
for index, item in enumerate(bucket_list):
    print(f"{index+1}번: {item}")  # 1번부터 시작

실행 결과: 

1번: 영화 보기
2번: 책 읽기
3번: 산책하기
4번: 친구 만나기

Step 4: 조건과 함께 순회하기¶

코드: 

scores = [85, 92, 78, 88, 95]

print("🎯 점수 피드백:")
for score in scores:
    if score >= 90:
        print(f"{score}점 - 우수! 🌟")
    else:
        print(f"{score}점 - 더 화이팅! 💪")

실행 결과: 

🎯 점수 피드백:
85점 - 더 화이팅! 💪
92점 - 우수! 🌟
78점 - 더 화이팅! 💪
88점 - 더 화이팅! 💪
95점 - 우수! 🌟

Step 5: 위시리스트 프로그램 (최종 실습)¶

코드: 

# 사용자로부터 위시리스트 입력받기
wish_list = []
print("🎁 당신의 위시리스트를 만들어봅시다!")
print("(종료하려면 '끝'을 입력하세요)\n")

while True:
    wish = input("원하는 것을 입력하세요: ")
    if wish == "끝":
        break
    wish_list.append(wish)  # 리스트에 추가

# 예쁘게 출력하기
print("\n✨ 당신의 위시리스트 ✨")
for num, item in enumerate(wish_list, start=1):
    print(f"  {num}. {item}")

실행 예시: 

🎁 당신의 위시리스트를 만들어봅시다!
(종료하려면 '끝'을 입력하세요)

원하는 것을 입력하세요: 새 노트북
원하는 것을 입력하세요: 영화표
원하는 것을 입력하세요: 맛있는 디저트
원하는 것을 입력하세요: 끝

✨ 당신의 위시리스트 ✨
  1. 새 노트북
  2. 영화표
  3. 맛있는 디저트

📝 전체 코드¶

# 위시리스트 프로그램 (Step 5 완성본)
wish_list = []

print("🎁 당신의 위시리스트를 만들어봅시다!")
print("(종료하려면 '끝'을 입력하세요)\n")

# 리스트에 항목 추가
while True:
    wish = input("원하는 것을 입력하세요: ")
    if wish == "끝":
        break
    wish_list.append(wish)

# 확인: 리스트가 비어있으면 메시지 출력
if len(wish_list) == 0:
    print("\n아직 원하는 것이 없네요... 😢")
else:
    # 번호와 함께 출력
    print(f"\n✨ 당신의 위시리스트 ({len(wish_list)}개) ✨")
    for num, item in enumerate(wish_list, start=1):
        print(f"  {num}. {item}")

⚠️ 주의할 점¶

1. 인덱스는 0부터 시작합니다! 

members = ["민지", "하니", "다니엘"]
# members[0] = "민지"  ✅
# members[1] = "하니"  ✅
# members[3]은 없음!   ❌ (IndexError 발생)

2. enumerate()의 start 매개변수 

# 0부터 시작 (기본값)
for idx, item in enumerate(items):
    print(idx, item)  # 0, 첫번째 / 1, 두번째

# 1부터 시작 (일반적)
for num, item in enumerate(items, start=1):
    print(num, item)  # 1, 첫번째 / 2, 두번째

✅ 점검하기¶

1. 다음 리스트에서 "우동"에 접근하려면 어떤 인덱스를 사용해야 할까요? 

foods = ["떡볶이", "김밥", "우동", "쌀국수"]

정답 확인 
foods[2]  # 우동

# 설명: 0번이 "떡볶이", 1번이 "김밥", 2번이 "우동"

2. 다음 코드의 실행 결과는? 

items = ["A", "B", "C"]
for idx, item in enumerate(items, start=1):
    print(f"{idx}. {item}")

정답 확인 
1. A
2. B
3. C

# start=1이므로 1번부터 시작됩니다

3. len() 함수는 리스트의 무엇을 반환할까요?

정답 확인 **리스트의 길이(요소의 개수)**를 반환합니다. 
numbers = [10, 20, 30, 40]
print(len(numbers))  # 4
