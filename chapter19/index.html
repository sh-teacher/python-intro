Chapter 19. 튜플과 문자열 다루기¶

🎯 이 장에서 배우는 것¶

  • 튜플의 개념을 이해하고 리스트와의 차이를 구분할 수 있다
  • 문자열 메서드(upper, lower, split, join, replace)를 활용할 수 있다
  • f-string으로 데이터를 문자열에 효과적으로 삽입할 수 있다

📚 핵심 개념¶

개념 1️⃣: 튜플 (Tuple) - 변경 불가능한 데이터 상자¶

튜플은 마치 유리 진열장에 전시된 물품과 같아요. 한 번 진열되면 물건을 꺼내거나 바꿀 수 없죠.

정확한 정의: 튜플은 리스트처럼 여러 값을 저장하지만, 생성 후 수정할 수 없는 자료구조입니다.

# 리스트 vs 튜플
my_list = [1, 2, 3]
my_tuple = (1, 2, 3)

# 리스트는 수정 가능
my_list[0] = 99  # ✅ 작동

# 튜플은 수정 불가능
my_tuple[0] = 99  # ❌ TypeError 발생!

언제 쓰나요? - 데이터가 실수로 변경되면 안 될 때 (설정값, 좌표) - 딕셔너리의 키로 사용할 때 (리스트는 불가, 튜플은 가능) - 함수에서 여러 값을 한번에 반환할 때

개념 2️⃣: 문자열 메서드와 f-string - 텍스트 마법사¶

문자열 메서드는 마치 텍스트 변신 도구와 같아요. 같은 문자열 데이터를 다양한 형태로 변환할 수 있습니다.

주요 메서드 (모두 새로운 문자열을 반환하며, 원본을 변경하지 않음):

text = "Hello Python World"

# 1. 대소문자 변환
print(text.upper())           # "HELLO PYTHON WORLD"
print(text.lower())           # "hello python world"
print(text.capitalize())      # "Hello python world"

# 2. 단어 분리와 합치기
words = text.split()          # ['Hello', 'Python', 'World']
print("-".join(words))        # "Hello-Python-World"

# 3. 치환
new_text = text.replace("Python", "JavaScript")
print(new_text)               # "Hello JavaScript World"

# 4. 공백 제거
messy = "  hello  "
print(messy.strip())          # "hello"

f-string으로 깔끔한 포맷팅:

name = "민수"
score = 95
level = "A"

# f-string 활용
message = f"{name}님의 점수는 {score}점입니다. 등급: {level}"
print(message)  # "민수님의 점수는 95점입니다. 등급: A"

# 계산식도 직접 넣기
print(f"내년 나이: {2024 - 2005 + 1}")  # "내년 나이: 20"

🔨 따라하기¶

Step 1: 튜플 만들고 접근하기¶

상황: 멍이가 게임에서 플레이어 위치(x, y) 좌표를 저장하려고 합니다.

# 튜플 생성
player_position = (10, 25)  # 괄호 안에 쉼표로 구분

# 각 요소 접근 (인덱싱)
x = player_position[0]  # 10
y = player_position[1]  # 25

print(f"플레이어 위치: ({x}, {y})")

실행 결과: 

플레이어 위치: (10, 25)

💡 팁: 튜플은 괄호를 생략할 수도 있어요. position = 10, 25 도 튜플입니다!

Step 2: 튜플 언패킹 (값 한 번에 꺼내기)¶

# 튜플 언패킹
rgb_color = (255, 128, 0)  # 주황색
red, green, blue = rgb_color

print(f"빨강: {red}, 초록: {green}, 파랑: {blue}")

실행 결과: 

빨강: 255, 초록: 128, 파랑: 0

Step 3: 문자열 메서드로 SNS 게시물 처리¶

post = "  안녕하세요! 파이썬 배우는 중입니다. #파이썬 #코딩  "

# 공백 제거
clean_post = post.strip()
print(f"원본: '{post}'")
print(f"정리: '{clean_post}'")

# 해시태그 찾기
if "#파이썬" in clean_post:
    print("✅ 파이썬 해시태그 발견!")

실행 결과: 

원본: '  안녕하세요! 파이썬 배우는 중입니다. #파이썬 #코딩  '
정리: '안녕하세요! 파이썬 배우는 중입니다. #파이썬 #코딩'
✅ 파이썬 해시태그 발견!

Step 4: 복합 예제 - 해시태그 추출 및 정렬¶

post = "오늘의 하루 #일상 #파이썬 #공부 #화이팅"

# 공백으로 단어 분리
words = post.split()

# 해시태그만 추출
hashtags = [word for word in words if word.startswith("#")]

# 결과 출력
print("추출된 해시태그:")
for tag in hashtags:
    print(f"  • {tag}")

# 모두 대문자로 변환해서 출력
print("\n대문자 버전:")
print(" ".join([tag.upper() for tag in hashtags]))

실행 결과: 

추출된 해시태그:
  • #일상
  • #파이썬
  • #공부
  • #화이팅

대문자 버전:
 #일상 #파이썬 #공부 #화이팅

Step 5: 문장 변환기 - 완성 프로젝트¶

# 사용자 입력 받기
sentence = input("변환할 문장을 입력하세요: ")

print("\n=== 문장 변환 결과 ===")

# 1. 대문자
print(f"1️⃣  대문자: {sentence.upper()}")

# 2. 소문자
print(f"2️⃣  소문자: {sentence.lower()}")

# 3. 단어 분리
words = sentence.split()
print(f"3️⃣  단어 개수: {len(words)}개")
print(f"    단어들: {', '.join(words)}")

# 4. 특정 단어 치환
replaced = sentence.replace("파이썬", "Python")
print(f"4️⃣  치환 결과: {replaced}")

# 5. 요약 정보
print(f"5️⃣  문자 길이: {len(sentence)}자")

실행 예시 (입력: "파이썬 배우기는 재미있어요"): 

=== 문장 변환 결과 ===
1️⃣  대문자: 파이썬 배우기는 재미있어요
2️⃣  소문자: 파이썬 배우기는 재미있어요
3️⃣  단어 개수: 3개
    단어들: 파이썬, 배우기는, 재미있어요
4️⃣  치환 결과: Python 배우기는 재미있어요
5️⃣  문자 길이: 11자

📝 전체 코드¶

# ===== 튜플 다루기 =====
print("【 튜플 예제 】")

# 1. 튜플 생성 및 접근
scores = (85, 90, 78)
print(f"점수: {scores[0]}, {scores[1]}, {scores[2]}")

# 2. 언패킹
math, english, korean = scores
print(f"수학: {math}, 영어: {english}, 국어: {korean}")

# ===== 문자열 메서드 =====
print("\n【 문자열 메서드 예제 】")

text = "  Hello Python World  "

# strip: 양쪽 공백 제거
print(f"원본: '{text}'")
print(f"정리: '{text.strip()}'")

# upper/lower: 대소문자
print(f"대문자: {text.strip().upper()}")
print(f"소문자: {text.strip().lower()}")

# split/join: 분리와 합치기
words = text.strip().split()
print(f"단어 분리: {words}")
print(f"언더바로 연결: {'_'.join(words)}")

# replace: 치환
new_text = text.replace("Python", "Java")
print(f"치환 결과: {new_text.strip()}")

# ===== f-string =====
print("\n【 f-string 포맷팅 】")

name = "냥이"
level = 10
exp = 850

status = f"""
{'='*20}
캐릭터: {name}
레벨: {level}
경험치: {exp}/1000
진행도: {(exp/1000)*100:.1f}%
{'='*20}
"""
print(status)

⚠️ 주의할 점¶

1. 튜플은 수정 불가능하다

position = (5, 10)
# position[0] = 7  ← TypeError 발생! 절대 하면 안 됨

# 새로운 튜플을 만들어야 함
position = (7, 10)  # ✅ 이렇게 해야 함

2. 문자열 메서드는 원본을 수정하지 않는다

text = "hello"
text.upper()  # 이것만으로는 text는 여전히 "hello"

# 반드시 변수에 저장해야 함
text = text.upper()  # ✅ 이렇게 해야 함

✅ 점검하기¶

1. 다음 중 올바른 튜플 문법은? 

a) my_tuple = [1, 2, 3]
b) my_tuple = (1, 2, 3)
c) my_tuple = {1, 2, 3}

정답 확인 **정답: b) `my_tuple = (1, 2, 3)`** - a)는 리스트 (변경 가능) - c)는 세트 (순서 없음) - 튜플은 반드시 괄호 `()` 사용

2. "hello world".split() 의 결과는?

정답 확인 **정답: `['hello', 'world']`** (리스트 반환) split()은 공백 기준으로 문자열을 분리해 리스트로 반환합니다.

3. 다음 코드의 출력은? 

tags = ["#python", "#coding"]
result = " ".join(tags)
print(result)

정답 확인 **정답:** 
#python #coding
join()은 리스트의 요소들을 지정한 구분자(" ")로 연결해 문자열로 만듭니다.
