    if 조건문: 만약에~ 라면?¶

    🎯 이 장에서 배우는 것¶

    • if문의 기본 구조(조건, 콜론, 들여쓰기)를 이해하고 작성할 수 있다
    • if-else문으로 두 가지 경우를 처리할 수 있다
    • 들여쓰기(인덴테이션)의 중요성을 이해하고 올바르게 적용할 수 있다

    📚 핵심 개념¶

    개념 1: if문 - 조건에 따라 다르게 행동하기¶

    프로그래밍도 마치 일상의 의사결정과 같아요.

    "만약 배가 고프다면 → 밥을 먹는다" "만약 비가 온다면 → 우산을 챙긴다"

    이렇게 조건이 참(True)이면 특정 코드를 실행하는 것이 if문입니다.

    조건이 참?
  ├─ Yes → if블록의 코드 실행 ✅
  └─ No → 다음으로 넘어감 ⏭️

    기본 구조: 

    if 조건:
    # 이 코드는 조건이 True일 때만 실행됨
    실행할_코드

    3가지 필수 요소: 1. if 키워드: "만약에"를 의미 2. 조건: True 또는 False를 판정하는 식 3. 콜론(:): 조건 다음에 반드시 붙여야 함 4. 들여쓰기: 파이썬은 들여쓰기로 코드 블록을 구분함

    개념 2: if-else문 - 두 가지 길 중 선택하기¶

    "만약 점수가 60점 이상이면 합격, 아니면 불합격"

    이처럼 조건이 참일 때와 거짓일 때 다르게 처리하려면 if-else를 사용합니다.

    조건이 참?
  ├─ Yes → if블록 실행 ✅
  └─ No → else블록 실행 ✅

    기본 구조: 

    if 조건:
    # True일 때 실행
    코드A
else:
    # False일 때 실행
    코드B

    💡 else는 선택사항: if만 있어도 프로그램은 잘 작동합니다. else는 "그렇지 않으면"의 경우가 필요할 때만 사용하세요.

    🔨 따라하기¶

    Step 1: 첫 번째 if문 작성하기¶

    간단한 나이 확인 프로그램을 만들어봅시다.

    age = 20

if age >= 18:
    print("어른입니다! 🎓")

    실행 결과: 

    어른입니다! 🎓

    🔍 코드 해석: - age >= 18: "나이가 18 이상인가?"라는 조건 - 조건이 True이므로 if블록의 코드가 실행됨

    Step 2: 조건이 거짓일 때 확인하기¶

    age = 15

if age >= 18:
    print("어른입니다! 🎓")

print("프로그램 종료")

    실행 결과: 

    프로그램 종료

    🔍 코드 해석: - age >= 18이 False이므로 if블록은 건너뜀 - 다음 코드부터 실행됨

    Step 3: if-else로 두 경로 모두 처리하기¶

    score = 75

if score >= 60:
    print("✅ 합격입니다!")
else:
    print("❌ 불합격입니다.")

    실행 결과: 

    ✅ 합격입니다!

    다른 값으로도 시도해봅시다:

    score = 45

if score >= 60:
    print("✅ 합격입니다!")
else:
    print("❌ 불합격입니다.")

    실행 결과: 

    ❌ 불합격입니다.

    Step 4: 여러 조건 조합하기¶

    name = "민수"
age = 25

if age >= 20:
    print(f"반갑습니다, {name}님! 🤝")
else:
    print(f"안녕, {name}! 👋")

    실행 결과: 

    반갑습니다, 민수님! 🤝

    Step 5: 사용자 입력으로 조건문 완성하기¶

    # 사용자로부터 숫자 입력받기
number = int(input("숫자를 입력하세요: "))

if number > 0:
    print(f"{number}은(는) 양수입니다! 👍")
else:
    print(f"{number}은(는) 양수가 아닙니다. 👎")

    터미널에서 실행: 

    숫자를 입력하세요: 10
10은(는) 양수입니다! 👍

    📝 전체 코드¶

    음료별 디저트 추천 프로그램 (통합 예제)

    # 좋아하는 음료를 입력받아 어울리는 디저트를 추천해요

beverage = input("좋아하는 음료를 입력하세요 (커피/초콜릿/딸기): ")

if beverage == "커피":
    print("☕ 커피라면 크로아상이 잘 어울려요! 🥐")
else:
    if beverage == "초콜릿":
        print("🍫 초콜릿이면 브라우니가 최고야! 🍰")
    else:
        if beverage == "딸기":
            print("🍓 딸기라면 딸기 쇼트케이크! 🎂")
        else:
            print("❓ 그 음료는 잘 모르겠어요...")

print("\n추천을 받으셨습니다! 즐겨보세요~ 😋")

    실행 결과 (입력값: 커피): 

    좋아하는 음료를 입력하세요 (커피/초콜릿/딸기): 커피
☕ 커피라면 크로아상이 잘 어울려요! 🥐

추천을 받으셨습니다! 즐겨보세요~ 😋

    ⚠️ 주의할 점¶

    1️⃣ 콜론(:)을 빠뜨리지 마세요!¶

    # ❌ 틀린 코드
if age >= 18
    print("어른입니다")

# ✅ 올바른 코드
if age >= 18:
    print("어른입니다")

    파이썬은 if 다음에 반드시 콜론(:) 이 필요합니다. 콜론이 없으면 SyntaxError가 발생합니다.

    2️⃣ 들여쓰기(인덴테이션)를 정확히 하세요!¶

    # ❌ 틀린 코드 (들여쓰기 없음)
if age >= 18:
print("어른입니다")  # 실행 안 됨!

# ✅ 올바른 코드 (스페이스 4칸 또는 탭)
if age >= 18:
    print("어른입니다")

    파이썬은 들여쓰기로 코드 블록을 판단합니다. 들여쓰기가 없으면 if문과 관계없는 독립적인 코드로 인식됩니다.

    💡 팁: 대부분의 코드 에디터(VS Code, Pycharm 등)는 if 다음 Enter를 누르면 자동으로 들여쓰기를 해줍니다.

    ✅ 점검하기¶

    1. 다음 코드의 실행 결과는?

    age = 16

if age >= 18:
    print("투표할 수 있습니다.")
else:
    print("아직 투표 나이가 아닙니다.")
    정답 확인 
    아직 투표 나이가 아닙니다.
    **설명**: `age`가 16이므로 `age >= 18`은 `False`입니다. 따라서 `else` 블록이 실행됩니다.

    2. 다음 코드에서 에러 원인은?

    score = 85

if score > 80
    print("우수!")
    정답 확인 **에러**: `SyntaxError: invalid syntax` **원인**: `if score > 80` 다음에 **콜론(`:`)이 없습니다**. **수정**: 
    if score > 80:
    print("우수!")

    3. 사용자로부터 숫자를 입력받아, 홀수이면 "홀수", 짝수이면 "짝수"를 출력하는 프로그램을 작성하세요.

    정답 확인 
    num = int(input("숫자를 입력하세요: "))

if num % 2 == 0:
    print("짝수입니다.")
else:
    print("홀수입니다.")
    **설명**: `num % 2`는 나머지를 구합니다. 나머지가 0이면 짝수, 1이면 홀수입니다.
