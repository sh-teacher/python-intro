📊 matplotlib로 데이터 시각화하기¶

🎯 이 장에서 배우는 것¶

  • matplotlib를 설치하고 첫 번째 그래프를 그릴 수 있다
  • 막대 그래프, 원형 그래프, 꺾은선 그래프를 만들고 선택할 수 있다
  • 제목, 축 레이블, 범례, 색상을 추가하여 차트를 꾸밀 수 있다
  • 한글 폰트를 설정하고 차트를 저장할 수 있다

💡 왜 이걸 배우나요?¶

냥이: "데이터를 숫자로만 봐서는 패턴이 안 보여. 하지만 그림으로 그리면? 아, 한눈에 보인다!"

숫자 [15, 23, 18, 31, 22] vs 그래프 📊

이게 바로 데이터 시각화의 힘입니다. 학교 과제 분석, 게임 점수 추이, SNS 팔로워 증감... 모두 그래프로 보면 훨씬 명확해집니다. matplotlib는 파이썬에서 가장 기본적이고 강력한 시각화 도구입니다.

📚 핵심 개념¶

개념 1: matplotlib란 무엇인가?¶

비유: 빨간색 크레용, 파란색 크레용, 자, 컴퍼스... matplotlib는 파이썬의 그리기 도구 상자입니다.

정확한 정의: matplotlib는 파이썬 라이브러리로, 숫자 데이터를 다양한 형태의 차트와 그래프로 시각화하는 도구입니다.

사용 흐름: 1. 데이터 준비 (리스트나 배열) 2. 차트 종류 선택 (막대, 원형, 꺾은선 등) 3. 차트 그리기 및 꾸미기 4. 화면에 보여주기 또는 파일로 저장

import matplotlib.pyplot as plt

# 데이터
음식 = ['피자', '치킨', '햄버거', '라면']
투표수 = [25, 32, 18, 15]

# 막대 그래프 그리기
plt.bar(음식, 투표수)

# 보여주기
plt.show()

출력: 간단한 막대 그래프가 화면에 나타납니다!

개념 2: 차트 종류와 사용 시점¶

각 차트는 데이터의 '이야기'에 따라 달라집니다.

막대 그래프 (Bar Chart): "각 항목의 크기를 비교하고 싶을 때" - 반 학생들의 키 비교 - 각 반의 시험 평균점수 - 음식 선호도 투표

원형 그래프 (Pie Chart): "전체 중에서 각 부분이 차지하는 비율을 보고 싶을 때" - MBTI 성격 비율 - 하루 시간 사용 분배 (수면, 공부, 게임 등) - 다양한 색상의 사탕 개수 비율

꺾은선 그래프 (Line Chart): "시간에 따른 변화 추이를 보고 싶을 때" - 한 달 용돈 변화 - 월별 플레이타임 - 주식 가격 변동

# 세 가지 차트를 한눈에 보기
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 3, figsize=(12, 4))

# 1. 막대 그래프
axes[0].bar(['A', 'B', 'C'], [10, 24, 15])
axes[0].set_title('막대 그래프')

# 2. 원형 그래프
axes[1].pie([10, 24, 15], labels=['A', 'B', 'C'])
axes[1].set_title('원형 그래프')

# 3. 꺾은선 그래프
axes[2].plot(['월', '화', '수'], [10, 24, 15])
axes[2].set_title('꺾은선 그래프')

plt.tight_layout()
plt.show()

개념 3: 차트 꾸미기 (제목, 축, 범례, 색상)¶

숫자만 있는 차트는 도서관, 꾸민 차트는 전시회입니다. 🎨

필수 꾸미기 4가지:

1️⃣ 제목 (plt.title()): "이 차트가 뭔지 알려줘" 2️⃣ 축 레이블 (plt.xlabel(), plt.ylabel()): "가로축, 세로축이 뭐지?" 3️⃣ 범례 (plt.legend()): "이 색이 뭘 의미해?" 4️⃣ 색상 (color= 또는 colors=): "더 예쁘게!"

import matplotlib.pyplot as plt

반 = ['1반', '2반', '3반', '4반']
과학점수 = [85, 78, 92, 88]

plt.figure(figsize=(8, 5))
plt.bar(반, 과학점수, color=['#FF6B6B', '#4ECDC4', '#45B7D1', '#FFA07A'])

plt.title('각 반의 과학 시험 평균점수', fontsize=14, fontweight='bold')
plt.xlabel('반', fontsize=12)
plt.ylabel('평균점수', fontsize=12)
plt.ylim(0, 100)  # y축 범위 설정

plt.show()

개념 4: matplotlib 좌표계 이해하기¶

matplotlib 세상의 구조:

Figure (전체 액자)
  └─ Axes (그릴 공간, 여기에 그래프가 들어감)
      └─ Plot (실제 그려진 데이터)

간단하게: plt.bar()처럼 직접 쓰면 자동으로 Figure와 Axes를 만들어줍니다. 하지만 여러 그래프를 한 화면에 그리려면?

# 방법 1: 자동 (간단)
plt.bar([1, 2, 3], [10, 20, 15])
plt.show()

# 방법 2: 직접 제어 (복잡하지만 강력)
fig, ax = plt.subplots()
ax.bar([1, 2, 3], [10, 20, 15])
plt.show()

Step 1: 첫 번째 막대 그래프 - 피자 vs 햄버거 투표¶

상황: 학급 투표 결과를 막대 그래프로 보여줘야 합니다.

import matplotlib.pyplot as plt

# 데이터
음식 = ['피자', '치킨', '햄버거', '라면']
투표수 = [25, 32, 18, 15]

# 막대 그래프 그리기
plt.bar(음식, 투표수)
plt.title('선호하는 음식 투표 결과')
plt.xlabel('음식')
plt.ylabel('투표 수')

plt.show()

실행하면: 4개의 막대가 나타나고, 치킨(32표)이 가장 높습니다!

Step 2: 색상과 크기 조절¶

import matplotlib.pyplot as plt

음식 = ['피자', '치킨', '햄버거', '라면']
투표수 = [25, 32, 18, 15]

# figsize로 화면 크기, color로 색상 지정
plt.figure(figsize=(10, 6))
plt.bar(음식, 투표수, color=['red', 'yellow', 'brown', 'orange'])

plt.title('선호하는 음식 투표 결과', fontsize=16, fontweight='bold')
plt.xlabel('음식', fontsize=12)
plt.ylabel('투표 수', fontsize=12)

plt.show()

변화: 화면이 넓어지고, 막대에 색이 입혀집니다! 🎨

Step 3: 원형 그래프로 비율 표현¶

상황: 학급 MBTI 성격 분포를 원형 그래프로 보여줍니다.

import matplotlib.pyplot as plt

성격 = ['ENFP', 'INFP', 'ISTJ', 'ENFJ']
인원 = [8, 6, 7, 3]

plt.figure(figsize=(8, 8))
plt.pie(인원, labels=성격, autopct='%1.1f%%', startangle=90)
plt.title('학급 MBTI 분포', fontsize=14, fontweight='bold')

plt.show()

출력 예: - ENFP: 32.0% - INFP: 24.0% - ISTJ: 28.0% - ENFJ: 12.0%

TIP: autopct='%1.1f%%'는 백분율을 소수점 1자리까지 표시합니다.

Step 4: 꺾은선 그래프로 추이 보기¶

상황: 지난 한 달 매일매일의 게임 플레이타임을 추적합니다.

import matplotlib.pyplot as plt

날짜 = ['1월 1일', '1월 2일', '1월 3일', '1월 4일', '1월 5일']
플레이타임 = [2, 3, 1.5, 4, 2.5]

plt.figure(figsize=(10, 5))
plt.plot(날짜, 플레이타임, marker='o', linewidth=2, markersize=8, color='blue')

plt.title('게임 플레이타임 변화', fontsize=14, fontweight='bold')
plt.xlabel('날짜', fontsize=12)
plt.ylabel('플레이타임 (시간)', fontsize=12)
plt.grid(True, alpha=0.3)

plt.show()

이해하기: - marker='o': 데이터 포인트에 동그라미 표시 - linewidth=2: 선의 굵기 - grid=True: 배경에 격자 표시 (읽기 쉬움)

Step 5: 여러 그래프를 한 화면에 표시¶

상황: 3개월의 공부 시간을 비교해야 합니다.

import matplotlib.pyplot as plt

월 = ['1월', '2월', '3월']
국어 = [10, 12, 15]
수학 = [8, 11, 14]
영어 = [9, 10, 13]

fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# 1번째 그래프: 국어
axes[0].bar(월, 국어, color='red')
axes[0].set_title('국어 공부 시간')
axes[0].set_ylabel('시간')

# 2번째 그래프: 수학
axes[1].bar(월, 수학, color='blue')
axes[1].set_title('수학 공부 시간')
axes[1].set_ylabel('시간')

# 3번째 그래프: 영어
axes[2].bar(월, 영어, color='green')
axes[2].set_title('영어 공부 시간')
axes[2].set_ylabel('시간')

plt.tight_layout()
plt.show()

결과: 3개의 차트가 나란히 표시됩니다!

📝 전체 코드¶

통합 예제: 학급 생활 데이터 분석

import matplotlib.pyplot as plt

# 한글 폰트 설정 (Windows)
plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False

# 데이터 준비
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# 1. 점심 메뉴 선호도 (막대 그래프)
메뉴 = ['스파게티', '돈까스', '불고기', '카레']
표수 = [15, 22, 18, 10]
axes[0, 0].bar(메뉴, 표수, color=['#FF6B6B', '#FFA07A', '#FFB6C1', '#FFE4E1'])
axes[0, 0].set_title('점심 메뉴 선호도', fontweight='bold')
axes[0, 0].set_ylabel('표 수')

# 2. 시간 사용 분배 (원형 그래프)
활동 = ['공부', '게임', '수면', '기타']
시간 = [6, 4, 8, 6]
axes[0, 1].pie(시간, labels=활동, autopct='%1.1f%%')
axes[0, 1].set_title('하루 시간 분배', fontweight='bold')

# 3. 월별 독서량 (꺾은선 그래프)
월 = ['1월', '2월', '3월', '4월', '5월']
책수 = [3, 5, 4, 6, 7]
axes[1, 0].plot(월, 책수, marker='s', linewidth=2, markersize=8, color='green')
axes[1, 0].set_title('월별 독서량', fontweight='bold')
axes[1, 0].set_ylabel('책 수')
axes[1, 0].grid(True, alpha=0.3)

# 4. 과목별 점수 비교 (막대 그래프)
과목 = ['국어', '수학', '과학', '영어', '사회']
점수 = [88, 92, 85, 89, 87]
axes[1, 1].barh(과목, 점수, color='#4ECDC4')  # barh = 가로 막대
axes[1, 1].set_title('과목별 중간고사 점수', fontweight='bold')
axes[1, 1].set_xlabel('점수')

plt.tight_layout()
plt.savefig('class_data.png', dpi=150)
plt.show()

실행 결과: 4개의 차트가 2x2 격자로 표시됩니다! 📊

⚠️ 자주 하는 실수¶

실수 1: matplotlib를 import하지 않았어요¶

# ❌ 틀림
plt.bar([1, 2, 3], [10, 20, 15])

# ✅ 맞음
import matplotlib.pyplot as plt
plt.bar([1, 2, 3], [10, 20, 15])

해결: 항상 파일의 맨 위에 import matplotlib.pyplot as plt를 쓰세요!

실수 2: 한글이 깨져서 나와요 (□□□)¶

# ❌ 문제: 한글이 깨짐
plt.title('우리 반 점수')

# ✅ 해결 1: 폰트 설정 (Windows)
import matplotlib.pyplot as plt
plt.rcParams['font.family'] = 'Malgun Gothic'

# ✅ 해결 2: 영어로 대체
plt.title('Our Class Score')

중요: 맨 처음에 폰트를 한 번만 설정하면 이후 모든 차트에 적용됩니다!

실수 3: plt.show()가 없어서 차트가 안 나타나요¶

# ❌ 틀림: 코드는 실행되지만 화면에 안 보임
import matplotlib.pyplot as plt
plt.bar([1, 2, 3], [10, 20, 15])

# ✅ 맞음
import matplotlib.pyplot as plt
plt.bar([1, 2, 3], [10, 20, 15])
plt.show()  # 이 줄이 필수!

원리: plt.show()를 쓸 때만 그린 그래프가 화면에 나타납니다.

실수 4: 데이터 개수가 맞지 않아요¶

# ❌ 틀림: x축 4개, y축 3개
plt.bar(['A', 'B', 'C', 'D'], [10, 20, 15])

# ✅ 맞음: 개수가 같아야 함
plt.bar(['A', 'B', 'C'], [10, 20, 15])

체크: x축 데이터 개수 = y축 데이터 개수

🚀 더 해보기¶

도전 1: 여러 데이터를 한 그래프에 비교하기¶

import matplotlib.pyplot as plt

월 = ['1월', '2월', '3월']
철수점수 = [80, 85, 90]
영희점수 = [75, 88, 92]

x = range(len(월))
width = 0.35

plt.bar([i - width/2 for i in x], 철수점수, width, label='철수', color='blue')
plt.bar([i + width/2 for i in x], 영희점수, width, label='영희', color='red')

plt.xlabel('월')
plt.ylabel('점수')
plt.title('철수와 영희의 점수 비교')
plt.xticks(x, 월)
plt.legend()

plt.show()

이렇게 하면 같은 달의 점수를 쉽게 비교할 수 있어요! 📊

도전 2: 색상을 더 예쁘게 (색상 팔레트 활용)¶

import matplotlib.pyplot as plt

# 인기 있는 색상 조합들
colors1 = ['#FF6B6B', '#4ECDC4', '#45B7D1', '#FFA07A']  # 파스텔
colors2 = ['#1f77b4', '#ff7f0e', '#2ca02c', '#d62728']  # 기본

음식 = ['피자', '치킨', '햄버거', '라면']
표수 = [25, 32, 18, 15]

plt.bar(음식, 표수, color=colors1)
plt.title('음식 투표')
plt.show()
