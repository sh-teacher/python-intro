Chapter 07. input()으로 대화하는 프로그램 만들기¶

🎯 이 장에서 배우는 것¶

  • input() 함수로 사용자의 입력을 받을 수 있다
  • 문자열을 숫자로 바꾸는 형변환(int(), float())을 이해한다
  • 입력과 출력을 조합해 대화형 프로그램을 만들 수 있다

📚 핵심 개념¶

개념 1: input() - 프로그램의 귀¶

비유로 시작
input()은 마치 마이크와 같아요. 프로그램이 마이크를 켜서 사용자의 목소리(입력)를 기다리고, 사용자가 말하면 그 말을 기록하는 거죠.

정확한 정의
input()은 사용자가 키보드로 입력한 데이터를 문자열로 받는 함수입니다. 항상 문자열 타입(str)으로 반환됩니다.

예시로 확인

name = input("이름을 입력하세요: ")
print(f"안녕하세요, {name}님!")

실행 결과: 

이름을 입력하세요: 민준
안녕하세요, 민준님!

개념 2: 형변환(Type Casting) - 문자를 숫자로¶

비유로 시작
사용자가 "25"라고 입력하면 input()은 문자 "25"로 받아요. 이것은 숫자 25와 다릅니다. 문자 "25"에 1을 더하고 싶으면 먼저 숫자로 변환해야 해요.

정확한 정의
형변환은 한 자료형을 다른 자료형으로 변환하는 과정입니다. - int(): 문자열 → 정수 - float(): 문자열 → 실수

예시로 확인

# ❌ 오류 발생
age = input("나이: ")
print(age + 1)  # TypeError!

# ✅ 형변환으로 해결
age = int(input("나이: "))
print(age + 1)  # 정상 작동

🔨 따라하기¶

Step 1: 사용자의 이름을 입력받고 인사하기¶

name = input("당신의 이름은? ")
print(f"만나서 반갑습니다, {name}!")

실행 결과: 

당신의 이름은? 수진
만나서 반갑습니다, 수진!

💡 TIP: input()의 괄호 안에 질문을 넣으면, 그 질문이 출력된 후 입력을 기다립니다.

Step 2: 숫자 입력받기 (형변환 필수!)¶

score = int(input("시험 점수를 입력하세요: "))
print(f"당신의 점수는 {score}점입니다.")
print(f"100점까지 남은 점수: {100 - score}점")

실행 결과: 

시험 점수를 입력하세요: 87
당신의 점수는 87점입니다.
100점까지 남은 점수: 13점

⚠️ WARNING: 형변환 없이 score = input(...)만 사면 뺄셈이 실패합니다!

Step 3: 여러 개의 입력받기¶

name = input("이름: ")
height = float(input("키(cm): "))
hobby = input("취미: ")

print(f"\n=== 프로필 ===")
print(f"이름: {name}")
print(f"키: {height}cm")
print(f"취미: {hobby}")

실행 결과: 

이름: 진호
키(cm): 175.5
취미: 프로그래밍

=== 프로필 ===
이름: 진호
키: 175.5cm
취미: 프로그래밍

Step 4: 간단한 계산 프로그램¶

num1 = int(input("첫 번째 숫자: "))
num2 = int(input("두 번째 숫자: "))

sum_result = num1 + num2
product = num1 * num2

print(f"{num1} + {num2} = {sum_result}")
print(f"{num1} × {num2} = {product}")

실행 결과: 

첫 번째 숫자: 12
두 번째 숫자: 8
12 + 8 = 20
12 × 8 = 96

Step 5: 나만의 프로필 카드 (완성 프로젝트)¶

print("=== 프로필 카드 생성기 ===\n")

name = input("이름: ")
age = int(input("나이: "))
mbti = input("MBTI: ")
hobby = input("취미: ")

print("\n" + "="*25)
print(f"  🎉 {name}의 프로필")
print("="*25)
print(f"나이: {age}세")
print(f"MBTI: {mbti}")
print(f"취미: {hobby}")
print("="*25 + "\n")

실행 결과: 

=== 프로필 카드 생성기 ===

이름: 지영
나이: 20
MBTI: INFP
취미: 독서

=========================
  🎉 지영의 프로필
=========================
나이: 20세
MBTI: INFP
취미: 독서
=========================

📝 전체 코드¶

# 🎯 input()과 형변환을 활용한 프로필 카드 생성기

print("╔" + "═"*23 + "╗")
print("║   프로필 카드 생성기   ║")
print("╚" + "═"*23 + "╝\n")

# 사용자 입력받기
name = input("👤 이름: ")
age = int(input("🎂 나이: "))
city = input("🏙️  도시: ")
mbti = input("💭 MBTI: ")

# 결과 출력
print("\n" + "─"*25)
print(f"🌟 {name}님의 프로필 카드")
print("─"*25)
print(f"나이: {age}세")
print(f"거주지: {city}")
print(f"성향: {mbti}")
print("─"*25)

⚠️ 주의할 점¶

1️⃣ input()은 항상 문자열을 반환한다¶

# ❌ 틀린 사용
price = input("가격: ")  # "5000"
total = price * 2        # "50005000" (문자열 반복!)

# ✅ 올바른 사용
price = int(input("가격: "))  # 5000
total = price * 2             # 10000 (숫자 계산!)

2️⃣ 형변환할 때 정확한 형식이 필요하다¶

# ❌ 정수로 변환할 수 없는 문자열
age = int(input("나이: "))  # 사용자가 "20살" 입력 → ValueError!

# ✅ 사용자에게 명확한 지시
age = int(input("나이(숫자만): "))  # 사용자가 "20" 입력 → 정상

✅ 점검하기¶

  1. input()이 반환하는 자료형은 무엇인가요?
정답 확인 문자열(`str`)입니다. 사용자가 숫자를 입력해도 input()은 항상 문자열로 받습니다.
  1. 다음 코드의 문제점은 무엇일까요? 
    length = input("직사각형 길이(cm): ")
width = input("직사각형 너비(cm): ")
area = length * width
print(f"넓이: {area}cm²")
정답 확인 input()은 문자열을 반환하므로, `length * width`는 문자열 반복이 됩니다. `int(input(...))`으로 형변환해야 합니다.
  1. f-string에서 변수를 사용하는 방식은?
정답 확인 중괄호 `{}`로 감싸서 사용합니다. 예: `f"안녕, {name}!"`

🚀 심화 도전 (선택)¶

사용자로부터 시작 온도(섭씨)를 입력받아 화씨로 변환하는 프로그램을 만들어보세요.
공식: 화씨 = (섭씨 × 9/5) + 32

# 💡 힌트: float()를 사용하세요
celsius = float(input("섭씨 온도: "))
fahrenheit = (celsius * 9/5) + 32
print(f"{celsius}°C = {fahrenheit}°F")

🔗 다음 장 미리보기¶

다음 장에서는 조건문(if/else)을 배워요! 프로그램이 입력받은 값에 따라 다르게 반응하는 방법을 배울 거예요.

예를 들어: 

age = int(input("나이: "))
if age >= 18:
    print("어서오세요, 성인입니다!")
else:
    print("미성년자입니다.")

이렇게 프로그램이 판단하고 선택하는 힘을 얻게 됩니다! 🎯
